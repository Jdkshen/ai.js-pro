QuickJS NativeFrame + YOLO 示例（OpenCV 5.0 DNN）

这组示例使用真正的原生图像链：

ImageReader RGBA Plane
  -> NativeFrame / C++ cv::Mat
  -> DirectByteBuffer（不复制像素）
  -> OpenCV 5.0 DNN 推理
  -> QuickJS 检测框数组

目录结构：
- DNN/   OpenCV 5.0 DNN 脚本与发布包内置模型（yolo26_160.onnx = 默认 160×160；yolo26_640.onnx = 保底 640×640）
- 模型管理.js   模型库管理：导入 .onnx / .txt 标签、切换当前模型、设置输入尺寸

包含六个识别模板 + 一个模型管理（均为 QuickJS 新引擎）：
- YOLO基准测试.js：预热后检测 5 张最新缓存帧，输出平均推理耗时。
- YOLO运行环境测试.js：后端可用性 / 版本 / 模型加载耗时，无需截图授权。
- YOLO单帧直连测试.js：截取一帧，推理并打印检测框与耗时。
- YOLO实时直连测试.js：连续推理 100 帧，每 10 帧打印进度，结束时输出
  平均/最大/最小耗时与 FPS。
- YOLO持续识别.js：连续 1000 帧截图 + 检测，约每 3 秒输出一次汇总
  （FPS / 平均耗时 / 命中数），检测到目标逐条打印；同时在全屏悬浮层
  绘制绿色检测框 + 黄色标签和得分，左上角显示后端 / 帧数 / 平均耗时 / 命中数。
  需要"显示在其他应用上层"悬浮窗权限（首次运行会 toast 提示）。
- YOLO区域检测.js（ROI）：只识别指定区域，演示 region 参数
  [x, y, width, height]（全屏像素坐标，越界会报错）；检测框坐标自动回移到
  全屏坐标系；每 5 秒输出"全屏 vs 区域"性能/命中对比（YOLO_ROI_SUMMARY），
  命中逐条打印（YOLO_ROI_HIT）。绘制层只显示区域命中的框。
- 模型管理.js：模型库插件。导入 / 切换 / 删除模型，设置 inputSize 与标签文件；
  切换后上面六个案例会自动改用当前模型。

模型库与模型切换（模型管理.js）：
- 发布包内置两个模型：默认 **yolo26_160**（inputSize=160，最快、小目标易漏）与 yolo26_640（保底、最准），删不掉；
  其它模型通过模型库导入（竖屏手机推荐 160×320），发布包不必为每个模型变大。
- 库目录默认 /sdcard/脚本/模型库（可在菜单里改）。三种导入方式任选：
  ① 菜单「导入模型」→ 手动输入 .onnx 完整路径；
  ② 菜单「导入模型」→ 自动在 Download / Documents / 脚本 里找 .onnx 让你选；
  ③ 直接用任何文件管理器把 .onnx（可选同名 .txt 标签）放进库目录。
- 用菜单导入时会自动按文件名推断 inputSize（如 yolo26_640.onnx → 640），
  并做「加载 + 可选跑一帧」校验；模型必须是 OpenCV DNN 能读的 end2end ONNX
  （输出 [1,300,6]：[x1,y1,x2,y2,score,classId]）。
- 校验分两步报，不会混在一起：加载（模型本身）与截图（拿一帧画面）。
  截图这一步如果没成，只会提示「跳过推理验证」，并说明是权限/画面问题
  （手机弹出「开始录制或投屏」时要点「立即开始」，页面会等 9 秒）；
  **不影响导入**，模型照样进库。
- 每行三个按钮：使用 / 验证 / 删除。「验证」= 用当前画面跑一帧（pre/inf 耗时、
  检出个数），随时可以点，不必重新导入。
- 输入尺寸支持两种：方形填一个数（如 640，存在 inputSize.<文件名>），竖屏矩形填
  「宽x高」（如 160x320，存在 inputWidth.<文件名> + inputHeight.<文件名>）。
  导入 yolo26_160x320.onnx 这类文件名会自动按 160x320 设好。
  【为何要矩形】竖屏手机屏幕（1080x2400）套进方形 320 时，真实内容只有 144x320，
  左右各 88px 是灰边白算；换 160x320 的竖屏模型后内容一模一样，但推理量减半。
  实测（K40）：方形 160 = 7.4ms、竖屏 160x320 = 12.4ms（≈方形 320 的质量）、
  方形 320 = 21.3ms、竖屏 288x640 = 37ms（≈方形 640 的质量）、方形 640 = 80ms。
- 改名：菜单「重命名模型」→ 选模型 → 输入新名字。会同时改 .onnx 与同名 .txt，
  并把 inputSize / 标签设置和「当前模型」一起挪到新名字上。
- 标签要填「.txt 的完整路径」：填成名字或不存在的路径会被直接拦下（不会存进去）；
  以前存过的失效路径会在下次读取时自动忽略并清除，并提示「已忽略并清除」——
  不会再因为这个把好好的模型报成「✗ 加载失败」。想恢复自动查找就把输入框清空后确定。
- 标签的自动顺序：模型同名 .txt → 库里 labels.txt → **发布包内置的默认标签（COCO 80）**。
  所以导入的模型没有带 .txt 也不会变成一堆 classId 数字；自定义类别的模型请用
  「设置标签」指到自己的 .txt（或在模型旁边放一个同名 .txt）。
- 在文件管理器里增删/改名模型，面板每 2 秒自动跟上，不用点「刷新」。
- 切换：「使用」按钮或「用内置模型」；当前选择存在应用存储里
  （storages: aijspro.yolo.models），与脚本放在哪无关；
  删掉正在使用的库内模型会自动回退到内置模型。
- 识别时的模型备注：六个案例启动时会打印一行
  [模型] 本次识别使用：<名称>（inputSize=N，来源：…），
  结构化输出（QUICKJS_YOLO_LOAD_OK / QUICKJS_NATIVE_YOLO_OK / NATIVE_YOLO_FRAME /
  QUICKJS_NATIVE_YOLO_LOOP_OK / YOLO_ROI_HIT / YOLO_ROI_SUMMARY / YOLO_BENCH /
  [STABILITY]）都带 model= 字段。
- 注意：方式③手动丢进库目录的模型默认按 inputSize=640 加载；不是 640 的模型
  （例如 320）请在菜单「设置输入尺寸」里改，或用方式①②导入（会自动认文件名里的数字）。

持续识别停止方式：在应用任务列表（"运行中任务"）点击停止单个脚本或
"停止全部"。正在推理时会在当前帧结束后响应停止。

耗时字段（detector.detect 返回的数组对象）：
- preprocessMs   预处理（缩放 + letterbox + 归一化）
- inferenceMs    模型推理
- totalMs        预处理 + 推理
- 实时/持续案例额外输出：averageModelMs / maxModelMs / minModelMs / fps

截图策略（全部 YOLO 案例已统一）：
- 基准、单帧、实时、持续和区域检测均使用
  { mode: 'fast', size: 720, fresh: false }，每轮立即取 ImageReader 当前最新帧，
  不因静止画面额外等待 50ms。
- 需要识别细小目标时可把 mode 改为 full；更重视速度时可把 size 改为 640。
- 视觉加速帧的检测框和 region 均自动映射到原屏幕坐标，不需要手动换算。

detect 可选参数：
- confidence  置信度阈值（默认 0.25）
- nms         非极大值抑制（默认 0.45）
- region      [x, y, width, height] 只检测该区域（默认全屏）

yolo.load 可选参数（输入尺寸）：
- inputSize       正方形边长（默认 640，需与模型输入一致）
- inputWidth     输入宽度（如 480）——矩形模型（如 480x640）使用，优先于 inputSize
- inputHeight    输入高度（如 640）
例：{ inputWidth: 480, inputHeight: 640 }（需模型输入 shape 匹配，如 [1,3,640,480]）

实测基准（Redmi K40 / 骁龙870 / Release）：
- 旧 320 模型（yolo26_320 @320，100 帧）：截图平均 7.06 ms，预处理平均 1.05 ms，
  推理平均 45.42 ms，模型总耗时平均 46.47 ms，端到端 18.5 FPS，100 帧 errors=0。
- 当前 640 模型的算力约为 320 的 4 倍，耗时需在本机重新实测：直接跑
  YOLO基准测试.js，看输出的平均 totalMs 与 FPS。
注意：OpenCV 的 OpenCL target 在骁龙/Adreno 上为负优化（实测 686ms），案例默认
不启用；OpenCV 5.0 新图引擎不支持手动指定 target，使用默认 CPU 即最优。

DNN 后端由 OpenCV 5.0 提供，支持应用当前打包的 ABI。
测试时请保证前台画面中有 COCO 数据集可识别目标，例如人、汽车、猫或狗。
