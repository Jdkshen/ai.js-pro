Rhino 引擎（兼容引擎）
====================

普通 .js 文件现在默认由 QuickJS 引擎执行；需要旧引擎的脚本在首行加 // @engine rhino 即可回退。
本目录存放 Rhino 引擎专属示例：

- 回归测试.js          基础 API 断言回归
- 全模块回归测试.js    全模块能力验证（files/device/app/events/media/sensors/sqlite/ui/
                       threads/images/floaty/dialogs/shell/toast/require/runtime/engines）

对比：
- QuickJS 引擎示例见上级目录「QuickJS 新引擎/」
- 普通脚本无需再写 // @engine quickjs（默认就是它）；旧脚本回退写 // @engine rhino
