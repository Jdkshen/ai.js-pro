Plugins#

Stability: 1 - Experimental（仅 Rhino 引擎）

插件（plugin）是一个独立的APK，用来把原生能力（第三方SDK、算法库、需要Java才能做的事情）打包成可以反复使用的能力包。脚本侧只需要知道插件包名，用plugins.load()加载它即可。

插件里同时带有一段脚本作为入口（index.js）：加载时宿主会把插件的脚本目录复制到应用缓存目录，用require()执行入口脚本，并把插件对象传给入口函数。因此插件的使用方式可以完全由插件作者定义。

插件是需要安装的第三方APK，加载插件等于让插件的原生代码以宿主应用的权限运行，只加载你信任的插件。

plugins.load(packageName)#

  • packageName <string> 插件的包名
  • 返回 <any> 插件入口脚本index.js的导出结果

加载流程：

  1. 用createPackageContext拿到插件的上下文；
  2. 读取插件AndroidManifest.xml中org.autojs.plugin.sdk.registry元数据指向的注册类，反射调用它的loadDefault(宿主Context, 插件Context, runtime, scope)；
  3. 把插件的assets脚本目录复制到cache/plugin-scripts/<包名>/，入口固定为index.js；
  4. require(index.js)并用插件对象作为参数调用其导出函数，导出函数的返回值就是plugins.load()的返回值。
var ocr = plugins.load("com.example.ocr.plugin");
var result = ocr.recognize("/sdcard/图片.png");
log(result);

加载失败会抛出Plugin.PluginLoadException，常见原因：插件没有安装、插件缺少registry元数据、插件与当前版本不兼容。

插件对象的成员#

传给插件入口函数的对象由插件SDK提供，通用成员如下：

  • plugin.unwrap() <Object> 取回插件SDK的原始实例，可以直接调用它的Java方法（插件自己的API、版本号等都从这里取）
  • plugin.getAssetsScriptDir() <string> 插件内脚本目录在APK里的路径
  • plugin.getMainScriptPath() <string> 复制到缓存后的入口脚本路径（Rhino下也可写成plugin.mainScriptPath）

典型的index.js写法（插件作者提供）：

// 插件 APK 内的 assets/scripts/index.js
module.exports = function (plugin) {
    var api = plugin.unwrap(); // 插件 SDK 的实例
    return {
        version: plugin.getVersion(),
        recognize: function (path) {
            return api.recognizeImageFile(path);
        }
    };
};

这样脚本侧就能直接ocr.recognize(path)了。

编写一个插件#

  1. 新建Android应用工程，在AndroidManifest.xml的<application>里声明注册类：
    <meta-data android:name="org.autojs.plugin.sdk.registry" android:value="com.example.plugin.Registry"/>
  2. 注册类提供一个静态方法：public static Object loadDefault(Context hostContext, Context pluginContext, Object runtime, Object scope)，返回插件SDK的实例对象。
  3. 把脚本入口放到assets/scripts/index.js，用module.exports = function(plugin){ /* 返回给脚本的API */ }导出。
  4. 用正式密钥签名后安装到设备，脚本侧用plugins.load("插件的包名")加载。

注意事项

  • 插件只在Rhino引擎可用；QuickJS引擎暂未实现plugins模块。
  • 插件入口脚本按Rhino脚本执行，可以直接使用require、plugins.load之外的Rhino API，但它与宿主脚本是不同的脚本上下文（engines里会多出一个脚本实例）。
  • 插件的assets脚本目录每次加载都会被复制到cache/plugin-scripts/，因此修改插件脚本需要重新安装插件APK。
