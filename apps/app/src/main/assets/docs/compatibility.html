能力当前写法状态

暂不收录的新版模块

当前运行时尚未提供 $work_manager、$zip、$crypto、 sqlite、RootAutomator2、$ocr、新版特征匹配和新版 WebSocket API。对应教程需要先实现底层模块并通过测试，之后才能加入可运行示例。
