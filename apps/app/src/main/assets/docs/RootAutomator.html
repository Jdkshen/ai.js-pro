RootAutomator#

Stability: 1 - Experimental（需要设备已 root）

RootAutomator 用root 权限直接往/dev/input/event*写输入事件，不走无障碍服务。它的特点是：

  • 不需要开启无障碍、不需要前台窗口，能在锁屏/游戏/输入法拦截等场景下点按；
  • 支持多指手势（双指缩放、三指等），这是无障碍gestures之外更底层的做法；
  • 代价是需要 root，并且要自己管理手指的按下/抬起（忘记exit()会残留“手指”）。

两个引擎的用法一致（Rhino 里是全局RootAutomator，QuickJS 里也是）；Pro 的RootAutomator2({ root: true } / { adb: true })（数组式多指、支持 Shizuku/ADB 授权）本引擎尚未实现，用本页的接口即可完成同样的操作。

new RootAutomator([inputDevice][, nonBlockingForReady])#

  • inputDevice <string> 可选，触摸设备名（如event3）或设备路径（/dev/input/event3）；不传则自动选择触摸屏设备
  • nonBlockingForReady <boolean> 可选，true表示构造时不等待 root shell 就绪（默认false，会等 root 授权完成）
  • 返回 <RootAutomator>

构造时会启动一个 root shell。设备未 root 时构造会失败（nonBlockingForReady为false时会一直等 root 授权），建议先用下面的方式探测：

var hasRoot = shell('id', true).result.indexOf('uid=0') >= 0;
if (!hasRoot) {
    toastLog('需要 root 权限');
    exit();
}
var ra = new RootAutomator();

方法#

  • ra.tap(x, y[, id]) <void> 点按
  • ra.press(x, y, duration[, id]) <void> 按住duration毫秒
  • ra.longPress(x, y[, id]) <void> 长按
  • ra.swipe(x1, y1, x2, y2[, duration[, id]]) <void> 滑动，默认时长 300ms
  • ra.touch(x, y) / ra.touchX(x) / ra.touchY(y) <void> 直接设置触摸坐标（等价于写ABS_MT_POSITION_X/Y）
  • ra.touchDown(x, y[, id]) <void> 按下某个手指
  • ra.touchMove(x, y[, id]) <void> 移动某个手指
  • ra.touchUp([id]) <void> 抬起某个手指（不传 id 时抬起默认手指）
  • ra.sendSync() / ra.sendMtSync() <void> 提交当前事件（多指手势里每改完一组坐标都要同步一次）
  • ra.sendEvent(type, code, value) <void> 直接写一个 input 事件（type/code是EV_*/ABS_*等常量值）
  • ra.getDefaultId() / ra.setDefaultId(id) <number / void> 默认手指 id
  • ra.setScreenMetrics(width, height) <void> 设置设计分辨率，之后坐标自动按屏幕缩放
  • ra.exit() <void> 关闭 root shell 并释放手指，脚本结束前务必调用

多指手势#

多指手势的过程是：逐指按下 → 逐指移动 → 逐指抬起，同一时刻的坐标用相同的sendSync()提交。下面是从两指捏合（缩放）的示例：

var ra = new RootAutomator();
sleep(1000);

var p0 = { x: 150, y: 300 }, p1 = { x: 850, y: 1700 };
// 手指 0 按住左上，手指 1 按住右下
ra.touchDown(p0.x, p0.y, 0);
ra.touchDown(p1.x, p1.y, 1);

// 两个手指相向移动
for (var i = 0; i < 350; i++) {
    ra.touchMove(p0.x + i, p0.y + i * 2, 0);
    ra.touchMove(p1.x - i, p1.y - i * 2, 1);
    ra.sendMtSync();
    sleep(1);
}
ra.touchUp(0);
ra.touchUp(1);
ra.exit();

忘记ra.exit()（或用exit()提前结束脚本）时，屏幕上可能残留“按着不放”的手指。脚本里用try…finally包住手势代码，确保退出时释放。

限制与替代方案#

  • 需要root；没有 root 时请用无障碍方式：click()、gestures()、automator（swipe/gesture等）。
  • 坐标是设备像素；换设备或改分辨率后请重新setScreenMetrics()。
  • 输入事件是“真实的”，系统与游戏都会当成真人操作，无法被无障碍检测到；但同样也会影响其它应用，请谨慎在游戏里使用。
  • 多指手势里的id是逻辑手指编号（0、1、2…），由本模块管理并映射到内核的 slot。
  • Pro 的RootAutomator2（{ root: true }/{ adb: true }、数组式多指、Shizuku 授权）未实现；本页接口同样支持多指，只是写法不同。
