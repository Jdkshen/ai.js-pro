IO#

Stability: 2 - Stable

io模块是files的补充：files.read()、files.write()这种接口会把整个文件一次性放进内存，几十MB以上的文件会占用大量内存甚至OOM。io模块提供"流式"读写，可以按行、按块处理，并且可以带缓冲。

io模块只有两个成员：io.open()（等价于全局函数open()）和io.files（等价于全局files）。用require("io")可以拿到该模块对象。

io.open(path[, mode[, encoding[, bufferSize]]])#

  • path <string> 文件路径
  • mode <string> 打开模式，见下表，默认"r"
  • encoding <string> 编码，默认设备默认编码（Android上通常为UTF-8）
  • bufferSize <number> 缓冲区大小，默认8192
  • 返回 <Object> 文件流对象，模式不支持时返回null
mode 说明 返回对象
"r" 以只读方式打开文本文件 只读文本文件，见下文
"w" 以可写方式打开文本文件，原有内容会被清空 可写文本文件
"a" 以可写方式打开文本文件，写入内容追加到末尾 可写文本文件

其它模式（例如"rw"）当前不支持，会返回null；需要随机读写二进制请用Java的RandomAccessFile或files.readBytes/files.writeBytes。

var reader = open("/sdcard/big.log", "r", "utf-8", 1024 * 64); // 等价于 io.open(...)
var writer = open("/sdcard/big-filtered.log", "w");
var appender = open("/sdcard/big.log", "a");

只读文本文件#

mode为"r"时返回，方法如下：

  • read() <string> 读取剩余全部内容
  • read(size) <string> 读取最多size个字符，读到末尾返回空串
  • readline() <string> 读取一行（不含换行符），读到末尾返回null
  • readlines() <Array> 读取剩余全部内容并按行切分
  • close() 关闭文件流
  • getPath() <string> 文件路径
// 逐行处理大文件：内存占用与文件大小无关
var reader = open("/sdcard/big.log");
var writer = open("/sdcard/errors.log", "w");
var line;
var count = 0;
while ((line = reader.readline()) !== null) {
    if (line.indexOf("ERROR") >= 0) {
        writer.writeline(line);
        count++;
    }
}
reader.close();
writer.close();
log("共写入 " + count + " 行错误日志");

可写文本文件#

mode为"w"或"a"时返回，方法如下：

  • write(str) 写入字符串（不自动换行）
  • writeline(line) 写入一行并换行
  • writelines(lines) 写入一个字符串数组，每行一个
  • flush() 立刻把缓冲区内容写到磁盘
  • close() 关闭文件流（会自动flush）
  • getPath() <string> 文件路径
var writer = open("/sdcard/report.csv", "w");
writer.writeline("时间,事件");
for (var i = 0; i < 10; i++) {
    writer.writeline(new Date().toLocaleString() + ",事件" + i);
}
writer.writelines(["--- 结束 ---"]);
writer.close();

注意事项

  • 流用完一定要close()，否则缓冲区里的内容可能没有落盘。
  • "w"模式会立即清空已有内容，只想追加请用"a"模式。
  • 读取非UTF-8文件（例如GBK）请显式传encoding，否则中文会乱码。
  • 两个引擎的行为差异：Rhino是真正的流式读取（内存占用与文件大小无关）；QuickJS的"r"模式会先把整个文件读进内存再模拟逐行接口，因此超大文件在QuickJS下内存占用与文件同量级，建议改用files.read()分片处理或Java互操作。flush()在QuickJS下是空操作（写入直接落盘）。
  • 二进制文件（图片、APK）：Rhino可用的files.readBytes()、files.writeBytes()、files.appendBytes()在QuickJS下暂未实现，请使用Java互操作中的java.io类或images模块的图片接口。
