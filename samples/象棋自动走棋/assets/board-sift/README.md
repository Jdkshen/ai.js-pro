# SIFT 棋盘定位模板

`board.png` 来自项目真机图片验证集的木色棋盘，裁剪区域为 `[12,600,1056,1176]`。
`calibration.json` 保存模板内第一个交点、格距和两块河界文字参照的相对坐标。

运行路径：主界面及悬浮面板 → `src/vision/locate-board.js` → `sift-board-locator.js`。
SIFT 只确定棋盘几何；90 格字形识别、红黑判色、圆心证据和棋规校验仍使用项目原实现。
完整读数通过规则门后才保存河界参照。下一帧复查参照，最多每 30 次复查再运行 SIFT。
参照变化只触发 SIFT 几何复查：交点未变则继续原读盘链，完整盘面通过后刷新参照；确认平移或缩放才报告变位。暂未找到或异常则拒绝当前观察，不声称棋盘已移动。新棋盘不会沿用旧盘面或旧点击坐标。

当前标定支持轴对齐的木色皮肤及等比缩放。SIFT 未找到模板时继续原有 Canny/Hough、图色格线定位。
倾斜和透视棋盘不交给轴对齐的字形识别器。

K40 项目入口回归：`tools/test-sift-board.js`，图片数据位于 `/sdcard/Download/ai-sift-chess`。
此脚本只做识别，输出 `test-output/sift-board-project.json`；不进行点击或算棋。
