QuickJS NativeFrame + YOLO 示例（ncnn / onnx / opencv 三套独立案例）

这组示例使用真正的原生图像链：

ImageReader RGBA Plane
  -> NativeFrame / C++ cv::Mat
  -> DirectByteBuffer（不复制像素）
  -> 后端推理（ncnn / ONNX Runtime / OpenCV 5.0 DNN）
  -> QuickJS 检测框数组

目录结构（每个后端一套，共三套）：
- ncnn/   yolo26_320.param + .bin（NCNN）
- onnx/   yolo26_320.onnx（ONNX Runtime / XNNPACK）
- opencv/ yolo26_320.onnx（OpenCV 5.0 DNN）

每套包含四个模板案例：
- YOLO运行环境测试.js：后端可用性 / 版本 / 模型加载耗时，无需截图授权。
- YOLO单帧直连测试.js：截取一帧，推理并打印检测框与耗时。
- YOLO实时直连测试.js：连续推理 60 帧，每 10 帧打印进度，结束时输出
  平均/最大/最小耗时与 FPS。
- YOLO持续识别.js：无限循环截图 + 检测，每 5 秒输出一次汇总
  （FPS / 平均耗时 / 命中数），检测到目标逐条打印；同时在全屏悬浮层
  绘制绿色检测框 + 黄色标签和得分，左上角显示后端 / 帧数 / 平均耗时 / 命中数。
  需要“显示在其他应用上层”悬浮窗权限（首次运行会 toast 提示）。

持续识别停止方式：在应用任务列表（“运行中任务”）点击停止单个脚本或
“停止全部”。QuickJS interrupt 在 sleep 分片内及时响应，最迟约 100ms 中止。

耗时字段（detector.detect 返回的数组对象）：
- preprocessMs   预处理（缩放 + letterbox + 归一化）
- inferenceMs    模型推理
- totalMs        预处理 + 推理
- 实时/持续案例额外输出：averageModelMs / maxModelMs / minModelMs / fps

原生 ncnn/onnx 仅支持 arm64-v8a；opencv 后端跟随 OpenCV 5.0 支持所有 ABI。
测试时请保证前台画面中有 COCO 数据集可识别目标，例如人、汽车、猫或狗。
