## 2. 铁律（违反会出事）

1. **Lead 独占**：构建、装机、LAN 发布、git 提交。队友/子代理只改代码。
2. **只本地提交，不 push、不建 tag/Release**（用户 2026-10-31 要求；只有明确说「推一次」才推）。
3. **证据制**：任何「已修复/已生效」都要**真机实测或单测**支撑；没验过的写「未验证」；不把未实现写成已实现。
4. **目录规范**：临时产出进 `output/<任务名>-<日期>/`；构建产物进 `.artifacts/<任务名>-<日期>/`；不许裸放 `output/` 根、仓库根、`docs/` 根。自检：`pwsh -File tools\check-dir-hygiene.ps1`（`-Fix` 按规范清理，**清理前确认无构建**）。
5. **红线**：不删 `.artifacts/updates/**`（LAN 更新源）｜不删 `src/test/**`（是源码）｜构建中不删 `build/` 与 `.gradle/8.9/executionHistory`｜**不用目录名正则清 `build`**（会误伤 `com/jdkshen/aijspro/**/build/` 真源码包）｜不往 `C:\Users\18101\Downloads` 写构建产物。

## 7. 踩坑清单（今天真花过时间的）

| 坑 | 正解 |
|---|---|
| Windows PowerShell **5.1** 不支持 `<<<` here-string | 用 `@'...'@` 写文件再 `git commit -F <file>`；本机**没有 PS7**，别用 `$PSNativeCommandUseErrorActionPreference` |
| `tools/build-slim-template.ps1` 中途中止 | gradlew 把提示写 stderr，配合 `$ErrorActionPreference='Stop'` 会被当终止错误 → 先把两处 gradlew 降到 `Continue`（看 `$LASTEXITCODE`）；设了 `JAVA_TOOL_OPTIONS` 时先 `Remove-Item Env:JAVA_TOOL_OPTIONS`；该 ps1 **必须是 UTF-8 with BOM** |
| 打包版跑的是旧引擎 | `template.apk` 是签入的**构建产物**，改 `modules/engine` 或 `apps/inrt` 后必须重建；用 `pwsh -File tools\check-artifact-freshness.ps1 -Deep` 查（出包脚本已内置，STALE 会 throw）|
| Dart 改动「改了但没生效」 | AOT payload 默认复用锁定产物 → 出包加 `-RebuildAot` |
| `:inrt:mergeDexRelease` 报 `classes4.dex 正被占用` | 有人在并发跑 gradle（队友）→ 让队友停手，杀残留 daemon 后重跑；**出包期禁止别人跑 gradle** |
| 测试「假死锁」 | 先清年龄 > 25 分钟的 `GradleWorkerMain` 残留进程（jstack 会显示 BLOCKED）|
| `grep 'C-PKG: ...'` 抓不到日志 | logcat 渲染成 `C-PKG   : `（冒号前有空格）→ 用 `grep 'ocr removed'` 这类关键字 |
| 用 `du -sm` 估 `res/` 大小 | toybox/`du` 对几百个小文件按 4 KB 取整会假高（曾把 2.20 MiB 报成 9 MiB）→ 要精确值用 zip 条目求和 |
| 装不上：`INSTALL_FAILED_CONFLICTING_PROVIDER` | 我们给 VS Code 扩展保留的 `org.autojs.autojspro.debug.provider` 与真 Auto.js Pro 冲突 → 出包加 `-NoUsbDiscovery` |
| MCP 调用静默失败 | K40 的 MCP 会掉线（`mcp=000`）→ 每批真机验证**先探活**再跑 |
