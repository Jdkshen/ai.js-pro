# 无障碍指纹手势

Rhino 和 QuickJS 使用相同接口，监听指纹传感器上的四向滑动。需要 Android 8（API 26）以上、已启用 AIjs Pro 无障碍服务，以及支持手势的指纹硬件和 ROM。有指纹解锁功能不代表支持指纹手势；屏下或侧边传感器是否支持由系统决定。

| 接口 / 事件 | 说明 |
| --- | --- |
| `events.observeFingerprintGesture()` | 请求指纹手势监听；注册成功返回 `true`，Android 8 以下返回 `false`。返回值不代表硬件可用。无障碍未开启时沿用现有引导。 |
| `events.isFingerprintGestureAvailable()` | 当前捕获是否可用；不主动开启无障碍或申请监听。首次开启后系统异步更新状态，应结合状态事件使用。 |
| `events.stopObservingFingerprintGesture()` | 释放当前脚本的监听和保活，不影响其他脚本的订阅。 |
| `fingerprint_gesture` | 回调参数为 `up` / `down` / `left` / `right` 字符串。 |
| `fingerprint_gesture_available` | 回调参数为布尔值；注册时报告初始状态，状态改变时通知。 |

```javascript
auto.waitFor();
events.on("fingerprint_gesture", function (direction) {
    log(direction);
    if (direction === "left") back();
});
events.on("fingerprint_gesture_available", function (available) {
    log("指纹手势可用：" + available);
});
events.observeFingerprintGesture();
```

监听期间脚本保活。脚本停止会自动注销；多个脚本共享捕获请求，最后一个订阅退出时释放。服务断开时报告不可用，重新连接后自动恢复已有订阅。指纹认证/录入期间系统可能暂时暂停手势检测。

该功能独立于屏幕触摸手势 `events.observeGesture()`，不需要开启触摸探索模式，也不需要 root。底层使用 `USE_FINGERPRINT` 普通权限、无障碍指纹能力声明和按需设置的 `FLAG_REQUEST_FINGERPRINT_GESTURES`；仅运行监听脚本时申请捕获。

内置样例：Rhino → 事件与按键、触摸监听 → 指纹手势；QuickJS → 系统与设备 → 指纹手势。

系统依据：[FingerprintGestureController](https://developer.android.com/reference/android/accessibilityservice/FingerprintGestureController)、[Android 无障碍服务开发指南](https://developer.android.com/guide/topics/ui/accessibility/views/service)。
