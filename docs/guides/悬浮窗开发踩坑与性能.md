# 悬浮窗开发踩坑与性能数据（脚本作者视角）

> 来源：`悬浮球2.js`（v25，1 球 + 5 彩球环形菜单）开发过程复盘 + 实测数据，
> 环境：Redmi 2602BRT18C · Android 16 (SDK 36) · 1280×2772 · density 3.25
> 引擎侧对应修复见 `docs/guides/悬浮窗触摸穿透说明.md` 与需求清单「批 E/F」。

## 一、踩坑速查（按现象找原因）

| 现象 | 原因 | 解法 |
|---|---|---|
| `Unable to create floaty window` | `cardCornerRadius="73.5px"` 小数过去解析不了 | **已修**（引擎支持小数）；旧包用 `Math.round()` |
| 窗口巨大 / 内容挤在角落 | `w="300"` 按 **dp**（×3.25 = 975px），`margin="91"` 按 **px** | 数值一律显式带单位：`w="300px"`、`margin="91px"` |
| 左上角闪现 | 创建即上屏，`setPosition` 慢一步 | 用创建配置 `floaty.rawWindow(xml, { x, y })`（visible:false 创建也行） |
| 多个透明卡片叠出“多边形阴影” | `<card>` 只要 `cardElevation > 0`，**背景全透明也投阴影** | XML 加 `cardElevation="0"` |
| 菜单收不回去 | N 个窗口显隐要逐一对齐，任一失败就“半开半合” | 严格配对 `setTouchable(true/false)` + `animating` 锁 + 点中心区也能收起 |
| 触摸回调拿不到坐标 | 回调是**单参数**（QuickJS 风格），Rhino 风格 `function(view, event)` 的第二个参数是 undefined | `node.setOnTouchListener(function (ev) { ev.getAction(); })`；兼容写法见下 |
| 透明方角挡住背后的 App | 窗口输入区域永远是矩形 | 容器窗口 `setTouchable(false)` 整窗穿透 + 菜单项独立小窗口（见触摸穿透说明） |
| 逐帧 `sleep` 做动画很贵 | 主线程逐帧（3 帧 94ms / 6 帧 237ms） | 用 `animate(props, duration, easing)`（调用 6ms，动画交给系统） |

### 触摸回调兼容封装

```js
function bindTouch(node, handler) {
    node.setOnTouchListener(function (a, b) {
        var ev = (b && typeof b.getAction === 'function') ? b : a;   // 兼容 (ev) 与 (view, ev)
        if (!ev || typeof ev.getAction !== 'function') return true;
        try { return handler(ev); } catch (e) { return true; }
    });
}
```

### 防连点

```js
var animating = false;
function showMenu() {
    if (opened || animating) return;
    animating = true;
    // …动画
    setTimeout(function () { animating = false; }, duration + 60);
}
```

### 尺寸自适应（按屏宽比例）

```js
var SW = device.width;
var BALL   = Math.round(SW * 0.13);    // ≈ 166px
var BTN    = Math.round(SW * 0.106);   // ≈ 136px
var R      = Math.round(SW * 0.21);    // ≈ 269px 环形半径
var BALL_R = Math.round(BALL / 2);     // 圆角半径取整（旧包必须）
```

### 环形布局

```js
function slotPos(i, n, ballX, ballY) {
    var deg = -90 + (360 / n) * i;                 // 从正上方开始均匀分布
    var rad = deg * Math.PI / 180;
    var cx = ballX + BALL / 2, cy = ballY + BALL / 2;
    return {
        x: Math.round(cx + R * Math.cos(rad) - BTN / 2),
        y: Math.round(cy + R * Math.sin(rad) - BTN / 2)
    };
}
```

## 二、实测性能数据（Android 16，1280×2772）

| 操作 | 耗时 | 备注 |
|---|---|---|
| `setVisibility` 显隐 | **0ms** | 最廉价，优先用它做开关 |
| `setSize` | **0.03ms** | 可放心高频调用 |
| `setPosition` | 1ms | 同步返回，`getX()` 立即是新值 |
| `setBackgroundColor` | 5–8ms | 需重绘 |
| `rawWindow()` 创建 | **~33ms/个** | 昂贵，**窗口要复用** |
| `sleep(16)` | 实际 16.6ms | 逐帧动画的硬成本 |
| `animate()` 调用 | **6ms** | 非阻塞，动画由系统渲染线程跑 |

结论：**用 `animate()` 替代逐帧 `sleep`**；窗口开合尽量用 `setContentVisible` / `setVisibility`（0ms）而不是销毁重建。

## 三、`animate()` 支持面（本轮已补充）

| 属性 | 支持 |
|---|---|
| `alpha` / `scaleX` / `scaleY` / `x` / `y` / `translationX` / `translationY` / `rotation` | ✅ |
| `scale`（自动拆成 `scaleX` + `scaleY`） | ✅ 本轮新增 |
| `width` / `height` | ❌ 需改布局，用 `setSize` 代替 |

缓动：`linear` / `accelerate` / `decelerate` / `accelerate_decelerate` / `anticipate` / `overshoot` / `anticipate_overshoot` / `bounce` / `cycle`；
**别名**（本轮新增）：`easeIn`→accelerate、`easeOut`→decelerate、`easeInOut`→accelerate_decelerate、`spring`→overshoot。

未知属性/缓动会抛错，错误信息里列出可用项。

## 四、圆形悬浮球的标准写法

```js
var D = 166, R = Math.round(D / 2);
var ball = floaty.window(
    '<card id="c" w="' + D + 'px" h="' + D + 'px" cardCornerRadius="' + R + 'px"'
    + ' cardElevation="0" cardBackgroundColor="#F01E88E5" clipToOutline="true"/>',
    { x: 600, y: 400 });            // 创建即定位，不闪现
ball.setCornerRadius(R);            // 非 XML 场景也可设轮廓
ball.setClipToOutline(true);        // 真圆形裁剪（视觉）
```

> 触摸穿透、`setTouchShape` 等按区域输入的真相与替代方案，见 `悬浮窗触摸穿透说明.md`。
