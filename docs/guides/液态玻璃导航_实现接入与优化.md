# 液态玻璃导航：实现、接入与优化

整理日期：2026-09-14。依据当前工作树实现，以及 dev-584 至 dev-586 的开发与真机验证记录。

本文介绍 AI.js Pro 顶部图标栏的液态玻璃选中胶囊。完整 Java 组件源码附在文末，可以复制到其他 Android 项目；接入本项目时直接使用已有组件。

## 1. 当前效果与实现范围

用户提供的参考视频里，选中胶囊在图标之间滑动，移动中发生拉伸，经过的图标呈现放大和变形。当前实现包含：

- 点击图标切页、滑动页面带动胶囊、直接横向拖动图标栏切页。
- 胶囊跟随页面的连续进度移动，滑到两页中间时拉宽，停到图标上时收拢。
- Android 13 及以上使用 AGSL 对图标栏纹理做局部、非均匀放大，模拟曲面折射。
- 较旧系统使用 BitmapShader 的矩阵缩放，保留移动、拉伸和放大效果。
- 胶囊与底部轨道叠加渐变高光、细边框和下缘阴影，适配浅色、深色与系统跟随。
- 保留 Material TabLayout 的选中状态、普通点击和无障碍描述。

**效果边界：当前采样的是缓存的图标栏，并没有实时采样或模糊后面的整页内容。** 玻璃质感来自图标的局部采样、高光与着色；胶囊内部的快照有固定底色。折射公式属于视觉近似，尚未实现真实光学折射、色散或参考视频的全部细节。

## 3. 实现原理

### 3.1 让 ViewPager 提供唯一的滑动进度

组件继承 `TabLayout`，继续用原有 `ViewPager` 切页。胶囊不单独维护另一套移动动画，而是监听页面进度：

```java
@Override public void onPageScrolled(int position, float offset, int pixels) {
    pagePosition = position + offset;
    postInvalidateOnAnimation();
}
```

例如从第 1 个标签移动到第 2 个标签，`pagePosition` 连续经过 `0 → 0.5 → 1`。内容滑动、图标点击和图标栏拖动，最终都走同一个页面进度，因此胶囊和页面可以同步。

`onPageSelected()` 用于标记选中图标的快照失效；页面进入 `IDLE` 后，再将进度对齐到 `pager.getCurrentItem()`，消除最终位置的小偏差。

### 3.2 计算胶囊位置和拉伸

下面为当前核心公式的摘录，完整上下文见附录：

```java
float position = Math.max(0, Math.min(getTabCount() - 1, pagePosition));
int first = (int) position;
float fraction = position - first;
float center = tabCenter(first)
        + (tabCenter(Math.min(first + 1, getTabCount() - 1)) - tabCenter(first)) * fraction;
float stretch = (float) Math.sin(fraction * Math.PI);
float cell = tabSpacing();
float width = Math.min(track.width(), Math.abs(cell) * (0.66f + 0.30f * stretch));
float height = Math.min(track.height() - dp(4), dp(34 + 4 * stretch));
```

`tabCenter()` 读取标签子 View 的实际中心，而非简单用整个屏幕宽度除以标签数。这样位置计算能考虑标签布局与滚动偏移；间距保留正负号，拖动映射也能使用标签的实际排列方向。

`sin(fraction × π)` 在起点和终点为 0，在两页中间为 1。胶囊静止时宽约为标签中心间距的 66%，中途拉宽到约 96%；高度从 34dp 增长到 38dp，且不超过轨道允许范围。

### 3.3 分层绘制

绘制顺序为：

1. `onDraw()` 绘制圆角轨道、轨道渐变与细边框。
2. `dispatchDraw()` 先调用 `super.dispatchDraw(canvas)`，绘制 TabLayout 原生图标。
3. 在图标上方绘制采样缓存纹理的胶囊，让胶囊范围内的图标显示放大和折射。
4. 叠加胶囊高光、圆角描边与下缘弧线。

胶囊内部使用 `drawRoundRect()` 限定绘制形状。组件没有手工调用 `saveLayer()` 做全栏离屏合成，也没有为胶囊模糊整页内容。

构造时将默认下划线和标签水波纹设为透明，避免它们与玻璃胶囊重复显示。普通点击仍交给 TabLayout 处理。

### 3.4 缓存图标栏，避免每帧重新生成纹理

```java
private void ensureSnapshot() {
    if (tabSnapshot == null) {
        tabSnapshot = Bitmap.createBitmap(getWidth(), getHeight(), Bitmap.Config.ARGB_8888);
        snapshotCanvas = new Canvas(tabSnapshot);
        tabShader = new BitmapShader(tabSnapshot, Shader.TileMode.CLAMP, Shader.TileMode.CLAMP);
        if (Build.VERSION.SDK_INT >= 33) refractionShader = RefractionApi33.create(tabShader);
        snapshotDirty = true;
    }
    if (snapshotDirty) {
        tabSnapshot.eraseColor(lensColor);
        super.dispatchDraw(snapshotCanvas);
        snapshotDirty = false;
    }
}
```

这是一张通过 Canvas 绘制的组件快照，不调用系统截图接口。调用的是 `super.dispatchDraw()`，只绘制标签子内容，避免把本组件已经绘制的胶囊再次画进快照。

位图只在首次需要或尺寸改变后创建；布局、选中状态和主题变化会让快照重新绘制。正常滑动帧复用位图，更新位置、尺寸和 Shader 参数。

### 3.5 Android 13+ 的曲面折射

Android 13 / API 33 起提供 AGSL 和 RuntimeShader。以下是当前 Java 拼接字符串展开后的 Shader，内容与附录中的实现一致。[Android AGSL 说明](https://developer.android.com/develop/ui/views/graphics/agsl)

```glsl
uniform shader tabs;
uniform float2 center;
uniform float2 radius;
uniform float strength;

half4 main(float2 xy) {
    float2 delta = xy - center;
    float2 rim = float2(max(abs(delta.x) - (radius.x - radius.y), 0.0), delta.y);
    float d = clamp(length(rim) / max(radius.y, 1.0), 0.0, 1.0);
    float magnification = 1.02 + strength * (1.0 - d * d);
    return tabs.eval(center + delta / magnification);
}
```

各参数的含义：

| 参数 | 含义 |
| --- | --- |
| `tabs` | 图标栏缓存对应的 BitmapShader |
| `center` | 胶囊中心，单位为当前 View 的像素 |
| `radius` | 胶囊宽、高的一半，单位为像素 |
| `strength` | 放大强度，当前为 `0.08 + 0.40 × stretch` |

`rim` 根据胶囊的直线段和圆弧端部计算归一化距离，`d` 越接近边缘越大。中心附近放大较强，接近边缘时回落到约 1.02 倍，形成非均匀变形。

采样时使用 `center + delta / magnification`：目标像素去读取一个更靠近中心的源像素，于是源图标看起来被放大。当前中心处静止时约 1.10 倍，拉伸最强时约 1.50 倍。

RuntimeShader 只在缓存初始化时创建。每帧调用 `setFloatUniform()` 更新位置、半径和强度，不重新编译 Shader。API 用法见 [RuntimeShader 文档](https://developer.android.com/reference/android/graphics/RuntimeShader)。

### 3.6 较旧系统的矩阵兼容方案

```java
float zoomX = 1.06f + 0.32f * stretch;
float zoomY = 1.06f + 0.16f * stretch;
lensMatrix.setScale(zoomX, zoomY, center, cy);
tabShader.setLocalMatrix(lensMatrix);
lensPaint.setShader(tabShader);
```

矩阵以胶囊中心为缩放中心，水平最多约 1.38 倍、垂直最多约 1.22 倍。这个分支有放大和拉伸，但没有 AGSL 分支的曲面采样变化。

当前项目对 Android 8–12 使用该兼容路径；其视觉效果还未在这些版本的真机上完整验收。较新图形 API 隔离在带 `@RequiresApi(33)` 的内部类中，低版本路径不执行这些调用。

### 3.7 图标栏直接拖动切页

组件先判断横向移动是否超过系统 `touchSlop`，且横向位移是否大于纵向位移。符合条件才拦截，调用 `pager.beginFakeDrag()`；未形成拖动的点击继续交给 TabLayout。

导航栏上一格距离较短，需要映射成 ViewPager 的整页宽度：

```java
pager.fakeDragBy(-(x - lastX) * pager.getWidth() / tabSpacing());
```

例如标签中心间距为 216px、页面宽度为 1080px，手指在图标栏移动 216px，相当于页面移动 1080px。负号来自 fakeDrag 的页面方向约定；标签间距保留符号。[ViewPager fakeDrag API](https://developer.android.com/reference/androidx/viewpager/widget/ViewPager)

松手时先保存最近标签，再结束 fakeDrag：

```java
int nearest = Math.round(pagePosition);
pager.endFakeDrag();
pager.setCurrentItem(nearest, true);
```

这样避免短距离图标栏拖动产生经过放大映射的惯性，导致意外跨过多页。`ACTION_CANCEL`、控件离开窗口和重新绑定 pager 时也会结束手势；多指抬起时切换活动指针并更新 `lastX`，减少坐标跳变。

## 4. 怎么接入与使用

### 4.1 环境条件

需要 Android Views 项目、Material Components 的 TabLayout、AndroidX ViewPager，以及支持 Material 的 Activity 主题。编译 SDK 至少为 33 才能编译 RuntimeShader 代码，本项目使用 35。

本组件绑定的是 `androidx.viewpager.widget.ViewPager`。迁移到 ViewPager2 时，需要替换页面监听、fakeDrag 和标签绑定逻辑，不能直接复用当前绑定方法。

### 4.2 替换 XML 标签

以下为最小接入示例。`app` XML 命名空间需在布局根节点声明：

```xml
<com.jdkshen.aijspro.ui.widget.GlassTabLayout
    android:id="@+id/tab"
    android:layout_width="match_parent"
    android:layout_height="48dp"
    app:tabMode="fixed"
    app:tabGravity="fill" />
```

移植到其他项目时，修改 Java 文件的包名和 XML 类名。本项目保留原来的 `R.id.tab`，因此已有 `findViewById()` 与 TabLayout 接口调用仍可使用。

`48dp` 是当前视觉高度；触摸目标还需结合设备字号、标签数和可用宽度检查。绘制轨道用 10dp 内缩，不需要给 TabLayout 添加同样的横向 padding；此前为轨道增加 padding 曾导致标签位置偏移与末尾图标裁切。

### 4.3 绑定图标和页面

下面是接入流程示例；`adapter`、图标和名称由调用项目提供：

```java
GlassTabLayout tabs = findViewById(R.id.tab);
ViewPager pager = findViewById(R.id.viewpager);

// 若页面依赖实例化回调绑定其他控件，应先注册回调，再设置 adapter。
pager.setAdapter(adapter);
tabs.setupWithViewPager(pager);

for (int i = 0; i < icons.length; i++) {
    TabLayout.Tab tab = tabs.getTabAt(i);
    if (tab != null) {
        tab.setIcon(icons[i]);
        tab.setText(null);
        tab.setContentDescription(titles[i]);
    }
}

tabs.setTabIconTint(new ColorStateList(
        new int[][] { new int[] { android.R.attr.state_selected }, new int[] {} },
        new int[] { 0xFF009688, 0x82000000 }));
tabs.setGlassTheme(false, 0xFFF7F7F7);
```

当前组件重写的是**单参数** `setupWithViewPager(pager)`，接入时使用该入口。不要直接改为调用双参数重载，除非同时补齐该重载中的自定义 pager 绑定与监听逻辑。

实际使用时，点图标可切页；在页面内容上横滑会移动胶囊；直接横向拖动图标栏，松手后会吸附到最近图标。无需启动额外的胶囊 ValueAnimator。

### 4.4 统一浅色、深色与系统跟随

本项目使用有效主题判定，不能只读取手动夜间开关：

```java
boolean dark = AijsMiuixThemeKt.isAijsDarkThemeResolved(this);
int surface = dark ? Color.BLACK : 0xFFF7F7F7;
int normal = dark ? 0xAAFFFFFF : 0x82000000;

tabs.setGlassTheme(dark, surface);
tabs.setTabIconTint(new ColorStateList(
        new int[][] { new int[] { android.R.attr.state_selected }, new int[] {} },
        new int[] { 0xFF009688, normal }));
```

迁移项目需要用自己的主题解析替代 `AijsMiuixThemeKt`。`setGlassTheme()` 只改变这个控件的配色，不会自动修改整个应用的主题模式。

本项目主题模式为：跟随系统启用时用 `MODE_NIGHT_FOLLOW_SYSTEM`，否则根据保存的手动选择用 YES 或 NO。切换后 MainActivity 更新导航、系统栏与原生文件列表。

如果通过 `android:configChanges="uiMode"` 避免主界面重建，需要自行更新原生控件，并让 Compose 接收配置变更。本项目关键代码为：

```java
@Override
public void onConfigurationChanged(Configuration configuration) {
    super.onConfigurationChanged(configuration);
    getWindow().getDecorView().dispatchConfigurationChanged(configuration);
    applyMainNavigationTheme();
    // 本项目还会调用文件页的 onAppThemeChanged()。
}
```

单独添加 `configChanges` 而不补颜色和配置通知，会留下旧颜色；此次测试确实发现过原生导航深色、Compose 顶栏浅色的情况。配置处理方式见 [Android 深色主题说明](https://developer.android.com/develop/ui/views/theming/darktheme)。

## 5. 已经做了哪些优化

| 已实施的措施 | 目的与代价 |
| --- | --- |
| 只缓存图标栏，不采样整屏 | 控制纹理面积；当前没有真实整页背景透视或模糊 |
| 复用 Bitmap、Canvas、Paint、RectF、Matrix 和 Shader | 避免正常滑动帧反复分配这些对象 |
| 快照失效时才重绘 | 布局、尺寸、选中与主题变化刷新；普通帧复用 |
| AGSL 复用程序，每帧只更新 uniform | 避免移动时重复构造和编译 RuntimeShader |
| 渐变在尺寸或主题变化时更新 | 不在 `dispatchDraw()` 中创建 LinearGradient |
| 跟随 ViewPager 连续进度 | 减少两套动画不同步的问题 |
| 使用 `postInvalidateOnAnimation()` | 将重绘请求安排到动画帧，而非忙循环绘制 |
| 松手吸附最近图标 | 避免导航手势的放大速度导致过度跨页 |
| 主界面原位更新主题 | 避免每次深浅切换重建五个已缓存页面 |
| 页面预加载、保留列表状态与已加载数据 | 减少切页时的页面创建；增加驻留内存，需按页面复杂度取舍 |

图标栏快照的 ARGB_8888 像素内存约为 `宽 × 高 × 4` 字节。例如 1080px × 132px 约为 570,240 字节，即 0.54MiB；这不包含 View 对象、图形驱动和可能的 GPU 资源开销。

当前 `releaseSnapshot()` 清除引用，不主动对旧纹理调用 `Bitmap.recycle()`，让仍可能持有该纹理的渲染线程安全释放资源。

## 6. 怎么继续优化

以下是后续建议，**尚未全部落到当前代码或完成测试**。

### 6.1 先测帧耗时，再决定优化目标

区分三种现象：首次触摸卡顿、持续拖动掉帧、主题切换延迟。分别检查纹理首次创建、每帧绘制/页面工作量、页面重建与批量主题重组。

使用 Android Studio Profiler 或 Perfetto 查看主线程、RenderThread、GC 和帧时间；`dumpsys gfxinfo` 可作为重复拖动测试的辅助统计入口：[Android 慢渲染排查](https://developer.android.com/topic/performance/vitals/render)。

```powershell
$adbExe = 'C:\Android\platform-tools\adb.exe'
& $adbExe -s ce4d2bdb shell dumpsys gfxinfo com.jdkshen.aijspro reset
# 真机重复执行图标栏拖动、内容横滑和点击。
& $adbExe -s ce4d2bdb shell dumpsys gfxinfo com.jdkshen.aijspro framestats
```

设备号需换成自己的测试机。60 / 90 / 120Hz 的刷新周期分别约为 16.67 / 11.11 / 8.33ms；这是预算参考，不代表本组件已测到相应帧率。此前 333–479ms 是整次主题切换测试的等待和检查耗时，不是每帧耗时。

### 6.2 收紧快照刷新条件

当前每次 `onLayout()` 都标记失效，易于保证正确性，但可能在内容未变化时重绘快照。后续可比较布局边界、图标内容和 tint 是否真的改变，再置脏；同时补一个公开的刷新入口给动态图标使用。

建议新增 API 示例，当前完整类尚无此方法：

```java
public void invalidateTabSnapshot() {
    dirtySnapshot();
}
```

动态调用 `tab.setIcon()` 或更新颜色后可显式刷新。收紧刷新条件前应覆盖选中态、动态资源、字号和旋转，避免把性能优化变成快照过期。

### 6.3 补图形能力降级

当前按 API 版本选择 AGSL，尚未额外处理 Shader 构造失败和软件 Canvas 场景。后续可以在创建 RuntimeShader 时捕获该步骤的异常，并在非硬件加速绘制时选择矩阵路径，保证基础导航仍能工作。

不要在每一帧反复尝试创建已失败的 Shader；记录能力检测结果，在尺寸或绑定重新初始化时有条件重试。当前本项目主界面已开启硬件加速。

### 6.4 调参先从观感入手

| 当前参数 | 调整方向 |
| --- | --- |
| 宽度 `0.66 + 0.30 × stretch` | 减小 0.30，可减少中途横向拉伸 |
| 高度 `34 + 4 × stretch` dp | 减小 4，可减少垂直膨胀 |
| AGSL 强度 `0.08 + 0.40 × stretch` | 减小 0.40，可减少图标变形和放大 |
| 矩阵水平 `1.06 + 0.32 × stretch` | 控制旧系统水平放大 |
| 矩阵垂直 `1.06 + 0.16 × stretch` | 控制旧系统垂直放大 |
| 描边 0.8dp、下缘弧线 0.5dp | 控制边缘明暗与厚度 |

例如把 AGSL 强度改为 `0.08 + 0.24 × stretch`，中途中心放大约降到 1.34 倍。**减小强度主要改善观感，并不会自动减少这段 Shader 的固定运算量。** 真正的性能改善仍要来自减少分配、采样、过度绘制或页面工作。

### 6.5 再考虑更复杂的玻璃效果

真实背景模糊需要额外的背景来源与模糊处理；色散通常增加通道采样，更多高光和阴影也会增加绘制成本。建议先在小范围胶囊上验证，再评估不同设备上的帧耗时，保留关闭重效果的路径。

如果要增加弹簧回弹，优先只让胶囊的尺寸、折射强度或装饰偏移产生短暂回弹，页面位置继续来自 ViewPager，避免页面和选中位置分离。当前还没有速度驱动的液体惯性或弹簧尾巴。

### 6.6 补重挂载、RTL 与多指测试

当前离开窗口会结束 fakeDrag 和释放纹理，但没有在该回调中额外解绑自定义 pageListener。长期保留 pager、反复移除/挂载标签栏的项目，应补成对的解绑与重绑，并防止重复注册。

当前读取实际标签中心与带符号间距，但还需实测 RTL、多指、父容器拦截、窗口切换，以及少量/较多标签。当前产品验证集中在五个固定图标；不等宽标签、可滚动标签和 ViewPager2 不属于已经验收的范围。

```java
package com.jdkshen.aijspro.ui.widget;

import android.content.Context;
import android.content.res.ColorStateList;
import android.graphics.Bitmap;
import android.graphics.BitmapShader;
import android.graphics.Canvas;
import android.graphics.Color;
import android.graphics.LinearGradient;
import android.graphics.Matrix;
import android.graphics.Paint;
import android.graphics.RectF;
import android.graphics.Shader;
import android.graphics.drawable.ColorDrawable;
import android.os.Build;
import android.util.AttributeSet;
import android.view.MotionEvent;
import android.view.View;
import android.view.ViewConfiguration;
import android.view.ViewGroup;

import androidx.annotation.Nullable;
import androidx.viewpager.widget.ViewPager;

import com.google.android.material.tabs.TabLayout;

/** Native tabs with a moving glass lens; the pager remains the source of selection. */
public class GlassTabLayout extends TabLayout {
    private final Paint paint = new Paint(Paint.ANTI_ALIAS_FLAG);
    private final Paint lensPaint = new Paint(Paint.ANTI_ALIAS_FLAG | Paint.FILTER_BITMAP_FLAG);
    private final RectF track = new RectF();
    private final RectF lens = new RectF();
    private final Matrix lensMatrix = new Matrix();
    private final int touchSlop;
    private final float density;
    private Bitmap tabSnapshot;
    private Canvas snapshotCanvas;
    private BitmapShader tabShader;
    private Shader refractionShader;
    private Shader trackHighlight;
    private Shader lensHighlight;
    private boolean snapshotDirty = true;
    private boolean dark;
    private int trackColor = Color.rgb(253, 253, 253);
    private int lensColor = Color.rgb(225, 236, 232);
    private float pagePosition;
    private int pagerState = ViewPager.SCROLL_STATE_IDLE;
    private ViewPager pager;
    private boolean draggingTabs;
    private float downX;
    private float downY;
    private float lastX;
    private int pointerId = -1;

    private final ViewPager.OnPageChangeListener pageListener = new ViewPager.SimpleOnPageChangeListener() {
        @Override public void onPageScrolled(int position, float offset, int pixels) {
            pagePosition = position + offset;
            postInvalidateOnAnimation();
        }

        @Override public void onPageSelected(int position) {
            snapshotDirty = true;
            if (pagerState == ViewPager.SCROLL_STATE_IDLE) pagePosition = position;
            postInvalidateOnAnimation();
        }

        @Override public void onPageScrollStateChanged(int state) {
            pagerState = state;
            if (state == ViewPager.SCROLL_STATE_IDLE && pager != null) {
                pagePosition = pager.getCurrentItem();
                snapshotDirty = true;
            }
            postInvalidateOnAnimation();
        }
    };

    public GlassTabLayout(Context context) { this(context, null); }

    public GlassTabLayout(Context context, AttributeSet attrs) {
        super(context, attrs);
        density = getResources().getDisplayMetrics().density;
        touchSlop = ViewConfiguration.get(context).getScaledTouchSlop();
        setSelectedTabIndicator(new ColorDrawable(Color.TRANSPARENT));
        setSelectedTabIndicatorHeight(0);
        setTabRippleColor(ColorStateList.valueOf(Color.TRANSPARENT));
        addOnTabSelectedListener(new OnTabSelectedListener() {
            @Override public void onTabSelected(Tab tab) { dirtySnapshot(); }
            @Override public void onTabUnselected(Tab tab) { dirtySnapshot(); }
            @Override public void onTabReselected(Tab tab) { dirtySnapshot(); }
        });
    }

    /** Colors use the same resolved light/dark mode as the Compose toolbar. */
    public void setGlassTheme(boolean dark, int surface) {
        this.dark = dark;
        trackColor = dark ? Color.rgb(22, 25, 27) : Color.rgb(253, 253, 253);
        lensColor = dark ? Color.rgb(44, 58, 56) : Color.rgb(225, 236, 232);
        setBackgroundColor(surface);
        updateHighlights();
        dirtySnapshot();
    }

    @Override public void setupWithViewPager(@Nullable ViewPager viewPager) {
        finishTabDrag();
        if (pager != null) pager.removeOnPageChangeListener(pageListener);
        super.setupWithViewPager(viewPager);
        pager = viewPager;
        if (pager != null) {
            pagePosition = pager.getCurrentItem();
            pager.addOnPageChangeListener(pageListener);
        }
        dirtySnapshot();
    }

    @Override protected void onSizeChanged(int w, int h, int oldw, int oldh) {
        super.onSizeChanged(w, h, oldw, oldh);
        releaseSnapshot();
        track.set(dp(10), dp(3), w - dp(10), h - dp(3));
        updateHighlights();
    }

    @Override protected void onLayout(boolean changed, int l, int t, int r, int b) {
        super.onLayout(changed, l, t, r, b);
        snapshotDirty = true;
    }

    @Override protected void onDraw(Canvas canvas) {
        super.onDraw(canvas);
        if (paint == null || track.isEmpty()) return;
        paint.setStyle(Paint.Style.FILL);
        paint.setShader(null);
        paint.setColor(trackColor);
        canvas.drawRoundRect(track, track.height() / 2, track.height() / 2, paint);
        paint.setShader(trackHighlight);
        canvas.drawRoundRect(track, track.height() / 2, track.height() / 2, paint);
        paint.setShader(null);
        paint.setStyle(Paint.Style.STROKE);
        paint.setStrokeWidth(dp(0.6f));
        paint.setColor(dark ? 0x24FFFFFF : 0xFFFFFFFF);
        canvas.drawRoundRect(track, track.height() / 2, track.height() / 2, paint);
        paint.setStyle(Paint.Style.FILL);
    }

    @Override protected void dispatchDraw(Canvas canvas) {
        super.dispatchDraw(canvas);
        if (paint == null || getTabCount() == 0 || getWidth() == 0 || getHeight() == 0) return;
        ensureSnapshot();
        if (tabShader == null) return;

        float position = Math.max(0, Math.min(getTabCount() - 1, pagePosition));
        int first = (int) position;
        float fraction = position - first;
        float center = tabCenter(first) + (tabCenter(Math.min(first + 1, getTabCount() - 1))
                - tabCenter(first)) * fraction;
        float stretch = (float) Math.sin(fraction * Math.PI);
        float cell = tabSpacing();
        float width = Math.min(track.width(), Math.abs(cell) * (0.66f + 0.30f * stretch));
        float height = Math.min(track.height() - dp(4), dp(34 + 4 * stretch));
        float cy = getHeight() / 2f;
        lens.set(center - width / 2, cy - height / 2, center + width / 2, cy + height / 2);

        // A cached, small tab-strip texture is sampled through the lens. Only its
        // matrix changes per frame: no screenshot, bitmap allocation or blur pass.
        float zoomX = 1.06f + 0.32f * stretch;
        float zoomY = 1.06f + 0.16f * stretch;
        if (refractionShader != null && Build.VERSION.SDK_INT >= 33) {
            RefractionApi33.update(refractionShader, center, cy, width / 2, height / 2,
                    0.08f + 0.40f * stretch);
            lensPaint.setShader(refractionShader);
        } else {
            lensMatrix.setScale(zoomX, zoomY, center, cy);
            tabShader.setLocalMatrix(lensMatrix);
            lensPaint.setShader(tabShader);
        }
        canvas.drawRoundRect(lens, height / 2, height / 2, lensPaint);

        paint.setShader(lensHighlight);
        paint.setStyle(Paint.Style.FILL);
        canvas.drawRoundRect(lens, height / 2, height / 2, paint);
        paint.setShader(null);
        paint.setStyle(Paint.Style.STROKE);
        paint.setStrokeWidth(dp(0.8f));
        paint.setColor(dark ? 0x58FFFFFF : 0xDBFFFFFF);
        canvas.drawRoundRect(lens, height / 2, height / 2, paint);
        // A soft lower rim and brighter upper rim suggest curved glass edges.
        paint.setStrokeWidth(dp(0.5f));
        paint.setColor(dark ? 0x35000000 : 0x18005447);
        canvas.drawArc(lens, 20, 140, false, paint);
        paint.setStyle(Paint.Style.FILL);
    }

    private void ensureSnapshot() {
        if (tabSnapshot == null) {
            tabSnapshot = Bitmap.createBitmap(getWidth(), getHeight(), Bitmap.Config.ARGB_8888);
            snapshotCanvas = new Canvas(tabSnapshot);
            tabShader = new BitmapShader(tabSnapshot, Shader.TileMode.CLAMP, Shader.TileMode.CLAMP);
            if (Build.VERSION.SDK_INT >= 33) refractionShader = RefractionApi33.create(tabShader);
            snapshotDirty = true;
        }
        if (snapshotDirty) {
            tabSnapshot.eraseColor(lensColor);
            super.dispatchDraw(snapshotCanvas);
            snapshotDirty = false;
        }
    }

    private void updateHighlights() {
        if (getHeight() == 0) return;
        trackHighlight = new LinearGradient(0, 0, 0, getHeight(),
                dark ? new int[] {0x15FFFFFF, 0x00FFFFFF, 0x08FFFFFF}
                        : new int[] {0x90FFFFFF, 0x00FFFFFF, 0x38D4E2DF},
                new float[] {0, 0.55f, 1}, Shader.TileMode.CLAMP);
        lensHighlight = new LinearGradient(0, dp(6), 0, getHeight() - dp(6),
                dark ? new int[] {0x26FFFFFF, 0x00FFFFFF, 0x0CFFFFFF}
                        : new int[] {0x72FFFFFF, 0x00FFFFFF, 0x24FFFFFF},
                new float[] {0, 0.55f, 1}, Shader.TileMode.CLAMP);
    }

    private float tabCenter(int index) {
        ViewGroup strip = getChildCount() > 0 ? (ViewGroup) getChildAt(0) : null;
        View tab = strip != null && index < strip.getChildCount() ? strip.getChildAt(index) : null;
        return tab == null ? getWidth() / 2f
                : strip.getLeft() + tab.getLeft() + tab.getWidth() / 2f - getScrollX();
    }

    private float tabSpacing() {
        return getTabCount() > 1 ? tabCenter(1) - tabCenter(0) : track.width();
    }

    @Override public boolean onInterceptTouchEvent(MotionEvent event) {
        if (event.getActionMasked() == MotionEvent.ACTION_DOWN) {
            downX = lastX = event.getX();
            downY = event.getY();
            pointerId = event.getPointerId(0);
        } else if (event.getActionMasked() == MotionEvent.ACTION_MOVE && !draggingTabs) {
            int index = event.findPointerIndex(pointerId);
            if (index >= 0 && pager != null && Math.abs(tabSpacing()) > 1) {
                float dx = event.getX(index) - downX;
                float dy = event.getY(index) - downY;
                if (Math.abs(dx) > touchSlop && Math.abs(dx) > Math.abs(dy)
                        && pager.beginFakeDrag()) {
                    draggingTabs = true;
                    getParent().requestDisallowInterceptTouchEvent(true);
                }
            }
        } else if (event.getActionMasked() == MotionEvent.ACTION_CANCEL
                || event.getActionMasked() == MotionEvent.ACTION_UP) {
            if (!draggingTabs) pointerId = -1;
        }
        return draggingTabs;
    }

    @Override public boolean onTouchEvent(MotionEvent event) {
        if (!draggingTabs) return super.onTouchEvent(event);
        int action = event.getActionMasked();
        if (action == MotionEvent.ACTION_MOVE) {
            int index = event.findPointerIndex(pointerId);
            if (index < 0 || pager == null || !pager.isFakeDragging()) {
                finishTabDrag();
                return true;
            }
            float x = event.getX(index);
            pager.fakeDragBy(-(x - lastX) * pager.getWidth() / tabSpacing());
            lastX = x;
        } else if (action == MotionEvent.ACTION_POINTER_UP) {
            int lifted = event.getActionIndex();
            if (event.getPointerId(lifted) == pointerId) {
                int next = lifted == 0 ? 1 : 0;
                pointerId = event.getPointerId(next);
                lastX = event.getX(next);
            }
        } else if (action == MotionEvent.ACTION_UP || action == MotionEvent.ACTION_CANCEL) {
            finishTabDrag();
        }
        return true;
    }

    private void finishTabDrag() {
        if (draggingTabs && pager != null && pager.isFakeDragging()) {
            int nearest = Math.round(pagePosition);
            pager.endFakeDrag();
            // The navigation lens snaps to the closest icon. Do not apply the
            // amplified full-page fling velocity to this short tab-bar gesture.
            pager.setCurrentItem(nearest, true);
        }
        draggingTabs = false;
        pointerId = -1;
        if (getParent() != null) getParent().requestDisallowInterceptTouchEvent(false);
    }

    @Override protected void onDetachedFromWindow() {
        finishTabDrag();
        releaseSnapshot();
        super.onDetachedFromWindow();
    }

    private void releaseSnapshot() {
        // Let the render thread release any reference to the old bitmap safely.
        tabSnapshot = null;
        snapshotCanvas = null;
        tabShader = null;
        refractionShader = null;
        if (lensPaint != null) lensPaint.setShader(null);
        snapshotDirty = true;
    }

    private void dirtySnapshot() { snapshotDirty = true; postInvalidateOnAnimation(); }
    private float dp(float value) { return value * density; }

    /** Isolate newer graphics APIs so Android 8–12 can use the matrix lens. */
    @androidx.annotation.RequiresApi(33)
    private static class RefractionApi33 {
        static Shader create(BitmapShader tabs) {
            android.graphics.RuntimeShader shader = new android.graphics.RuntimeShader(
                    "uniform shader tabs;\n"
                    + "uniform float2 center;\n"
                    + "uniform float2 radius;\n"
                    + "uniform float strength;\n"
                    + "half4 main(float2 xy) {\n"
                    + "  float2 delta = xy - center;\n"
                    + "  float2 rim = float2(max(abs(delta.x) - (radius.x - radius.y), 0.0), delta.y);\n"
                    + "  float d = clamp(length(rim) / max(radius.y, 1.0), 0.0, 1.0);\n"
                    + "  float magnification = 1.02 + strength * (1.0 - d * d);\n"
                    + "  return tabs.eval(center + delta / magnification);\n"
                    + "}\n");
            shader.setInputShader("tabs", tabs);
            return shader;
        }

        static void update(Shader shader, float cx, float cy, float rx, float ry, float strength) {
            android.graphics.RuntimeShader runtime = (android.graphics.RuntimeShader) shader;
            runtime.setFloatUniform("center", cx, cy);
            runtime.setFloatUniform("radius", rx, ry);
            runtime.setFloatUniform("strength", strength);
        }
    }
}
```
