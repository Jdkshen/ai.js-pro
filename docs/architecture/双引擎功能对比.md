# 双引擎功能对比（Rhino / QuickJS）

> 更新日期：2026-09-11 ｜ 依据：Mi8 上 `list_engine_api` 实测（Rhino 225 项 / QuickJS 245 项 / 缺 4 项，见 `.artifacts/engine-api/engine-api-diff.json`）与源码实现
> 变更：P0（选择器 / UiObject、setScreenMetrics）、P1（顶层别名、`random/sync/auto/print/err`、应用快捷别名、选择器动作全局形式）、P1b（`gesture/gestures`、`input`、RootShell 按键助手）与 P2（`crypto`/`zips`/`util`/`automator`/`context`/`rawInput`/`sqlite` + 运行时状态全局、控制台浮窗 `openConsole`/`clearConsole`、`io`/`files.open`、选择器 `filter`/`addFilter`/`findAndReturnList`（Java → JS 同步回调）、`web`/`newInjectableWebView`/`newInjectableWebClient` 与 `continuation`、跨线程 JS 回调通路）已上线：QuickJS 全局 61 → 222，缺口 173 → 14。
> Java 互操作（用户拍板与 Rhino 对齐）：`Packages`/`importClass`/`importPackage`/`Java.type` + 类与实例句柄（静态/实例方法、字段、JavaBean 属性、重载解析、值转换与异常映射），并把 Rhino 预导入的 `Intent`/`Paint`/`Shell`/`KeyEvent`/`MutableOkHttp`/`Canvas`/`Image`/`RootAutomator`/`Input`/`Module` 一并补齐：QuickJS 全局 222 → 245，缺口 14 → 4。
> 悬浮窗 / UI 打磨：控件代理支持任意属性 `attr(name[, value])` 与属性式读写、`click()/click(fn)` 双形态、`on("click"/"long_click"/"key"/"touch")`、窗口 `getWidth/getHeight/findView`、不存在的控件 id 返回 undefined；`ui` 补齐 `ui.<id>`/`$ui.<id>` 代理、`ui.emitter`、`ui.findView`、`ui.layoutFile`、`ui.post`、`ui.isUiThread`、`ui.statusBarColor`。
> OpenCV 图色对齐：新增帧↔`org.opencv.core.Mat` 双向桥（`images.toMat`/`images.matToImage`）+ `images.opencv` 类映射（Mat/Core/Imgproc/CvType/Scalar/Size/Point/Rect/Bitmap/BitmapFactory），补齐 `inRange`/`interval`/`adaptiveThreshold`/`gaussianBlur`/`medianBlur`/`findAllPointsForColor`/`toBytes`/`fromBytes`/`readPixels`；`images` 成员 42 项 ⊇ Rhino 39 项（仅 Rhino 内部 `opencvImporter` 不适用），回归 177 → **184 项全绿**（Mi8 / Android 15）。
> 普通 `.js` 走 Rhino 1.7.7.2；首行 `// @engine quickjs` 走 QuickJS（libquickjs.so）

## 4. 主要差距（QuickJS 待补，剩 4 项）

> 按 2026-09-11 Mi8 实测差异归并；逐项清单见 `.artifacts/engine-api/engine-api-diff.json` 的 `onlyRhino`。

| 缺口 | 优先级 | 说明 |

## 5. 如何验证当前支持面

MCP 工具（需运行授权）：
```
list_engine_api {engine: "quickjs"|"rhino"}   # 枚举全局 API
probe_engine_api {engine: "rhino", name: "app"}  # 探测类型与成员
```

一次拿到差异表：

```powershell
.\tools\compare-engine-api.ps1 -Device <serial>   # 产物 .artifacts/engine-api/engine-api-diff.json
```

> PowerShell 5.1 的 HTTP 栈会给请求带上 `Expect: 100-continue`，而这个轻量 HTTP 服务按协议直接回 `417 Expectation Failed`（见 `McpHttpServer.serve`）；脚本改用系统自带 `curl.exe` 并显式 `-H "Expect:"` 去掉该头，会话内与子进程都能跑。
