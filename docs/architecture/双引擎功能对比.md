# 双引擎功能对比（Rhino / QuickJS）

> 更新日期：2026-09-11 ｜ 依据：Mi8 上 `list_engine_api` 实测（Rhino 225 项 / QuickJS 61 项，见 `.artifacts/engine-api/engine-api-diff.json`）与源码实现
> 普通 `.js` 走 Rhino 1.7.7.2；首行 `// @engine quickjs` 走 QuickJS（libquickjs.so）

## 1. 总览

| 功能 | Rhino 引擎 | QuickJS 引擎 |
|------|------------|--------------|
| 悬浮窗 | ✅ 完整支持（XML 布局窗口、rawWindow、多控件、可拖动） | ✅ 支持（XML 布局/文本、控件代理、触摸/按键监听、焦点与调整模式、onClose/exitOnClose） |
| JSX 语法 | ✅ 支持 | ❌ 不支持 |
| 拖动功能 | ✅ 流畅 | ✅ 悬浮窗支持拖动 |
| 点击菜单 | ✅ 完整 | ⚠️ 使用对话框替代 |
| UI 界面（ui / $ui） | ✅ 完整（`ui.*`，XML 布局 + 事件 + attr） | ✅ XML 布局完整控件 + click 回调 view 参数 + list/grid setDataSource + item_click/item_long_click |
| 模块系统 | ✅ CommonJS require | ✅ CommonJS require（内置模块） |
| 稳定性 | ✅ 成熟稳定 | ⚠️ 开发中（持续对齐 Auto.js Pro） |

## 2. 模块级详细对比

| 模块 | Rhino | QuickJS | QuickJS 说明 |
|------|-------|---------|--------------|
| `ui` / `$ui` | ✅ 完整 | ✅ XML 布局完整控件 | DynamicLayoutInflater（TextView/EditText/ImageView/LinearLayout/FrameLayout/Toolbar/Spinner/TabLayout/DatePicker/RadioGroup/ProgressBar/TimePicker/AppBar + list/grid）+ click 回调 view 参数 + item_click/item_long_click + attr（轮询队列） |
| `floaty` | ✅ 完整 | ✅ 支持 XML/文本 | `window(xmlOrConfig)`/`rawWindow`/`closeAll` + `window.<id>` 控件代理（click/longClick/on/onKey/getText/setText/setVisibility/setOnTouchListener/requestFocus）+ 窗口级 setSize/setPosition/getX/getY/setText/setBackgroundColor/setTouchable/setAdjustEnabled/isAdjustEnabled/requestFocus/disableFocus/close + onClose 回调 + exitOnClose()（close 时退出脚本，与 Rhino 一致） |
| `threads` | ✅ 完整 | ✅ 常用能力 | 独立 QuickJS worker、JSON 参数、`getResult`/`waitForResult`、`join`/`interrupt`；跨 worker 事件总线待补 |
| `events` | ✅ 完整 | ✅ | 事件总线 |
| `sensors` | ✅ 完整 | ✅ 对齐 | register/unregister/list/Delay；`change` 带完整数据、`accuracy`/`accuracy_change` 事件；不支持的传感器返回 null（`ignoresUnsupportedSensor=true` 时返回 noop） |
| `media` | ✅ 完整 | ✅ 对齐 | 音量 getVolume/getMaxVolume/setVolume + playMusic/stopMusic/pauseMusic/resumeMusic/musicSeekTo/getMusicDuration/getMusicCurrentPosition/scanFile |
| `events` | ✅ 完整（EventEmitter + 系统观察） | ✅ 常用观察已接入 | EventEmitter 全量；`observeKey/Touch/Notification/Toast/Gesture`、`onKeyDown/onKeyUp`；系统回调通过有界队列回到 QuickJS 引擎线程 |
| `images` | ✅ OpenCV 全套 | ⚠️ 基础 | fromBase64/toBase64/concat/load + 图色查找 |
| 图色（findColor/findImage 等） | ✅ 完整 | ✅ | captureScreen/findColor/findImage/findMultiColors/findColorInRegion 等 |
| `http` | ✅ 完整 | ✅ | 网络请求 |
| `storages` | ✅ 完整 | ✅ | 本地存储（含 LocalStorage） |
| `files` | ✅ 完整 | ✅ | 文件读写 |
| `shell` | ✅ 完整 | ✅ | Shell 执行 |
| `shizuku` | ❌ | ✅ | QuickJS 原生注入 |
| `drawing` | ❌ | ✅ | QuickJS 原生注入（画布/绘制） |
| `performance` | ❌ | ✅ | QuickJS 原生注入 |
| `notifications` | ✅ | ✅ | 通知（QuickJS 原生注入；Rhino 原生完整） |
| `quickSettings` | ✅ | ✅ | 快捷设置 |
| `yolo` | ✅ | ✅ | YOLO 推理（两引擎均可） |
| `NativeFrame` / `YoloDetector` | ❌ | ✅ | QuickJS 专用 C++ 原生帧/检测器接口 |
| `RootAutomator` | ✅ 完整（原生 Java 注入） | ⚠️ | 简化版（click/longClick/back/press/swipe 等） |
| 控件选择器 / UiObject | ✅ 完整（`text/id/desc/className/bounds` 构造器 + `find/waitFor/untilFind` + 控件属性与动作） | ❌ 未实现 | QuickJS 没有任何选择器入口；`require` 也只读磁盘 `.js`，取不到 Rhino 的内置 `__selector__.js` |
| `gesture` / `input` / 按键常量 | ✅ | ❌ | 多指手势、`input("文字")`、`KeyCode/KeyEvent/Tap/Swipe/Menu/Back/Power/Volume*` 等常量对象未迁移（`keys` 已可用） |
| `setScreenMetrics` | ✅ | ❌ | 多分辨率坐标适配缺失 |
| 内置模块（`web`/`zips`/`sqlite`/`crypto`/`util`/`io`/`plugins`） | ✅ | ❌ | Rhino 侧为 `assets/modules/__*.js`；QuickJS 的 `require` 没有内置模块解析 |
| 调试器（Dim 断点/单步/变量） | ✅ | ❌ | 仅 Rhino 实现 |
| `engines` / `runtime` / `global` | ✅ | ✅ | 引擎管理、运行时、全局对象 |
| `require`（CommonJS） | ✅ | ✅ | 内置模块解析 |
| AP 打包 | ✅（项目级） | ✅（项目级） | 由 App 打包链路提供，非引擎差异 |

## 3. QuickJS 已注册全局 API（61 项实测）

`$ui`、`LocalStorage`、`NativeFrame`、`YoloDetector`、`app`、`back`、`captureScreen`、`clearInterval`、`clearTimeout`、`click`、`colors`、`console`、`currentActivity`、`currentPackage`、`device`、`dialogs`、`drawing`、`engines`、`events`、`exit`、`files`、`findColor`、`findColorEquals`、`findColorInRegion`、`findImage`、`findImageInRegion`、`findMultiColors`、`floaty`、`getClip`、`global`、`home`、`http`、`images`、`keys`、`log`、`longClick`、`media`、`notifications`、`performance`、`press`、`quickSettings`、`recents`、`requestScreenCapture`、`require`、`runtime`、`sensors`、`setClip`、`setInterval`、`setTimeout`、`shell`、`shizuku`、`sleep`、`storages`、`swipe`、`threads`、`toast`、`toastLog`、`ui`、`yolo`

`require` 只按脚本相对路径加载**磁盘**上的 `.js`，不解析 Rhino 侧的内置模块（`assets/modules/__*.js`），所以 `require('selector')` 这类写法在 QuickJS 里拿不到东西。

## 4. 主要差距（QuickJS 待补）

> 按 2026-09-11 Mi8 实测差异（Rhino 独有 173 项）归并；逐项清单见 `.artifacts/engine-api/engine-api-diff.json` 的 `onlyRhino`。

| 缺口 | 优先级 | 说明 |
|------|--------|------|
| **控件选择器 / UiObject 体系** | 高 | `text/desc/id/className/packageName/bounds*` 构造器、`find/findOne/findOnce/findOf/exists/untilFind/waitFor/waitForActivity/waitForPackage`、控件的 `click/setText/scroll*/copy/cut/paste/bounds/depth/row/column/...` 属性与动作、`accessibilityFocus` 全缺。这是 Auto.js 4.x 无障碍自动化脚本的主体，缺它现有脚本几乎无法迁移 |
| `setScreenMetrics` / `SetScreenMetrics` | 高 | 多分辨率坐标适配 |
| Java 互操作（`importClass`/`Java.type` 任意反射） | 高（设计边界） | QuickJS 有意采用白名单桥接，不提供 Rhino 式任意反射；需先定正式兼容边界 |
| 顶层兼容函数 | 中 | `alert/confirm/prompt/select`（QuickJS 只在 `dialogs.*` 下）、`random(min,max)`、`sync()`、`auto.waitFor()`、`print`、`err`、`openConsole/clearConsole/addFilter`、`setImmediate/clearImmediate` |
| `gesture`/`gestures`/`gestureAsync`、`input`、按键常量 | 中 | 多指手势与文本输入；`KeyCode/KeyEvent/Tap/Swipe/Menu/Back/Home/Power/Volume*` 常量对象 |
| `web`/`zips`/`sqlite`/`crypto`/`util`/`io`/`plugins`、`Screencap`/`Image`/`Canvas`/`Paint`、`context` | 中 | 模块级未迁移 |
| `debugger`（断点/单步/变量） | 中 | 现有 Dim 调试器仅 Rhino |
| JSX / JSX 编译 | 中 | 语法层，短期不做 |
| UI 动态绑定（{{item.name}}） | 中 | 项目级 inflater 未实现绑定解析，Rhino 同样受限 |

## 5. 如何验证当前支持面

MCP 工具（需运行授权）：
```
list_engine_api {engine: "quickjs"|"rhino"}   # 枚举全局 API
probe_engine_api {engine: "rhino", name: "app"}  # 探测类型与成员
```

一次拿到差异表：

```powershell
.\tools\compare-engine-api.ps1 -Device <serial>   # 产物 .artifacts/engine-api/engine-api-diff.json
```

> PowerShell 5.1 的 HTTP 栈会给请求带上 `Expect: 100-continue`，而这个轻量 HTTP 服务按协议直接回 `417 Expectation Failed`（见 `McpHttpServer.serve`）；脚本改用系统自带 `curl.exe` 并显式 `-H "Expect:"` 去掉该头，会话内与子进程都能跑。
