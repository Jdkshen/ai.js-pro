# 双引擎功能对比（Rhino / QuickJS）

> 更新日期：2026-09-11 ｜ 依据：Mi8 上 `list_engine_api` 实测（Rhino 225 项 / QuickJS 126 项 / 缺 108 项，见 `.artifacts/engine-api/engine-api-diff.json`）与源码实现
> 变更：选择器 / UiObject 桥已上线（复用 `modules/automator` 的 UiGlobalSelector/UiObject，含 find/waitFor/untilFind 与控件动作），QuickJS 全局从 61 项增到 126 项。
> 普通 `.js` 走 Rhino 1.7.7.2；首行 `// @engine quickjs` 走 QuickJS（libquickjs.so）

## 1. 总览

| 功能 | Rhino 引擎 | QuickJS 引擎 |
|------|------------|--------------|
| 悬浮窗 | ✅ 完整支持（XML 布局窗口、rawWindow、多控件、可拖动） | ✅ 支持（XML 布局/文本、控件代理、触摸/按键监听、焦点与调整模式、onClose/exitOnClose） |
| JSX 语法 | ✅ 支持 | ❌ 不支持 |
| 拖动功能 | ✅ 流畅 | ✅ 悬浮窗支持拖动 |
| 点击菜单 | ✅ 完整 | ⚠️ 使用对话框替代 |
| UI 界面（ui / $ui） | ✅ 完整（`ui.*`，XML 布局 + 事件 + attr） | ✅ XML 布局完整控件 + click 回调 view 参数 + list/grid setDataSource + item_click/item_long_click |
| 模块系统 | ✅ CommonJS require | ✅ CommonJS require（内置模块） |
| 稳定性 | ✅ 成熟稳定 | ⚠️ 开发中（持续对齐 Auto.js Pro） |

## 3. QuickJS 已注册全局 API（126 项实测）

`$ui`、`LocalStorage`、`NativeFrame`、`YoloDetector`、`accessibilityFocused`、`algorithm`、`app`、`back`、`bounds`、`boundsContains`、`boundsInside`、`captureScreen`、`checkable`、`checked`、`className`、`classNameContains`、`classNameEndsWith`、`classNameMatches`、`classNameStartsWith`、`clearInterval`、`clearTimeout`、`click`、`clickable`、`colors`、`column`、`columnCount`、`columnSpan`、`console`、`contentInvalid`、`contextClickable`、`currentActivity`、`currentPackage`、`depth`、`desc`、`descContains`、`descEndsWith`、`descMatches`、`descStartsWith`、`device`、`dialogs`、`dismissable`、`drawing`、`drawingOrder`、`editable`、`enabled`、`engines`、`events`、`exists`、`exit`、`exports`、`files`、`find`、`findColor`、`findColorEquals`、`findColorInRegion`、`findImage`、`findImageInRegion`、`findMultiColors`、`findOf`、`findOnce`、`findOne`、`findOneOf`、`floaty`、`focusable`、`focused`、`getClip`、`global`、`home`、`http`、`id`、`idContains`、`idEndsWith`、`idMatches`、`idStartsWith`、`images`、`indexInParent`、`keys`、`log`、`longClick`、`longClickable`、`media`、`module`、`multiLine`、`notifications`、`packageName`、`packageNameContains`、`packageNameEndsWith`、`packageNameMatches`、`packageNameStartsWith`、`password`、`performance`、`press`、`quickSettings`、`recents`、`requestScreenCapture`、`require`、`row`、`rowCount`、`rowSpan`、`runtime`、`scrollable`、`selected`、`selector`、`sensors`、`setClip`、`setInterval`、`setTimeout`、`shell`、`shizuku`、`sleep`、`storages`、`swipe`、`text`、`textContains`、`textEndsWith`、`textMatches`、`textStartsWith`、`threads`、`toast`、`toastLog`、`ui`、`untilFind`、`untilFindOne`、`visibleToUser`、`waitFor`、`yolo`

`require` 只按脚本相对路径加载**磁盘**上的 `.js`，不解析 Rhino 侧的内置模块（`assets/modules/__*.js`），所以 `require('selector')` 这类写法在 QuickJS 里拿不到东西；选择器请用全局函数（`text()`…）或 `selector()`。

## 4. 主要差距（QuickJS 待补，剩 108 项）

> 按 2026-09-11 Mi8 实测差异归并；逐项清单见 `.artifacts/engine-api/engine-api-diff.json` 的 `onlyRhino`。

| 缺口 | 优先级 | 说明 |
|------|--------|------|
| `setScreenMetrics` / `SetScreenMetrics` | 高 | 多分辨率坐标适配（下一项任务） |
| `gesture`/`gestures`/`gestureAsync`/`gesturesAsync`、`input`/`Input`/`rawInput` | 中 | 多指手势与文本输入 |
| 按键常量（`KeyCode/KeyEvent/Tap/Swipe/Back/Home/Menu/Power/VolumeUp/Down/Camera/Up/Down/Left/Right/OK/Text`） | 中 | Rhino 通过 Java 类注入提供；QuickJS 白名单桥可用 `keys` 覆盖常用场景 |
| 顶层兼容别名 | 中 | `alert/confirm/prompt/select`、`random`、`sync`、`auto.waitFor`、`print`、`err`、`openConsole/clearConsole/addFilter`、`setImmediate/clearImmediate`/`timers` |
| 应用/引擎快捷全局 | 中 | `launch/launchApp/launchPackage/open/openAppSetting/getAppName/getPackageName`（`app.*` 已有）、`isRunning/isStopped/stop/isShuttingDown/notStopped` |
| 选择器动作的全局形式 | 低 | `scrollForward/setText/setSelection/setProgress/scrollTo/copy/cut/paste/select/collapse/expand/dismiss/show/contextClick/focus` 已在选择器/控件对象上提供，但未挂到全局作用域 |
| 等待类 | 低 | `waitForActivity` / `waitForPackage` |
| 模块与类注入 | 中 | `web`（`newInjectableWebView/Client`）、`zips`、`sqlite`、`crypto`、`util`、`io`、`plugins`、`Screencap/Image/Canvas/Paint`、`context`、`continuation`、`Intent/Module/Shell/MutableOkHttp`、`requiresApi/requiresAutojsVersion` |

| JSX / JSX 编译、UI 动态绑定（{{item.name}}） | 中 | 语法层与项目级 inflater 绑定 |
| Java 互操作（`importClass`/`Java.type` 任意反射） | 高（设计边界） | QuickJS 有意采用白名单桥接，不提供 Rhino 式任意反射；需先定正式兼容边界 |

## 5. 如何验证当前支持面

MCP 工具（需运行授权）：
```
list_engine_api {engine: "quickjs"|"rhino"}   # 枚举全局 API
probe_engine_api {engine: "rhino", name: "app"}  # 探测类型与成员
```

一次拿到差异表：

```powershell
.\tools\compare-engine-api.ps1 -Device <serial>   # 产物 .artifacts/engine-api/engine-api-diff.json
```

> PowerShell 5.1 的 HTTP 栈会给请求带上 `Expect: 100-continue`，而这个轻量 HTTP 服务按协议直接回 `417 Expectation Failed`（见 `McpHttpServer.serve`）；脚本改用系统自带 `curl.exe` 并显式 `-H "Expect:"` 去掉该头，会话内与子进程都能跑。
