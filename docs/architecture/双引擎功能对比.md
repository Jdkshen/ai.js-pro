# 双引擎功能对比（Rhino / QuickJS）

> 更新日期：2026-09-06 ｜ 依据：`list_engine_api` 实测（Rhino 225 项 / QuickJS 57 项）与源码实现
> 普通 `.js` 走 Rhino 1.7.7.2；首行 `// @engine quickjs` 走 QuickJS（libquickjs.so）

## 1. 总览

| 功能 | Rhino 引擎 | QuickJS 引擎 |
|------|------------|--------------|
| 悬浮窗 | ✅ 完整支持（XML 布局窗口、rawWindow、多控件、可拖动） | ✅ 支持（XML 布局/文本、可拖动、几何更新；无窗口生命周期钩子） |
| JSX 语法 | ✅ 支持 | ❌ 不支持 |
| 拖动功能 | ✅ 流畅 | ✅ 悬浮窗支持拖动 |
| 点击菜单 | ✅ 完整 | ⚠️ 使用对话框替代 |
| UI 界面（ui / $ui） | ✅ 完整（`ui.*`，XML 布局 + 事件 + attr） | ✅ XML 布局完整控件（DynamicLayoutInflater 全套）+ click/on/attr |
| 模块系统 | ✅ CommonJS require | ✅ CommonJS require（内置模块） |
| 稳定性 | ✅ 成熟稳定 | ⚠️ 开发中（持续对齐 Auto.js Pro） |

## 2. 模块级详细对比

| 模块 | Rhino | QuickJS | QuickJS 说明 |
|------|-------|---------|--------------|
| `ui` / `$ui` | ✅ 完整 | ✅ XML 布局完整控件 | DynamicLayoutInflater（TextView/EditText/ImageView/LinearLayout/FrameLayout/Toolbar/Spinner/TabLayout/DatePicker/RadioGroup/ProgressBar/TimePicker/AppBar）+ click/on/attr（轮询队列） |
| `floaty` | ✅ 完整 | ✅ 支持 XML/文本 | `window(xmlOrConfig)`/`rawWindow`/`closeAll` + setSize/setPosition/setText/setBackgroundColor/setTouchable/close；XML 复用 DynamicLayoutInflater，可拖动 |
| `threads` | ✅ 完整 | ✅ 基础 | 多线程 + `sleep`/定时器 |
| `events` | ✅ 完整 | ✅ | 事件总线 |
| `sensors` | ✅ 完整 | ✅ | 主线程 Handler 注册监听 |
| `media` | ✅ 完整 | ⚠️ 精简 | 音量/媒体基础能力 |
| `images` | ✅ OpenCV 全套 | ⚠️ 基础 | fromBase64/toBase64/concat/load + 图色查找 |
| 图色（findColor/findImage 等） | ✅ 完整 | ✅ | captureScreen/findColor/findImage/findMultiColors/findColorInRegion 等 |
| `http` | ✅ 完整 | ✅ | 网络请求 |
| `storages` | ✅ 完整 | ✅ | 本地存储（含 LocalStorage） |
| `files` | ✅ 完整 | ✅ | 文件读写 |
| `shell` | ✅ 完整 | ✅ | Shell 执行 |
| `shizuku` | ❌ | ✅ | QuickJS 原生注入 |
| `drawing` | ❌ | ✅ | QuickJS 原生注入（画布/绘制） |
| `performance` | ❌ | ✅ | QuickJS 原生注入 |
| `notifications` | ✅ | ✅ | 通知（QuickJS 原生注入；Rhino 原生完整） |
| `quickSettings` | ✅ | ✅ | 快捷设置 |
| `yolo` | ✅ | ✅ | YOLO 推理（两引擎均可） |
| `NativeFrame` / `YoloDetector` | ❌ | ✅ | QuickJS 专用 C++ 原生帧/检测器接口 |
| `RootAutomator` | ✅ 完整（原生 Java 注入） | ⚠️ | 简化版（click/longClick/back/press/swipe 等） |
| `engines` / `runtime` / `global` | ✅ | ✅ | 引擎管理、运行时、全局对象 |
| `require`（CommonJS） | ✅ | ✅ | 内置模块解析 |
| AP 打包 | ✅（项目级） | ✅（项目级） | 由 App 打包链路提供，非引擎差异 |

## 3. QuickJS 已注册全局 API（57 项实测）

`$ui`、`LocalStorage`、`NativeFrame`、`YoloDetector`、`app`、`back`、`captureScreen`、`clearInterval`、`clearTimeout`、`click`、`colors`、`console`、`currentActivity`、`currentPackage`、`device`、`dialogs`、`drawing`、`engines`、`events`、`files`、`findColor`、`findColorEquals`、`findColorInRegion`、`findImage`、`findImageInRegion`、`findMultiColors`、`floaty`、`getClip`、`global`、`home`、`http`、`images`、`log`、`longClick`、`media`、`notifications`、`performance`、`press`、`quickSettings`、`recents`、`requestScreenCapture`、`require`、`runtime`、`sensors`、`setClip`、`setInterval`、`setTimeout`、`shell`、`shizuku`、`sleep`、`storages`、`swipe`、`threads`、`toast`、`toastLog`、`ui`、`yolo`

## 4. 主要差距（QuickJS 待补）

| 缺口 | 优先级 | 说明 |
|------|--------|------|
| 悬浮窗窗口生命周期（exitOnClose/关窗事件） | 中 | 当前 close 幂等；`exitOnClose` 返回 false |
| UI 复杂交互（ListView 列表适配器、$ui 回调完整参数） | 中 | CPI 控件已支持，事件参数待增强 |
| JSX / JSX 编译 | 中 | 语法层，短期不做 |
| media/传感器/事件全量 API | 中 | 逐步对齐 Rhino 签名 |

## 5. 如何验证当前支持面

MCP 工具（需运行授权）：
```
list_engine_api {engine: "quickjs"|"rhino"}   # 枚举全局 API
probe_engine_api {engine: "rhino", name: "app"}  # 探测类型与成员
```
