## 1. 【一致性问题】可统一，低风险

### 1.1 列表外边距有 **5 种**写法

| 页面 | 现值 | 行号 |
| --- | --- | --- |
| 资源 | `PaddingValues(6.dp)` | `MiuixResourceFragment.kt:175` |
| 搜索 | `PaddingValues(16.dp)` | `MiuixSearchActivity.kt` |
| MCP 历史 | `PaddingValues(16.dp)` | `MiuixMcpHistoryActivity.kt:81` |
| 图标选择 | `PaddingValues(12.dp)` | `MiuixIconPicker.kt:101` |
| 插件（新，作为基准） | `start12/end12/top8/bottom12` | `MiuixPluginFragment.kt:184` |
| 教程 / 管理 | `bottom = 18.dp`（**无左右边距**） | `MiuixSampleFragment.kt:188` / `MiuixTaskManagerFragment.kt:159` |
| 文件 | **无 contentPadding** | `MiuixScriptListHost.kt` |

影响：切换 tab 时内容左右边界会跳。资源页 `6.dp` 几乎贴边，与插件页 `12.dp` 对比明显。

### 1.2 行高差 **22dp（37%）**

`60`（文件）· `74`（教程）· `78`（管理）· `82`（资源）

### 1.3 分隔线有 **2 套写法**

| 写法 | 使用者 |
| --- | --- |
| `Box(Modifier.fillMaxWidth().padding(start = X.dp).height(1.dp).background(dividerLine))` | 文件 `:692`（74dp）· 教程 `:312`（82dp）· 管理 `:322`（82dp）· 搜索 `:1157` |
| Miuix `Divider(...)` | 仅插件卡片边框用 `dividerLine` 令牌（`MiuixPluginFragment.kt:489`） |

### 1.4 硬编码颜色（不随深色主题）

| 文件 | 处数 | 说明 |
| --- | --- | --- |
| `AijsMiuixTheme.kt` | **21** | 主题令牌定义本身，**正常** |
| `MiuixBuildActivity.kt` | 9 | 错误红 `#D32F2F`、权限等级色、`#009688` |
| `MiuixSampleFragment.kt` | 7 | 文件类型色（目录/JS/MD/APK）+ 错误红 |
| `MiuixScriptListHost.kt` | 4 | 分类头 4 个图标 tint `#828384` |
| `MiuixSearchActivity.kt` | 4 | 项目/目录/文件类型色 |
| 其余 | 各 1–2 | 单点 |

**注意**：`MiuixScriptListHost.kt` 的 4 处 `#828384` 与**旧界面 `script_file_list_category.xml` 的 `app:tint="#828384"` 完全一致**，
改主题令牌会偏离旧界面 —— 属于「旧实现自带」而非新 UI 引入。**要不要动需你决定。**

## 5. 我的建议顺序

1. **统一 1.1 外边距 + 1.2 行高 + 1.3 分隔线**（纯数值，风险最低，直接改善「精致度」）
2. **资源页 2.1 改两列卡片**（与插件页同形态，视觉最统一）
3. **教程页 2.2**（与文件页同源，改前建议先确认是否要保留扫视效率）
4. **3.1 无障碍描述**（逐处判断，装饰性图标不动）
5. **2.5 日志页 LazyColumn**（性能相关，与美观无关）
