## 范围

## 本轮实现

- `modules/common-api.js`：文件 API v1、命名 JSON 存储、设备方法及 `$` 别名。
  Node 的 `files.remove` 改为文件删除，递归目录删除用 `removeDir`；编码/文件流复用 Java Files。
- QuickJS 补字节写入与编码处理；文件监听停止/重启收回系统事件轮询定时器。
  同时修复最后一个定时器结束时 native `waitForNextTimer` 空队列仍无限等待的问题。
- `Files(Context, workingDirectory)` 复用文件实现，不创建 Rhino ScriptRuntime。
- `LocalStorage` 在提供者可用时走私有单进程存储服务，避免脚本进程和 Node 进程池的 SharedPreferences 快照过期。
  v1 继续使用原 `autojs.localstorage.*` 名称；Node 原平铺字符串 API 保留 `node24.storage.*`，不悄悄迁移或覆盖旧数据。
- Node `storages.create(name)` 提供与 Rhino/QuickJS 一样的 JSON 对象接口。
  全局 `storages.remove(name)` 删除命名存储内容；旧 Node 模块 `remove(key,name)` 保留，新增 `removeStorage(name)` 消除歧义。
- JSON 存储拒绝 undefined/循环引用，保留 null/false/0/空字符串；循环检测也避免 Rhino 原 stringify 卡住。
- `modules/common-device.js`：三引擎共用 v2 Device/OS/BrightnessMode；真实亮度、设备信息、音量范围、内存、充电通道和权限异常。
  v1 Device 方法使用现有 Java Device；不再给 Node 用户伪造固定亮度/MAC。
- 原 Node color 模块迁到 `modules/common-color.js`，三引擎共用 Color/HSVColor/HSLColor；补 v1 颜色入口。
- `modules/common-lang.js`：高级版 lang / java_utils 的延迟、Deferred、超时与 Java 集合/数组转换共用实现。
  Node 标准库保留；Deferred 等待结束后会撤销持活定时器。
- 修复 Rhino Timer/Timers 用历史最大截止时间判断存活的问题：取消未来定时器后空队列不再永久等待；
  保留并跟踪直接 post 的 Runnable 与各子线程定时器。
- 文件流 `readline` 后 `read` 共用 BufferedReader 游标，定长读取 EOF 返回空串；
  QuickJS/Node 的 readlines 返回真正 JS 数组；QuickJS `io.files` 同步到共享 files 门面。
- Rhino Intent category 数组循环变量、邮件地址数组逐项赋值修正。
- Node `legacy-runtime.js`：真实 app 包名/名称查询和 launch 返回值、本地全局 events、旧 util；
  `engines.execScript` 直接发源码到现有协调器；文件执行扩展参数保留 delay/interval/loopTimes/path/arguments。
- `ExecutionConfig` 接受真正的 null 参数，不用 JSONObject.NULL 冒充 JS null。
