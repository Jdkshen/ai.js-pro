# 启动主题统一与文档复制优化（dev-1256）

日期：2026-10-26。用户要求启动界面颜色统一，API 文档简单、美观、易操作，方便复制代码。

## 改动

- 原生启动页、Flutter window、品牌页、主页和文档统一使用深色 `#1C2022` / 浅色 `#F7F7F8`，状态栏和导航栏同步配色与图标明暗。
- Flutter 在 `runApp` 前通过轻量 `appearance` 读取主题，读取有 800ms 上限；不等 Home 的目录 bootstrap 才纠正品牌页颜色。兜底根背景改为不透明主题色，保留原有启动持有时长。
- Android 12+ 用 `UiModeManager.setApplicationNightMode` 持久化本应用主题覆盖，使系统自己的启动窗口也跟随应用选择；跟随系统时清除应用覆盖。没有调用改变全局夜间模式的 `setNightMode`。
- 新增 v31 启动主题和带内边距的品牌图标，移除默认白色图标底板并避免图标被圆形遮罩裁切。Splash 销毁时取消待执行回调，防止主题配置重建遗留跳转。
- 文档配色跟随应用，不依赖系统 WebView 深浅偏好。搜索区更紧凑，专题与说明按需展开，结果预览最多两行，搜索默认只展开首项。
- 每个代码块加入「复制代码」与「已复制」反馈，保留中文、引号、缩进和换行；自动换行不修改复制文本。支持全部收起、可见返回按钮和窄屏显示。重新搜索回到首条，显示更多保留已展开内容。
- Android 复制仅通过本地 API 页的限定 prompt 消息处理；同时检查请求页和当前页，只允许写剪贴板，不开放文件、Shell 或任意 Java 调用。单次上限 128Ki UTF-16 字符，超出明确拒绝，不静默截断。浏览器使用标准复制回退。

Android 平台依据：[夜间主题建议](https://developer.android.com/develop/ui/views/theming/darktheme)、[启动页主题属性](https://developer.android.com/develop/ui/views/launch/splash-screen)、[AOSP 应用夜间模式实现](https://android.googlesource.com/platform/frameworks/base/+/a42e14ce6379/services/core/java/com/android/server/UiModeManagerService.java)。全局主题不属于本轮修改范围。
