# 象棋主界面 M3 改版与功能对齐

工程版本：0.6.33。主界面使用浅色绿调的 Material 3 风格令牌：大圆角分组卡片、清晰的文字层级、选中态和固定底部操作栏。这是现有 QuickJS XML 控件的样式实现，不依赖新增 Compose 页面。

## 功能变化

| 功能 | 主界面入口 | 与悬浮窗的关系 |
| --- | --- | --- |
| 模式、红黑方 | 对局控制 | 共用存储；模式/点击通道变化时先停止，再手动开始 |
| 时间、层数、深度超时、调整步长 | 算棋设置 | 沿用旧保存值，双向读取，下次搜索生效 |
| 线程、缓存、开局手数、避和、求胜 | 引擎与策略 | 应用到实际驱动和 Pikafish 配置 |
| 开局候选随机 | 引擎与策略 | 补充开关；浮窗运行同样读取 |
| 开始、停止 | 底部固定操作栏 | 主页面启动同项目的悬浮窗执行流程；不会另开一套自动点击循环 |
| 定位、实时识别、新会话、声明轮次 | 对局控制 / 棋盘工具 | 通过命令调用浮窗控制器，等待回执；失败显示原因 |
| 识别绘制 | 棋盘工具 | 与浮窗的识别审核画板一致；关闭会收起画板 |
| 打开、关闭、收起/展开 | 悬浮窗卡片 | 保留独立运行；页面显示就绪/准备/运行/错误状态 |
| 离线图片、自检、运行环境 | 更多设置 | 折叠收纳，保留原有能力 |

旧页面把搜索时间固定为 1200ms，且模式同步用大写枚举对象查小写值，造成配置不一致。新页面的日常对局按钮走悬浮窗控制器；参数统一由 `session-settings.js` 读取、校验和应用。

## 后续修改位置

- `src/ui/page-layout.js`：配色、间距、卡片和按钮布局；`COLORS` 是页面样式入口。
- `src/ui/page-settings.js`：参数按钮绑定、选中态、范围与边界禁用显示。
- `src/app/session-settings.js`：参数默认值、合法范围、旧配置迁移与驱动参数映射。沿用 `xiangqi-panel` 原有键。
- `src/app/panel/settings.js`：浮窗只应用存储中真正发生改变的键，保留本次 autorun 的非持久化覆盖。
- `src/app/page-actions.js`：等待同目录面板就绪、单操作等待、回执与超时、取消。
- `src/app/panel/bus.js`：面板执行命令并发布实际状态、进度、最近日志。命令绑定面板的 `readyAt`，超过 12 秒或发给旧实例的命令不能重放。

新增参数时先扩展共享定义和驱动映射，再加两个入口的控件，避免页面与浮窗各自写一套默认值。时间/线程等参数允许下一次搜索应用；改变模式或点击通道必须停止当前运行。

## 悬浮窗日志优化（0.6.31–0.6.33）

- 日志窗改成“运行日志 · 当前状态”标题栏，并显示当前可见摘要行数；窗口高度调整为 380px，标题下最多保留 6 条最近事件。
- 日志区改用 `ScrollView`，不再按字符截断长路径、autorun 诊断和识别信息；文本按控件宽度自然换行，完整内容仍在浮窗内可见。
- 新日志写入后自动滚到最新行；日志窗位于棋盘和底部菜单之间的安全带，允许手指上下滑动查看更早的启动日志。心跳类日志不上屏，完整原文继续写入 `panel-log.txt` 和 logcat。
- 主面板根布局的固定 380px 高度与子项重新对齐，根内边距调整为 6px，进度区最后一行（轮次/历史/落点）不会再贴边或被裁掉。
- 主面板进度摘要取消 30 字硬截断；轮次等待、观察统计和确认状态使用完整结论，进度卡支持自然换行和滚动，长内容不再出现半截省略号。
