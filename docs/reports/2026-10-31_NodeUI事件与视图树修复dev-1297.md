# Node UI 事件与视图树修复（dev-1297）

日期：2026-10-31。来源：设备 192.168.10.4 上 `chess-auto/docs/已知问题.md` §2 与 `node-port/ui/README.md` §6（Redmi 2602BRT18C / Android 16 / dev-1294 实测）。

本轮针对其中的 Node UI 问题做实现并在 MI8 上做真机复测（dev-1297）。

## 1. 修复内容

| 编号 | 问题 | 修复 |
| --- | --- | --- |
| 6.10 | `ui.inflate(layoutId)` 报“找不到布局” | JS 归一化数字 id / `ui.R.layout.x` / `{type,name}` / 名字；宿主 inflater 支持 layoutId/名字解析并给出“布局不存在：<ref>”诊断 |
| 6.11 | `ui.inflate()` 返回包装对象、`getParent()` 恒 null | 宿主返回真实 View 句柄；JS 新增视图门面 `addView/removeView/getParent/getChildCount/getChildAt/findViewById`；旧宿主明确报错不静默 |
| 6.13 | listener 挂载成功但永不回调 | 两个根因：① 原生监听器统一套用了 `NavigationBarView$OnItemSelectedListener` → 按事件选择正确接口；② Activity/绑定路径的 `view.on()` 只把回调放进 EventEmitter，而原生命中从 `eventHandlersOf(view)` 取 → 两条路都登记 |
| 2.1 | 输入框无文本变化事件 | 新增 `on('text_change')`：真实 View 走 TextWatcher（补全三方法），协议句柄走 `setOnTextChangedListener`，旧宿主轮询 `getText()` |
| 2.2 | `Handler.postDelayed` 在 `onContentViewSet→_bind` 不执行 | 宿主提供主 Looper `postDelayed/removeCallbacks`（`uiRequestView`）；`scheduleAdapterRetry` 守卫改为 `sessionContentView()` |
| 2.6 | `JsViewPager.initAdapterFromChildren()` 不识别 `<include>` | 宿主 `NodeUiRecyclerView` children 模式 + include 展开；`childCount/adapterCount` 正确 |
| 2.7 | `BottomNavigationView` itemId 与 `ui.R.id` 不一致、监听不回调 | `id` 类型在宿主 getIdentifier 为 0 时回退 `Ids.parse`（同源）；菜单访问 `getMenuSize/getMenuItemId/menuItems`；`item_selected` 监听真实安装 |
| 6.1/6.2 | keepRunning 只扫入口 / 约 3.4s 自退 | 引用计数保活 + 工程源码扫描；`stopRunning()` 只释放最近一次，新增 `cancelKeepRunning(token)` |
| 2.3/6.6 | 自建 vector drawable 不生效 | 未实现渲染，提供可执行诊断（`tools/build-project-res.ps1` 或改用内置图标） |

另外：无 `@+id` 的 inflate 根 View 现在会分配稳定 viewId，避免多个 inflate 共用 -1 造成 click/check 事件串台。

## 3. 已知剩余问题（未验收）

- `navigation.setSelectedItemId(id)` 抛 `NullPointerException: Expected to unbox a 'boolean' primitive type but was returned null`；反向同步（ViewPager→导航）暂不可用。
- `item_selected` 回调当前拿到的是 Java `MenuItem` 对象而不是数字 id；脚本侧需要 `item.getItemId()`，与文档口径需统一。
- `ui.layout(...)` 返回的内联 binding 没有 viewId（`__markerState.viewId` 为空），该路径的 `on()` 仍是 JS 侧登记、不触发；`ui.setMainActivity`/Activity 路径正常。
- vector drawable 只有诊断，没有实现渲染。
- 真机只覆盖 MI8（Android 35/36 族）；192.168.10.4 上的 chess-auto 工程未安装 dev-1297，需用户侧复测。
