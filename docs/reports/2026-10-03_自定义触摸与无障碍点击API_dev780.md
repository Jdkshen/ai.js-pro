# 自定义触摸与无障碍点击 API（dev-780）

## 新增接口

| 接口 | 用途 |
| --- | --- |
| `ui.replaceAccessibilityAction(view, action, label, callback)` | 为脚本自己的 UI / 悬浮窗控件定义无障碍点击、长按动作与描述 |
| `ui.performClick(view)` | 自定义触摸识别到轻触后调用原生 View.performClick，保留普通点击监听和无障碍通知 |

两个接口均支持 Rhino、QuickJS。控件可传 Android View、UI 控件代理、悬浮窗控件或当前 UI 的 id 字符串。

- 点击动作支持 `click`、`ACTION_CLICK`、16；长按支持 `long_click`、`longClick`、`ACTION_LONG_CLICK`、32，也支持对应 Android AccessibilityAction 对象。
- 回调接收 `(view, {action, label})`。通过脚本事件循环派发，回调返回值不作为 Android 动作处理结果。
- `callback=null` 移除自定义动作，恢复默认动作。注册不会替换普通 OnClickListener。
- 脚本退出清理自己的动作；旧脚本退出不会移除后来由另一个脚本替换的动作。中断线程退出也会在主线程完成清理。
- 这些接口操作脚本自己的 View。其他应用节点仍使用 UiObject 的自动化操作。

Android 设计参考：[自定义视图无障碍文档](https://developer.android.com/guide/topics/ui/accessibility/views/custom-views?hl=zh-CN)。

## 源码与文档

- `modules/engine/src/main/java/com/stardust/autojs/core/ui/AccessibilityClickSupport.java`：主线程动作注册、原生点击、回调队列与退出清理。
- `modules/engine/src/main/assets/modules/ui-accessibility.js`：跨引擎脚本接口。
- Rhino：在 `__ui__.js` 安装接口；QuickJS：由 `QuickJsHostBridge` 加载共享脚本。
- `apps/app/src/main/assets/docs/ui.html`：两个接口的离线文档、目录和用法。

## 示例

- 示例 → QuickJS 新引擎 → 界面与交互 → **自定义触摸与无障碍点击.js**
- 示例 → Rhino 引擎 → 界面控件 → **自定义触摸与无障碍点击.js**

蓝色触摸区域：轻触通过 performClick 执行选择，拖动超过系统触摸阈值则取消。两个按钮分别演示原生点击和无障碍动作。窗口使用 XML 指定宽度并自动测量高度，避免 QuickJS setSize 的负高度变成 0 而出现触摸穿透。
