## 2. 「左下角输出日志不翻滚」根因与修复

logcat 实测（dev-1407 诊断构建）：

```text
refresh follow=false inserted=1 filtered=291 lastVisible=-1 attached=true console=true
```

`findLastVisibleItemPosition()` 返回 **-1**（`notifyDataSetChanged()` 后瞬时无子项），而旧条件 `-1 >= size-2` 恒 false
→ `follow` 永久 false → `scrollToPosition` 再不被调用。**300 行复现**：脚本已打印 `MARKER-DONE-300`，窗口仍停在 `LINE-291`。

**修**（5 行含注释）：`follow = lastVisible < 0 || lastVisible >= mFilteredEntries.size() - 2;`

**走过的弯路（记录以免重犯）**：先按「显式跟随状态 + OnScrollListener + notifyItemRangeInserted」大改，K40 上窗口内容区变**全空**；
改回原文件（只留 1 行语义修正）仍然全空 → 说明「空」另有原因、与本次改动无关：把 `ConsoleView.java` 用 `git checkout` 还原后同样空白。
