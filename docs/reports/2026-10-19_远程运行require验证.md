## 帧格式
```
[int32 BE payload length][int32 BE type (1=JSON)][payload UTF-8 JSON]
```
- 服务端连接后先发 hello；客户端发：
```json
{"type":"hello","data":{"client_version":4}}
```
- 运行脚本：
```json
{"id":1,"type":"command","data":{"command":"run","id":"remote-sim-1","name":"remotetest.js","script":"..."}}
```
- 响应：`response_1`（data 为空表示命令受理）+ 后续 `log` 帧（脚本 console/运行日志）。

## 复现步骤
1. 打开 App 的 VS Code 调试服务器（设置默认值 `key_dev_plugin_server_enabled=true` 或 UI 开关），确认 9317 LISTENING；
2. `adb forward tcp:9317 tcp:9317`；
3. PC 侧建立 TCP，发送上文的 hello/command 帧（帧头 8 字节）；
4. 看到 response + log 帧；logcat 出现 `C-REMOTE module=... __dirname=... requireBase=...`；
5. 工程依赖放在 `/sdcard/脚本/<工程名>/`（save 过），handler 会按脚本里 `require('./x')` 自动扫一级子目录选 requireBase。
