## 三、根因

**不是"垃圾多"，而是这几个目录的默认位置就在 C 盘，且每次开发都会增长：**

| 增长源 | 每轮增长 | 为什么在 C: |
| --- | ---: | --- |
| Gradle 产物转换缓存（`transforms`） | 2–3 GB | `GRADLE_USER_HOME` 未设 → 默认 `~\.gradle` |
| 各类临时文件 | 5–7 GB | `TEMP`/`TMP` 默认 `~\AppData\Local\Temp` |
| Codex 会话 + 任务暂存 | 累积到 9 GB | `CODEX_HOME` 未设 → 默认 `~\.codex` |
| npm/pip 缓存 | 0.3 GB | 环境变量未设 |
| 仓库 `build/` 产物 | 2–4 GB | Gradle 默认在模块目录下（**本次未动，见 §六**） |

C: 219 GB 里另有约 67 GB 是**不可再生的固定占用**（`WinSxS` 9.8 + `System32` 6.8 +
`Installer` 3.2 + 微信/QQ 12 + ChatGPT/Doubao 15 + 旧工程/项目 14 + VS Code 工作区 6），
所以可回旋空间本就不大，缓存增长会很快触顶。

## 四、修复

### 4.1 清理（释放约 10 GB，全部可再生）

| 对象 | 大小 | 依据 |
| --- | ---: | --- |
| `~\.codex\tmp\aijs-*` | 4.75 GB | 名为 tmp、内容是 10-30 的任务构建暂存（`aijs-node-widget-release` / `aijspro-vscode-log-fix-build` / `aijspro-log-candidate`）；`arg0`/`arg0-windows` 是运行时 shim 已保留 |
| 仓库构建产物 | 2.66 GB | `apps/app/build` 1.07 + `apps/inrt/build` 0.85 + `modules/engine` 0.37 + `flutter-ui` 等 |
| `~\.codex\sessions` 30 天前 | 1.69 GB | 195 个文件（保留 2026-10/11） |
| `ms-playwright` | 0.67 GB | 可 `npx playwright install` 重装 |
| `Temp` / Edge 缓存 / CrashDumps | 0.25 GB | |

### 4.2 迁移（治本）

用 `robocopy /MOVE /E` **搬运**（不是重新下载），然后设用户级环境变量：

```powershell
$root = 'E:\dev-cache'
New-Item -ItemType Directory -Force -Path $root, "$root\temp", "$root\npm", "$root\pip"
robocopy "$env:USERPROFILE\.gradle" "$root\gradle" /MOVE /E
robocopy "$env:USERPROFILE\.codex"  "$root\codex"  /MOVE /E

# 用户级（写注册表，新进程生效）
[Environment]::SetEnvironmentVariable('GRADLE_USER_HOME', "$root\gradle", 'User')
[Environment]::SetEnvironmentVariable('CODEX_HOME',       "$root\codex",  'User')
[Environment]::SetEnvironmentVariable('TEMP',             "$root\temp",   'User')
[Environment]::SetEnvironmentVariable('TMP',              "$root\temp",   'User')
[Environment]::SetEnvironmentVariable('npm_config_cache', "$root\npm",    'User')
[Environment]::SetEnvironmentVariable('PIP_CACHE_DIR',    "$root\pip",    'User')
```

  └ wrapper\dists                          0.14 GB（Gradle 发行版）

## 六、边界与未做

1. **仓库 `build/` 目录仍写在 C:**（2–4 GB/次构建）。要彻底解决需在
   `gradle.properties`/`settings.gradle` 统一改 `buildDir` 到 E:，
   那是**改仓库构建配置**（影响所有协作者/CI），本轮**刻意未做**。
2. **现有进程不生效**：环境变量写注册表，只有**新启动**的进程读到。
   所以 VS Code 必须**完全退出重开**，其集成终端才会用新 `TEMP`；本会话（DSH）仍是旧值。
3. **E 盘成为构建依赖**：E: 若是可移动盘需注意；本机 E: 是本地固定盘（56% 已用）。
4. **`~\.codex\plugins` 0.8 MB 残留**：被运行中的 Codex 进程持有，无权删除，已保留。
5. **未动用户数据**：`Documents\ChatGPT` 9.08 GB、`Doubao` 5.66 GB、
   `win灵动岛` 6.02 GB、`AutoJsPro-本地工程-20261008` 8.09 GB、微信/QQ 12 GB、
   VS Code `workspaceStorage` 5.04 GB（其中 2.8 GB 是 Copilot **对话历史**，非缓存）。
6. **WinSxS 9.79 GB 未清**：需管理员执行
   `DISM /Online /Cleanup-Image /StartComponentCleanup`（预计省 1–3 GB）。

### 回滚方法

```powershell
[Environment]::SetEnvironmentVariable('GRADLE_USER_HOME', $null, 'User')
[Environment]::SetEnvironmentVariable('CODEX_HOME',       $null, 'User')
[Environment]::SetEnvironmentVariable('TEMP', 'C:\Users\18101\AppData\Local\Temp', 'User')
[Environment]::SetEnvironmentVariable('TMP',  'C:\Users\18101\AppData\Local\Temp', 'User')
robocopy E:\dev-cache\gradle C:\Users\18101\.gradle /MOVE /E
robocopy E:\dev-cache\codex  C:\Users\18101\.codex  /MOVE /E
```

### 预期效果

C: 每轮开发增长预计 **10–15 GB → 2–4 GB**（只剩仓库 `build/` 与用户数据）。
