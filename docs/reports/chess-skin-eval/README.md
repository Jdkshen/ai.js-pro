## 指标口径

- **严格**：单元格必须与真值完全一致（**含阵营**）。
  ⚠️ 曾经把大小写归一化，等于「颜色判错不算错」—— 那样会把 81.9% 报成 88.5%，所以口径必须是严格的。
- 「只看兵种+位置」：只用来定位问题属于「认错子」还是「认错色」。
- **未知格数**：自动走棋的出手闸门就是「未知格必须为 0」，所以它单独报。

## 这轮查出并修掉的两个真问题

1. **棋规反查把「颜色错」当「多一个子」丢掉**（`consistency.repair`）：
   模型把黑士判成红仕 → 同时触发「仕士不在九宫」和「红仕 3 个」→ 修复直接把这枚子降级成未知（真的少一个子）。
   现在两条分支都先试**改阵营**（翻完不引入新硬违规、另一色未满就翻），只有真的多子才降级。
2. **校准的搜索代价不能只看未知格**：有了翻色修复后，任意偏移都能凑出「0 未知格」，
   搜索会立刻停在未对齐的 `(0,0)`，反而把颜色正确性丢掉（颜色错 0 → 18）。
   现在代价 = `修复动作数 × 1000 + 未知格数`（先看修复动作，再看未知格）。
