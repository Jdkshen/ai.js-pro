# entry_（入口分析）：组件/进程/Application + native 线索 + 提前加载建议（dev-1425）

> 日期：2026-11-09 11:0x–11:3x · 起点 HEAD f8865168 · K40=cccc62c7（dev-1425）

## 0. 本轮做了什么

交接单 ⑥⑦ 的第三个工具项 `entry_`（范围提案 §4）落地：**静态编排，不新增解析能力**——Manifest 的 AXML/ResXmlElement、DEX、native ELF 解析都已存在，本工具把它们按「入口」这个视角组织起来，并给出**与注入器同源**的提前加载建议。

## 1. 返回什么（W1 task-29）

| 段 | 内容 |
|---|---|
| `application` | `class`（相对名按包名展开）/`classSource=manifest\|default`/`declaredClass`/**`appComponentFactory` 两态**（声明时明说 `application@name` 不可靠）/`classInitializer` 摘要（父类可用性、是否 final/接口、clinit 类是否已在 DEX、失败码） |
| `launcher[]` | kind/name/**`targetActivity`（activity-alias 的声明值与展开值）**/`process`/`exported`/evidence/confidence |
| `exportedComponents[]` | activity/service/receiver/provider 的 name/exported/`android:process`（复用 `isLauncherComponent`/`processOf`，与 `patchManifest` 的 provider 进程判定同源）；`exported=null` 如实表示「未显式声明」 |
| `nativeEntryHints[]` | 逐个 `lib/**/*.so`：`soname`/`needed[]`/`jniOnLoad{found,address,size,binding}`/`initArray`/stripped/architecture，按 confidence 排序 + `nativeNote`「**没找到 ≠ 没有 native 初始化**」 |
| `preloadRecommendation` | `provider\|dt_needed\|clinit` 三选一 + reason + **`reasonSource`（函数名+实参）** + `modes{...available,reason,checkedBy}` + `runtimeVerified=false` + `suggestedArguments` |
| 分层 | `staticConclusions[]` 与 `needsDynamicConfirmation[]` 分开，`limits.notScanned[]` 列明未覆盖项 |

**同源实现**：`preloadRecommendation` 只读注入器用的同一份预检（`ToolkitGadgetPreload.plan` + 本轮**新拆出的只读** `ToolkitGadget.assessClinit`）；`prepareClinitHook` 改为 `assessClinit + 编译`，失败码/文案逐字保持一致 → `apk_inject_gadget` 的 clinit 路径与 `entry_` 的建议**不会分叉**，并有单测逐字段断言。

## 4. 未做 / 边界

1. `entry_` 是**静态**分析：`runtimeVerified=false`；壳可动态注册组件；DEX 方法体里的 `System.loadLibrary` 调用点、`resources.arsc` 里的组件字符串、Split APK **未扫**（写进 `limits.notScanned`）。
2. `recommendation` 复用 `plan()` 会读**每个候选 .so**（单个 ≤64MiB）→ 大包上耗时数秒，因此默认后台 job（同步调用要 `background:false` 且给足 `timeoutSeconds`）。
3. `workspaceId` 的目录公式是按现有 store 路径镜像实现；不对时明确报 `WORKSPACE_EXPIRED`（可观测，不静默给错文件），但未真机专门构造该失败路径。
4. `exported` 读取失败（非布尔属性）按 `null` 处理并注明——不区分「未声明」与「畸形值」（有意保守）。
5. 随包文档（Guide/Playbook/Reverse-Guide 的工具清单与计数）与 `tools/mcp-smoke` **未同步** `entry_`/`vm_survey`/`dev_screen_diff`（W3/Lead scope）。
