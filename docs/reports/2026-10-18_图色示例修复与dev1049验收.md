## 两处已复现问题与修复

1. 图色示例从示例页执行，经 `PocRuntime` 进入 `:script`，`Images.requestScreenCapture()` 立即报“隔离进程暂不支持投屏截图”。相同 QuickJS API 回归脚本直接在主进程运行正常。新增 `ScreenCaptureScriptRouting`，识别入口中的截图、共享截图、异步截图和窗口截图调用，经原有 `executeFile` 在主进程执行，保留本地投屏帧和 NativeFrame 路径。
2. Rhino“获取网络图片并保存”旧 URL 无法解码，`images.load()` 返回 null 后保存触发空指针。替换为已在 PC、K40 验证的 `https://httpbin.org/image/png`；下载失败有中文错误，保存到当前脚本目录 `downloaded-image.png`，校验保存结果，finally 回收图片。

UI 路由保持优先；native 项目继续走原有隔离进程。纯图片读取、模板匹配等普通脚本继续在 `:script` 运行。能力检测跳过注释、普通字符串、模板文本、无关对象和函数声明，避免仅因文档里的 API 名称改变路由。
