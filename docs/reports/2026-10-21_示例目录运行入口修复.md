## 问题与原因

K40 在示例列表点击 React 目录外侧的运行按钮，提示：
`Bad state: 项目入口文件不存在：dist/main.node.js`。
日志定位到 `PocRuntime.runProject`，发生在引擎启动之前。

React / Vue3+CLI 的原始工程配置把 `project.json.main` 指向 APK 构建产物
`dist/main.node.js`，根目录实际开发入口是 `main.node.js`；
`build-apk-pre-prepare` 负责打包时生成 dist。此前直接运行源码的回归绕过了
目录运行逻辑，因此没有覆盖用户点击的这个入口。

## 修改

新增 `PocProjectEntry`，由现有 Flutter 运行项目桥调用：

1. 配置入口已存在时仍运行配置入口。
2. 开发 Node 工程配置了 APK 构建钩子、存在 package.json、配置入口位于工程子目录且为
   `.node.js`，而构建产物尚不存在时，选择根目录同名 `.node.js` 源码。
3. 不随意猜测 main.js 或不同文件名；缺文件和不合法 main 配置继续报错。
4. 已声明 release 的 BuildInfo 不进行开发入口替换；支持现有三个 release 字段别名。
5. 不修改示例 project.json、打包钩子、BuildInfo，也不伪造 dist 文件。工作目录仍为工程根。
