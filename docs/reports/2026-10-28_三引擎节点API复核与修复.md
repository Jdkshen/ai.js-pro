## 边界

- 节点动作返回 true 只表示宿主接受；目标不支持/页面变化返回 false，不是异常。
- 密码节点的 text 返回空串，且不会写入保护选择器；长文本严格拒绝，不截断。
- `:script` 隔离进程的实际 UI 自动化仍需从浮窗/扩展入口单独回归；本报告不把主进程示例通过等同于隔离进程全量通过。
