# 节点分析：隔离、超时取消与大树优化（2026-10-28）

目标：继续 2026-10-27 静态对照后的实现工作，先处理抓取超时/取消/退出，再优化大树点选与主线程工作，并做分析 UI 的进程隔离。当前为**未发布候选**，不代表 AJ Pro 全量等价。

## 已实现

- 抓取统一入口：`CaptureRequestGate` + `NodeCaptureBudget`；单物理抓取、8 s 预算、15000 节点/256 层上限；超时/取消丢弃晚到结果，不把 UI 恢复当成 Binder 已终止。
- `LayoutInspector` 提供可取消请求；窗口刷新与当前窗口共用同一线程池，避免每超时新建线程。
- 新增 `:inspector` 独立渲染进程（`InspectorHostService`、`InspectorProcessBridge`、`InspectorSnapshotTransport`）：主进程采集，快照经同 UID 随机 token 缓存目录传给子进程；文件大小/节点数/深度校验。
- 子进程渲染离屏快照；切换范围图/层次树、搜索、属性面板和改进生成器保留。
- 大树点选使用 `InspectorHitIndex` BVH；范围图不再每次触摸全树 BFS，绘制改为缓存 Path。
- 搜索改为后台线程 + 代次校验；窗口刷新和打开有超时恢复；主题从主进程调色板同步到子进程。
- 音量下退出监听接入 `GlobalKeyObserver`，打开时注册、关闭时移除。
- 隔离失败时回退旧主进程分析窗，避免“整个分析功能消失”。
- 面板/搜索/菜单/属性弹窗改用动态调色板；NodeInfoView 属性读取移到后台。
