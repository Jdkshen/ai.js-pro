## 探针关键证据

- `accessibility`：enableService 已 resolve true；on(key_event/view_clicked/toast) 可用；toggleRecents/openNotifications/back/home 可用；**enableKeyEvents 不存在**；**lockScreen 抛「暂未支持」**。
- `notification`：notify/update/addAction/cancel/cancelAll/on/off；**requestListeningNotifications 不存在**；`on` 只接受 click/action。
- `media`：playMusic/stopMusic/... 均存在；getVolume = `{stream:3,volume:0,max:25}`；**playMusic(URL) 不支持**（按文件路径解析）。
- `plugins`：list/all/isInstalled/info/load/launch/open 均可用；`isInstalled('org.autojs.plugin.ffmpeg')=false`。
- `image`：导出无 `matchFeatures`，`Image` 实例无 `detectAndComputeFeatures`。
- 其他：`root_automator`、`template` 模块 require 失败；`app.launch('com.android.fileexplorer')` 抛宿主桥 explicit activity 错误（目标包在 MI8 未安装）。

## 建议

1. **已修复项**（19、21）可把账本状态改成通过（Node UI / 自定义组件能力已落地）。
2. **低成本可修**：42 补 `accessibility.enableKeyEvents`；55 补 `notification.requestListeningNotifications` 并让 `notification.on('notification')` 可用；37 让 `media.playMusic` 支持 http(s) URL（或样例改成本地文件）；43/45/48 的 `lockScreen` 仍是明确未支持（提示已如实）。
3. **前置缺失**：36 需 ffmpeg 插件 APK（当前仓库无产物，需发布/内置）；43 依赖 `com.android.fileexplorer`，MI8 无该应用（可改为通用 `VIEW Intent` 拉起任意文件管理器）。
4. **设计限制**：2/3 的 JS 继承 Java 类（`defineClass`）按设计不支持，建议在账本里标注 designed_unsupported 而非能力缺口；22/34 属模块/API 未提供。
