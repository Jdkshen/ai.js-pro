## 修复

- 在既有 Java View 代理上补充 Node UI 的 `on/once/off/removeListener/removeAllListeners/attr`，
  保留原始 Java 句柄、对象身份和原生方法，不换成 marker。点击监听使用真实 Android listener。
  当前实现的原生事件为 click / long_click，其他事件明确报不支持；不能据此宣称完整 View 事件兼容。
- `Widget.view` 和 `Widget.of(view)` 绑定同一个真实 View；XML 中显式属性与
  `initialAttributes` 的自定义 setter 都执行。运行时 `attr('color', value)` 调用组件 setter，
  基础属性使用已有 `ViewAttributes`，实际应用在 Android 主线程。
- `MaterialButtonAttributes` 继承 `TextViewAttributes`，同时支持 Material 图标属性及基础 text/hint。
- Node Activity 默认只用 `NEW_TASK` 复用宿主任务；脚本显式提供的 flags 仍保留。
  没有更换三引擎架构、增加进程或修改原始 colored-button 示例绕过问题。
