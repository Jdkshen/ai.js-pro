## 二、UI 原型（落地时按此实现）

### 2.1 列表项
```
┌────────────────────────────────────────────────────────┐
│ 名称（含内置/第三方标记）                    [状态徽标] │
│ 状态：未安装 · 已安装 v1.2.0 · 可更新到 v1.3.0（+大小） │
│ 说明（一行，来自清单 description）                      │
│ [下载安装] / [更新] / [卸载]或[停用]   ← 按状态给不同按钮 │
│ 下载中：进度条 + 45%（1.2 MB / 2.7 MB）                 │
│ 失败：网络不可达 · 校验不符（sha256）· 包名不符 · 无权限 │
└────────────────────────────────────────────────────────┘
```

### 2.2 状态机（判定优先级，单一来源）
1. `installing/downloading(item)` → **下载/安装中**（显示进度；按钮禁用）；
2. `manifest` 有该 id 且本机已安装的 `versionCode < manifest.versionCode` → **可更新到 vY**（按钮「更新」）；
3. `installed(item) == true` → **已安装 vX**（按钮「卸载」/「停用」；卸载需系统确认，见 2.4）；
4. 其它 → **未安装**（按钮「下载安装」，来自清单的大小/说明）。

### 2.3 失败原因（可读映射，禁止只显示异常字符串）
| 现象 | 用户可见文案 |
|---|---|
| 连接失败/超时/DNS | 「下载失败：网络不可达（源：<自动选的源>）」 |
| HTTP 非 2xx | 「下载失败：源返回 <code>」 |
| sha256 不符（清单有） | 「下载失败：文件校验不符（sha256 不一致）」 |
| 下载落盘的 APK 包名不符 | 「安装包与清单不一致（包名不符）」 |
| 系统安装被拒/无权限 | 「系统未允许安装（请在系统里允许本应用安装未知来源应用）」 |
| 清单里没有该 id | 「清单未收录该插件」 |

### 2.4 安装完成后
- 复用现有确认口径：`installPlugin` 返回 `true` 表示**已打开系统安装界面**（不是安装完成）⇒ 文案保持「已打开系统安装界面，安装状态以返回后的目录为准」（`catalog_page.dart:222`）✓；
- 返回页面后 `load()` 重新读目录 ⇒ 若版本变化则提示「已更新到 vX」；
- **是否需要重启**：由清单字段 `requiresRestart`（或「插件类型 = 引擎/OCR/打包」）决定 ⇒ 是则提示「**已更新，需重启应用生效**」（一次性提示，不弹窗阻塞）。

### 2.5 卸载
- 今天**没有**卸载桥 ✗。建议：**先只做「停用」**（已有 `pluginSetEnabled` ✓、**零新风险**），卸载作为后续项（要 `ACTION_DELETE` + 系统确认 + 目录一致性，属 W2/W1 面）。**原型按「停用」交付**，文案用「停用（仍占用空间，删除请到系统应用管理）」。

## 三、复用清单（**不另造 URL 逻辑**）
| 复用对象 | 方法/常量 | 用途 | 落地时怎么用 |
|---|---|---|---|
| `PluginDownloads` | `pluginUrl(Context,String fileName)`（:32）、`defaultSourceUrl(String fileName)`（:42） | 源解析（GitHub Release + gh-proxy 加速、失败直连） | **只在原生侧**解析；Dart 只传清单里的 `fileName`/`id`，**绝不自己拼 URL** |
| `PluginDownloads` | `isExpectedPackage(Context,File,String)`（:53） | 下载后包名校验 | 原生侧下载完立刻校验，失败即报「包名不符」 |
| 现有桥 | `pluginStates`、`pluginSetEnabled`、`installPlugin{path,packageName}` | 已安装/停用态、启停、拉起系统安装 | 三态 UI 直接复用；**不新增重复能力** |
| `VersionService` | （插件被明确排除，:414-416） | —— | **不要**把插件塞进主程序更新路径；插件版本一律以新清单为准 |
| 现有 UI 机制 | `catalog_page.dart` 的 `notify/readable/load/installing/disabledPlugins` | 提示与刷新 | 新按钮沿用；进度用逐项 `downloading` map（同 `togglingPlugins` 的写法 ✓） |
