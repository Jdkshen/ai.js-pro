## 已复现的根因

小米 8 / Android 15，在公开 dev-1266 上运行原始 `听海UI.js`：

1. 首次启动出现系统“AI.js Pro 没有响应”。
2. 同一份源码仅添加计时日志后，`setup` 用时 **5562 ms**。
3. 系统记录焦点事件等待 **5004 ms** 超时；随后 MCP 返回 `Node24 service disconnected`。
4. `ApplicationExitInfo` 记录对应 `:node24_1` 进程 **reason=6 (ANR)**，描述为 `user request after error: Input dispatching timed out`；crash buffer 没有新增 native fatal。

因此，在这台测试机上已证明：服务断开可以由 UI 主线程无响应后被结束造成，不能仅凭这条错误就判定 native 崩溃。原报告所述 Android 16 / Mali 的随机断开尚无对应退出记录，不能用小米 8 的结论替代原设备证据。

原实现将整段 `ui.runOnUiThread(fn)` 包进 Java `Runnable`，Android 主线程同步等待 Node 完成整个 JS 回调。创建复杂布局超过 5 秒会触发 ANR；超过 JNI Java→JS 回调的 10 秒期限还可能结束 Node 会话。

另外，宿主 Java 对象表对 Bitmap 等对象持有强引用，没有发现“JS 包装对象 GC 就自动 recycle 原生 Bitmap”的路径。保留现有图标缓存，不增加盲目的 recycle 或弱引用改造。

## 底层修改

- `node24/ui.js`：延后执行 UI JS 回调，先固定 JNI 宿主工作线程，再进入同步 Java UI 调度范围；回调返回、异常、嵌套 Promise 均释放调度范围。
- `Node24HostBridge`：同步 Java 构造、字段及方法逐次交给 Android 主线程，包含类型化 JNI 路径和无参 JSON 缓存路径。使用线程局部状态，显式异步 Java 调用继续使用原执行器。
- Android 28+ 使用异步主线程 Handler，避免每一次桥调用都等待绘制同步屏障；较旧系统保留 Handler 回退。
- 支持时，对当前内容根布局合并同步回调中的布局请求；返回或抛错时恢复状态，保留脚本事先设置的布局抑制，减少中间树的重复测量。
- 保留真正需要同步返回值的 Java 接口回调；不删除 native 回调超时，也不使用自动重启掩盖故障。
- 更新 `NODE_UI_API.md` 并重新生成 App / MCP 共用的离线文档。

## 项目副本的修正

修正版位于本次独立产物目录，不覆盖原 ZIP，也不将其字体、图标加入仓库：

- `onUi` 接收 Promise 拒绝，避免外围同步 try/catch 漏掉异步错误。
- 主脚本的 Bitmap/Path/Paint 计算改由 `ui.post` 留在 Node 宿主工作线程，View 构造和操作由引擎自动回到 Android 主线程；保留同步 Java UI 语义的通用接口 `runOnUiThread` 不做这一替换。
- 正确保留 Android 布局常量 `-1` / `-2`；它们不能按 density 缩放为 `-3` / `-6` 等值。
- 用关闭状态及界面代次丢弃销毁前排队的 UI 更新。
- 保留已有的 `icCache` 和单色 `GradientDrawable.setColor` 分支。
- README 不再将 native 崩溃、位图 GC 推测写成已证实结论；保留原始报告作为历史证据。
- M3 文件的字体绝对路径改为基于 `__dirname` 的相对路径，修复换目录后的 ENOENT / Font asset not found。
- 报告附录 R2 的 `0xFF46617F` / `0xFF8A6B86` 会选中 ColorLong 构造器，实测抛 `Invalid ID: 63`；改为 `value | 0` 后成功。原主脚本使用 `Color.parseColor`，不受此处影响。不改变通用数字重载规则，以免截断正常 long 参数。

### 启动性能仍需继续优化

安全调度避免持续占用 Android 主线程，但增加了跨线程调用成本。原写法单次构建计时为 5562ms，同时触发 ANR；最终通用 `runOnUiThread` 写法单次约 16975ms。本项目将绘图留在 Node 侧后为 **12242ms**，仍不能称为完成了启动提速。这些是单次真机记录，不是统计性能基准。

后续优先做有明确线程、返回值及异常边界的桥批处理、程序布局向 XML/原生列表迁移、首屏优先与隐藏页懒加载；不要为了数字变好，重新让整段 JS 阻塞主线程，或悄悄改变需要同步返回值的 Java 回调语义。

调度合约脚本：`modules/engine/src/test/device/node24-cooperative-ui.js`。运行时在 `COOPERATIVE_BUSY_BEGIN` 后通过无障碍把输入框内容从 `probe` 改为 `UI_ALIVE`，应输出 `COOPERATIVE_UI_PASS`。
