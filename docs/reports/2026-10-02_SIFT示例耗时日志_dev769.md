# SIFT 示例耗时日志（dev-769）

用户指出 dev-768 示例没有明确显示耗时。此前结果 JSON 的 elapsedMs 是后端场景匹配耗时，单次调用不包含模板准备，也缺少便于查看的独立日志。

## 修复

- QuickJS、Rhino 的 main.js 和 Rhino 全分辨率入口增加“匹配总耗时：N ms”。在 API 调用前后计时，包含路径解码、模板准备、匹配和可选绘图，不含日志打印、打开图片。
- 两个缓存示例分别输出模板准备耗时和第 1～3 次匹配耗时。没有匹配返回 null 时也输出耗时。
- 同步两个示例 README 及使用指南。原 API 返回值和资源清理方式保持兼容。
