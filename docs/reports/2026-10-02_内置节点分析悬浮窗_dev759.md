## 源码改动

- `InspectorFloatyWindow`：范围图和层次树共用菜单、搜索面板、属性对话框、窗口选择、文件操作和关闭清理。
- 搜索 text、desc、id/fullId、className、packageName；可切换大小写匹配、上一项／下一项、点击结果定位、长按结果查看属性。搜索面板可拖动。
- 属性表支持勾选并复制 selector 代码；默认选择 id 和 packageName，无 id 时使用 text 或 className。长按复制单项属性，idHex 只读。字符串正确转义，fullId 转为 id()，负数坐标保留。
- 范围图与层次树共用 `InspectorSession`，切换时保留节点选中状态；展开目标祖先，滚动到选中行，显示 id、父节点索引和文本／描述。
- `LayoutInspector` 在后台保留获取时各窗口的节点快照；窗口列表展示类型、层级、包名、边界和节点数量，避免在菜单 UI 线程查询其他应用。
- 布局保存为版本化扁平 JSON；默认目录 `Android/data/com.jdkshen.aijspro/files/layouts/`，读取时列出已保存文件，也可输入路径。恢复父子关系和节点标量属性，明确标注“文件快照”。
- 导入校验格式、版本、父节点顺序、坐标和属性类型，拒绝循环关系／多个根，限制 16 MB、30000 节点。文件 I/O 在后台执行。
- 修正范围图触摸事件消费、最小命中框面积计算、递归绘制和刷新；菜单夹在屏幕内；退出时关闭搜索、弹出菜单和所有对话框。
- 静态 capture 入口把浮窗创建投递到主线程；树视图使用库的对象索引接口定位，避免把内部 Node 包装对象与 NodeInfo 比较。
