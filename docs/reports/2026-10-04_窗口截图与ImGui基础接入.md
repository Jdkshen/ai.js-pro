# 窗口截图与 ImGui 基础接入

## 范围

根据用户“怎么添加 / 继续”落实窗口截图 API、象棋窗口通道与原生透明绘制。参考 Downloads 内的架构 MD；未把该文档中的性能目标当作实测结论。

- Rhino / QuickJS：images.isWindowCaptureAvailable、listCaptureWindows、captureWindow。
- Android 14+ takeScreenshotOfWindow，独立于 MediaProjection；明确失败，不回退整屏。
- 返回窗口边界、方向、宿主帧序号、开机时间戳；截图期间几何变化丢帧。
- 象棋 window 通道：固定游戏包名、屏幕坐标画布、不为截图藏显窗口；窗口变化停用旧坐标，定位校准后再使用。
- QuickJS drawing.show({renderer:'imgui'})：Dear ImGui v1.91.9b + GLES3，透明不可触摸的绘制窗口；保留最新快照，更新时渲染。
- 操作按钮使用现有面板；遮挡落子位置仍用点击租约暂避。没有迁移整个操作面板，也没有加入 NCNN YOLO 或固定 120fps。
- 应用文档、API 补全索引、Rhino/QuickJS 示例和象棋项目结构 MD 已更新。
