## 1. 问题

- 新机（Redmi 2602 / `.4`）出现手动滑动失效；注销进程内窗口后确认残留 `NodeUiCanvasView` 与 `tag=node-port-overlay` 的 TextView。
- 根因：脚本直接 `WindowManager.addView` 的 View 没有登记到任何生命周期表；MCP `stop_script` 只 `forceStop`；`Node24LocalOverlay` 曾强制去掉 `FLAG_NOT_TOUCHABLE`，绘制层会拦截触摸。
- 进程模型：Rhino/QuickJS 在 `:script`（部分场景主进程），Node24 在 `:node24`；静态注册表不能跨进程直接 removeView。

## 2. 实现

### 2.1 OverlayRegistry（engine 模块，进程内）

`modules/engine/src/main/java/com/stardust/autojs/overlay/OverlayRegistry.java`：

- `register(ownerEngineId, ownerTag, engine, Kind, view, wm, touchable)` / `unregister(view)` / `closeByOwner` / `closeByTag` / `closeAll` / `snapshot` / `size`；
- 关闭优先 `WindowManager.removeViewImmediate`，主线程执行（非主线程 1.5s 有界等待），失败兜底反射 `WindowManagerGlobal.removeView(v, false)`；
- 每次变更写 `filesDir/overlay-state/overlay-<pid>.json` 快照（pid/updatedAt/entries：engineId/ownerTag/engine/kind/touchable/createdAt/viewClass），写失败只记日志；
- 进程正常退出删除自己的快照；MCP 读取侧过滤 >30s 的陈旧文件。

### 2.2 三引擎接入

| 引擎 | 接入点 |
|---|---|
| Rhino | `ScriptRuntime` 增加 engineId；`RhinoJavaScriptEngine.init()` 注入、`destroy()` `closeByOwner`；`Floaty.JsRawWindow/JsResizableWindow` 创建成功后注册，close 前反注册。 |
| QuickJS | `QuickJsHostBridge` 保存 ownerEngineId；`QuickJsFloatyWindow.showNow/hideNow/close` 注册/反注册；`QuickJsOverlay`（canvas）与 `ImGuiDrawingOverlay` 注册为 `QUICKJS_DRAW` 并强制 `NOT_FOCUSABLE|NOT_TOUCHABLE|NOT_TOUCH_MODAL`；`HostBridge.close()` 与 `QuickJsJavaScriptEngine.destroy()` 追加 `closeByOwner`。ImGui 层因无公开访问器用反射取根 View，失败降级。 |
| Node24 | `Node24LocalOverlay` 读取 `engineId/owner/touchable`（默认 true），注册 `NODE_UI`；`touchable=false` 时保留 `FLAG_NOT_TOUCHABLE` 并清 clickable/focusable；`NodeUiHost` 注册与 `overlayParams(touchable)`；新增 `Node24DirectOverlayCleanup` 反射 `WindowManagerGlobal.mViews` 清理 `NodeUiCanvasView`/`tag=node-port-overlay`；`Node24HostBridge.handleUiJson` 注入 engineId/owner，`closeUiOverlay()` 顺序：LocalOverlay.closeAll → 主进程 floating close → direct cleanup → `OverlayRegistry.closeByOwner` → handleUiJson(close)；`Node24Service` 日志带 `direct=`；`floating_window.js` 支持 `touchable`（默认 true）。 |

### 2.3 MCP

- `McpToolCatalog` 新增 `list_overlays`、`close_overlays`（含 Pro 别名 `listOverlays`/`closeOverlays`）；
- `get_status` 新增 `overlayCount`、`overlayState`（跨进程快照聚合，不再是主进程本地 registry 数量）；
- `stop_script` 先取 engineId 再 forceStop，本进程 `closeByOwner` 兜底，返回 `overlayClosed`；
- `stop_all_scripts` / `stopRuns` / `McpService.stop()` 调 `closeAll`；
- `close_overlays(executionId?)`：有 id 走 `stop_script`，为空走 `stop_all_scripts`，400ms 后返回剩余 `overlayCount` 与 `list_overlays` 结果。

## 3. 真机验证（小米 8 / dev-1205）

| 用例 | 结果 |
|---|---|
| Rhino `floaty.rawWindow` 运行中 | `overlayCount=1`、`list_overlays` 显示 `RHINO_FLOATY touchable=true pid=14798` |
| stop_script Rhino | `overlayClosed=1`，1.8s 后 `overlayCount=0` |
| QuickJS `floaty.window` | `overlayCount=1`、`QUICKJS_FLOATY ownerTag=qjs-2`；stop 后 0 |
| Node24 `floating_window.show({touchable:false})` | `overlayCount=1`、`NODE_UI touchable=false pid=14958(:node24)`；stop 后 0 |
| 三引擎同时开 | `overlayCount=3`；`close_overlays(mcp-7)` 后 2；`stop_all_scripts` 后 `overlayClosed=1, overlayCount=0` |
| Node 直接 addView（tag=node-port-overlay，全屏 `NOT_TOUCHABLE`） | 覆盖层存在时 `adb input swipe` 列表照常滚动（截图 B/C 列表项变化，覆盖文字仍在），停止后同进程探针 `WindowManagerGlobal.mViews=[]` |
| 停止后窗口残留 | `dumpsys window windows | grep -iE "aijspro|NodeUiCanvas|node-port-overlay"` 无输出 |

单元测试：`:app:testMiuixCompatDebugUnitTest` **310 项通过**；构建 `assembleMiuixCompatDebug` 成功。

## 4. 未覆盖 / 后续

- QuickJS ImGui 绘制层走反射注册，未在真机绘制层场景验收；`ui.layout` 交互覆盖层未注册为 DRAW（避免破坏触摸交互）。
