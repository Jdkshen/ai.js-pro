# 切页浮动按钮空指针修复

用户堆栈：ViewPagerFragment.onPageShow → MiuixSampleFragment.onPageShow → MainActivity.onPageSelected，访问未绑定的 FloatingActionButton 导致空指针。

## 原因和修改

MainActivity 在 setAdapter / setOffscreenPageLimit 之后才注册页面实例化回调。增加页面缓存后，setOffscreenPageLimit 会同步创建页面，部分页面错过 setFab。现在先注册回调，再设置适配器和预加载范围；选页时也绑定实际存储的 Fragment，兼容恢复的页面实例。初始实例化和切页共用选页处理，确保上一页收到隐藏通知。

ViewPagerFragment 将按钮更新提取为独立方法。按钮尚未绑定时仍记录页面显示状态，延迟绑定后同步恢复按钮状态和点击处理，避免隐藏的预加载页面抢走当前页按钮。
