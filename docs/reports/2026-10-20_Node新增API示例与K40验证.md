## 3. 回归工具说明

tools/test-node-samples-device.ps1 只推送 .js 文件，不复制同目录资产，因此在 _node_samples_regress_ 下 #7/#8（board.png）与 #1–#6（template/hellokitty）会缺图；建议工具按示例目录同步非 js 资产，或使用任务约定的 _nodeapi_probe_ 目录整体推送方式。本次按后者完成 13/13 实测。

## 4. 已知限制

- Node24 Java 桥不支持把 Class/primitive TYPE 作为参数传给反射 Array.newInstance（已在 #12 记录 workaround 提示）；
- Packages 链可访问顶层类，嵌套类（Build$VERSION）需用 $ 写法，点号 .VERSION 返回 undefined（#11 注释说明）。
