## 二、真机验证（MI8 / dev-1360）

### 2.1 生效值可诊断（不用反汇编）

```json
get_status.limits      = {"maxProjectEntries":200000,"maxProjectBytes":2147483648,"childHeapMb":2048,"maxTimeoutSeconds":1800}
toolkit_status.limits  = 同上；原 6 条人类可读能力说明已移到 capabilityNotes（未丢）
reverse_capabilities.limits = {… "timeoutSecondsMax":1800, "maxProjectEntries":200000, "childHeapMb":2048}
```

工具 schema（`tools/list` 实测）：`apk_build_project.timeoutSeconds.max=1800`、`native_session_query.timeoutSeconds.max=1800`、`native_resident_command.timeoutMillis.max=1800000`。

### 2.2 参数闸门真的放行

`apk_build_project {projectDir:"__no_such_project__", timeoutSeconds:900}` → 报 **`projectDir 不是Apktool解包工程`**。
改前 900 会直接死在「timeoutSeconds 必须在 1..300」；现在参数放行，错在该错的地方。

### 2.3 31,001 文件工程：真的能进 apktool（本次最关键证据）

在设备上造 `smali/d1..d62/f1..f500.smali`（31,000 个空文件）+ `apktool.yml`，共 **31,001 文件**（跨过旧 30000 闸门）后跑后台构建：

```
job 90c0c505… : RUNNING 147s → FAILED
error.code      = APKTOOL_FAILED
error.message   = Apktool exit=1（子进程堆 -Xmx2048m）: I: Using Apktool 3.0.3-dirty on x.apk
                  I: Smaling smali folder into classes.dex...
                  project/smali/d1/f1.smali[1,0] required (...)+ loop did not match anything at input ''
                  APKTOOL_COMPONENT_ERROR: AndrolibException: Could not smali file: …
```

解读：
1. **没有出现**「工程文件过多或不是普通文件」——闸门确实移到 200,000；
2. 复制整棵树用了约 147s（31k 空文件在 FUSE 上，与交付方实测的「小文件吞吐 ≈1.4MB/s」量级一致），随后 apktool 真正开始工作；
3. 失败原因是我故意造的**空 smali**（非法 smali 语法），属预期失败；
4. 文案里的 **`（子进程堆 -Xmx2048m）`** 直接证明 `-Xmx` 已进真实命令行。

## 三、边界与未做

1. **31k 工程只证明「闸门放开 + 能进 apktool」**，没有证明 5.7 万文件的**真实** apktool 工程能成功回编：本次用的是空 smali，构造真实大工程需要独立样本。
2. `-Xmx2048m` 是否足够由工程规模决定；真机主进程堆 512MB、子进程 2048MB 都是「上限」，不是保证；`apk_build_project` 仍是「整树复制 + 一次 apktool」，内存峰值未优化（清单 §4 已列为未做）。
3. 清单里提到的 `NativeProjectStaging` int 参数经核实是 **depth**；`PocPackaging/PocWorkspace` 无上限——所以 flutterpoc 那三条**没改**，理由已写在上面。
4. 可选的内置 apksigner/zipalign、分片构建、工作区自动回收**均未做**（前两项需新增组件与校验链，最后一项是破坏性操作）。
5. 附带发现（不在清单内、本次未改）：`get_status` 的 213 工具/`toolCount` 与交付方一致；交付方提到的 jadx OOM 在 2048MB 下是否仍 OOM 未复测（本次没跑 jadx）。
