## 修改与逐项结论

| 报告项 | 本轮处理与验证 |
| --- | --- |
| P0-1 XML 字符串 | `ui.inflate(xml,parent,attach)` 走动态 inflater，返回真实 Java View；支持 Activity 外 inflate、正确的 parent LayoutParams 和 attach。`ui.layout(xml)` 安装根 View；无 Activity 时创建 inline Activity。 |
| P0-2 复杂构建卡死 | View 构造和调用在没有活动 UI 时也按类型转主线程；Activity 事件使用主线程 Runnable 的回调上下文。小米 8 原 dev-1221 的 40 卡/日志基线本身也通过，因此没有把报告中的非确定性卡死直接归因于某个锁；Android 16 原机仍需复测。 |
| P0-3 构建中打印日志 | 20 轮嵌套卡片构建允许逐张 console.log；没有禁止日志或替换成文件打点。现有 stdout 日志通道保留。 |
| P0-4 recreate | 重读 JS layoutXml、展开 Widget、更新 Intent 后调用真实 Activity.recreate；重建保留会话 token、保活和 callbacks，旧 Activity 不发终态 destroy，新 Activity 刷新 JS 的真实 Activity 引用。三次重建后文字为最新值，脚本继续运行。 |
| P1-1 线程 | onContentViewSet 和 runOnUiThread 内的 Java Looper 检测为 true。V8 始终运行在 Node 线程，嵌套 Java 调用在原 Android 回调线程执行；没有通过硬编码 true 伪造线程。runOnUiThread 返回 Promise，回调异常会 reject。 |
| P1-2 多方法接口 | 对象字面量自动适配 SeekBar listener / TextWatcher；所需方法必须可调用，可带额外状态字段，方法保留 JS this。补 `$java.implement(Interface,object)`。单函数 SAM 及普通 Map 参数保持原语义。 |
| P1-3 Widget 子内容 | 按元素边界展开，保留嵌套同名标签、文本、注释和带 `>` 的属性。优先注入 render 的 content/slot 容器，也可用 widget.contentSlot 指定 id；否则追加到根。无外部 id 的组件分配内部 id，仍可 mounted/Widget.of。 |
| P1-4 switch | Node inline 和共用 XmlConverter 均映射到 androidx.appcompat.widget.SwitchCompat；全限定 android.widget.Switch 保持原样。 |
| P2-1 android.R | 宿主 member/field 解析支持小写嵌套类 android.R.color / attr，继续读取真实静态字段。 |
| P2-2 Class.forName | 单参数 Class.forName 按当前任务的宿主/动态插件类加载顺序查找，并保留初始化语义；MaterialButton 真机解析通过。 |
| P2-3 console.error | 保留现有级别桥；对 ERROR/WARN 的 MCP 执行日志可见性做真机检查，未采用吞错处理。 |
| P2-4 UI 保活 | setMainActivity 现有自动 keepRunning 保留；探针不手工调用 keepRunning，跨三次重建及超过 160 秒构建保持运行。 |
| P3-1 binding 枚举 | 真 View 和 marker binding 增加 ownKeys/属性描述符；真 View 只枚举实际后代 id。避免枚举每个属性时重复扫描全部 id。 |
| P3-2 原生 View.on | require('ui') 后即安装真实 View 扩展钩子，new Button(context).on('click',...) 真实触发通过。 |

`$java.implement` 当前接收一个接口（或单元素数组）。生成 Java 子类的 defineClass 仍按原契约要求显式 Java 父类；普通监听器使用对象字面量或 implement，无需生成子类。`ui.run` 保留 Node 同步执行语义，`ui.post` 保留定时调度语义；需要 Android 回调上下文时使用 `await ui.runOnUiThread(fn)`。Promise 后续 continuation 仍运行在 Node 线程。
