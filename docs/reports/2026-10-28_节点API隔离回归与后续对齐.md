# 节点 API 隔离回归与后续对齐

基线：DP 已将上一轮工作提交为 `0278ced3`，dev-1279 已发布 LAN 并安装 MI8。此报告记录在该提交之后的 dev-1280 测试候选；当前 LAN 仍为 1279。

## 本轮改动

1. 修正混合筛选的候选截断：Remote 只要有本地条件就对保留快照应用完整的宿主条件与本地条件交集，避免先取 500 条导致漏掉后面的匹配。纯宿主条件保留快速通路。
2. Node 的 `textMatches + where` 不再与宿主前 500 条结果按 path 取交集；改为批量 Java Pattern 完整匹配。保留 Java 的内联标志与引用语法，非法输入明确报错。
3. Remote Rhino、QuickJS 补齐 `filter/addFilter`；Node 增加同名方法，回调都用方法式节点。Node 原有 `where` 保留属性式节点。回调在引擎内对快照运行，错误不吞掉。
4. BFS/DFS 真正下发给宿主并按队列/深度遍历，未知算法报错；修正原生 BFS 正数 limit 多返回一项。不会对截断的 DFS 快照排序冒充 BFS。
5. 三引擎增加 `getRangeInfo()` 读取范围；Node 同时提供属性式 `rangeInfo`。非范围控件返回 null，快照需要重新查询才能反映后来的进度。
6. `node.find` 在保留快照上按子树过滤、再运行谓词/计数，且包含自身，对齐 Native UiObject；Node `select.from` 仍只取后代。原生数值范围校验同步；QuickJS progress 不再偷偷将字符串/布尔转成数字。
7. 新增三套同名“节点查询进阶_只读.js”示例；更新 API 指南和离线/MCP 文档索引。
8. 真机发现原生 QuickJS 的谓词异常被反射包装成 `InvocationTargetException`，丢失原始信息；解包后保留原异常类型、消息与调用栈，追加 4 项 JVM 回归并在最终 APK 复测。

## 能力与边界

| 类别 | 可实现性与当前状态 |
|---|---|
| 属性、通用动作、父子/范围查询 | 1279 已接入；本轮补隔离入口回归和上述漏项 |
| 自定义谓词 | 三引擎可用；隔离路径是快照语义，不能假称拿到主进程的活 Java UiObject |
| BFS/DFS | 基本宿主条件可真实执行；BFS 与本地谓词/JS RegExp/范围快照组合暂明确拒绝 |
| 大树完整性 | 仍有约 200 KiB JSON、5 秒、节点/深度预算，直接查询最多 500 项；分页与完整性标记尚需后续协议改造 |
| 极大下标、跨布局稳定身份 | Node 的读取 index 上限仍为 255；完整跨布局身份需宿主 token，当前动作仍使用路径及属性保护 |
| 其他高级版细节 | `idStartsWith` 的短资源名规则、窗口切换、原始 Java 节点所有继承方法尚不能称完全等价；已确认技术上可继续做 |

`true` 只代表 Android 接受动作；本轮受控界面会另外检查输入、按钮计数、勾选和进度的实际变化。集合空结果不能被解释成已操作控件。
