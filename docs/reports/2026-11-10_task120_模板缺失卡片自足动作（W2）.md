## 二、「缺少打包运行时模板」区块的显示条件（写清）
- 显示点：BuildScreen() 里 if (!templateReady) { TemplateNoticeCard() }；页面进入与 onResume 都调 refreshTemplateState()。
- 判定：templateReady = ApkBuilderPluginHelper.templateStatus(this).available。available=false 需要**同时**满足：
  1) /sdcard/template.apk 不可用（不存在或不满足 isUsableTemplate）；2) 宿主缓存 files/apk-builder/&lt;versionCode&gt;/template.apk 不可用；3) **内置 assets/template.apk 读不到**（正常设备不会发生：它随包分发）；4) 插件也未安装。
  ⇒ 换句话说：**只有「内置模板都拿不到」才会显示这张卡**；不装插件的正常设备走的是 merged 内置路径，这张卡不出现。
- 卡片内容：标题（缺少打包运行时模板）+ 详情（自足三条修法，文案在 strings.xml）+ templateDetail（source/detail）+ **唯一按钮＝清缓存并重新检测**。
- 打包前还会再过一道 validateTemplate()：失败时给同一条详情文案 + 手动放置路径（manualTemplateFile().path），不引导装插件。
- 说明：ApkBuilderPluginHelper.templateStatus 的**判定逻辑本轮未改**（只删了 UI 侧的插件动作）；卡片文案由 W4 维护。
