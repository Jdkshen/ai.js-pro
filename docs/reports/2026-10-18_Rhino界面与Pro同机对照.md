# Rhino UI 与 Pro 同机对照

2026-10-18。用户要求查看手机当前界面，不一致时运行高级版对照。代码由 DP 实现，Codex 负责定位、审查、集成和真机验证。

## 对照对象与发现

- 同一台设备 `DQKFJB59596L45BI`，屏幕 1280×2772、density 520。
- 同一份原始脚本 `/sdcard/脚本/hz_ybzj/main.js`，标题为“华仔部落-佣兵战纪脚本”，首行 `"ui";`，使用 Rhino；不是此前的 Node M3 示例。
- 自有应用 `com.jdkshen.aijspro` dev-1033；参照应用 `com.boyai.auma` Pro 9.3.11-0（9131100）。两次都确认顶层为对应包的 `ScriptExecuteActivity`。
- 原始脚本未修改。只启动界面，没有点击注册、绑定、续期、检查更新等业务按钮。

| 控件 | dev-1033 高度 px | Pro 高度 px |
| --- | ---: | ---: |
| 点击注册（无显式 style） | 120 | 120 |
| 检查更新 | 62 | 156 |
| 获取注册码 / 绑定注册码 / 解绑注册码 / 注册码续期 | 各 62 | 各 156 |

显式 `style="Widget.AppCompat.Button.Colored"` 的按钮在 dev-1033 变成黑字、缺少内边距的文字条；Pro 为白字居中的完整按钮。dev-1033 状态栏是浅色，Pro 与青绿工具栏同色。设备尺寸和 DPI 不符的警告在两边都有，是脚本自身提示。

对照截图和 UI 层级保存在 `output/node-ui-compare/`：`current.png`、`dev1033-hierarchy.xml`、`pro-reference.png`、`pro-reference-hierarchy.xml`、`initial-button-bounds.json`。`pro-open.png` 只是透明 OpenActivity 的过渡画面，不作为 Pro 渲染成功的证据。

## 修复

`DynamicLayoutInflater.constructView()` 原先仅解析带 `@` / `0x` 前缀的样式。裸名称保留了非空 style 标记，却把全零样式参数传给四参数构造器，跳过 Button 默认样式。

DP 的修改使裸名称也通过资源解析，查不到样式时回退默认构造路径；保留既有 M3 构造器回退和 AppBar 参数修复。没有针对本脚本硬编码按钮尺寸、颜色或名称。

ScriptTheme 的默认状态栏改为跟随工具栏主题色，使用白色系统图标；移除原先与 Miuix 宿主页面配色绑定的夜间覆盖。Flutter / AppTheme 和 Node Activity 主题未修改。

本轮精确基线保存在 `output/node-ui-compare/baseline/`；此前已有的用户修改及 dev-1032 / dev-1033 修复继续保留。
