## 备注
- 42 的新阻塞点是 Java 类路径访问：样例写 `const KeyEvent = android.view.KeyEvent;`，Node24Host 收到 `class name=android.view` 即报“不能省略包名”；需兼容 `android.*` 路径式类访问（或样例改 `Java.use`/字符串全名）。
- 48 需要确认：lockScreen 后屏幕熄灭导致脚本线程被冻结；Auto.js 通常靠 keepRunning/wakelock 保活，Node 样例可能需 host 侧在 lockScreen 前持有 wakelock，或用 `wakeUp` 前恢复。
