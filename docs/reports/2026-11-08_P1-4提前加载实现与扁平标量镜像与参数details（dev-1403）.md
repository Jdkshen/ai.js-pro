## ① P1-4 提前加载：受控 in-place DT_NEEDED 写入器

新增 `ToolkitElfNeeded.kt` + 接线（`ToolkitGadgetPreload.plan` / `AndroidReverseRuntime` / `ToolkitGadget.prepare(patchedEntries)` / `ToolkitReverseTools` schema）：

| 项 | 内容 |
|---|---|
| 支持 | ELF64/ELF32、小端；有节表按 `SHT_DYNAMIC`+`sh_link`，stripped 走 `PT_DYNAMIC`+`DT_STRTAB/DT_STRSZ` |
| 安全 | **不改文件大小**（只复用 `.dynstr` 同名串或节尾 NUL padding；只用「改后仍保留终止 `DT_NULL`」的空槽；不移动节/段/PT_LOAD）；原子写；失败**不产出 APK** |
| 自校验 | 重解析 `DT_NEEDED`/串/大小/`changedRanges` |
| 失败码 | `NOT_ELF` / `UNSUPPORTED_ELF_CLASS` / `UNSUPPORTED_ENDIAN` / `NO_DYNAMIC_SEGMENT` / `DYNAMIC_NO_SPARE_NULL` / `DYNSTR_NO_ROOM:<need>x<have>` / `DYNSTR_INVALID` / `VERIFY_FAILED` |
| 接口 | `apk_inject_gadget{preloadMode:"dt_needed", preloadTarget?}`；成功才 `earlyLoad=true/preloadImplemented=true`；失败抛 `PRELOAD_DT_NEEDED_FAILED` + `details={preload JSON}` |
| 测试 | `ToolkitElfNeededTest` **9 项**（ELF64/32 × 有节表/stripped × 能打/不能打，含槽位与大小不变断言）；合成 APK 内选择目标用例 |

**K40 真机**：`real.apk` → 逐目标 `DYNSTR_NO_ROOM:17x0`（明确建议"不要插入字节，改用外部 patchelf 或换目标 .so"）；`template.apk` → `PRELOAD_NO_NATIVE_LIBRARY` + `nextActions`。两者都**没有产出半坏 APK**。

**边界（如实）**：成功路径只在合成夹具上验证，返回 `runtimeVerified=false`；真实 `.so` 的 `.dynstr` 常紧排（试的 `real.apk` 就是 0 padding）→ 会明确失败并回退到 `patchelf --add-needed … --page-size 16384`（现为文档化推荐回退）。`<clinit>` 仍只评估。
