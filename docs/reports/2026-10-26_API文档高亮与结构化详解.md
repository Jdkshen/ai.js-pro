# API 文档语法高亮、主题同步与结构化详解

用户要求文档代码有高亮、美观易读，补充 API 细节供人和 MCP 共用，并跟随 App 主题。最终版本 dev-1259；最终包验收与发布状态见下方。

## 变更

- 离线语法高亮：JavaScript、JSON、XML/HTML、Java、Shell、CSS。内置 PrismJS 1.30.0，仅在条目展开时分词；手动模式，不自动扫描整份索引，不发网络请求、不执行示例。未知语言或超过 64000 字符保持可读原文。
- 保留字符：使用 Prism token 树与独立 HTML 编码，避开默认编码将 NBSP 换成空格的行为；高亮后再次比较 textContent，异常回退原文。复制使用装饰前原始代码，中文、emoji、缩进、制表符、CRLF 和转义内容保持不变。
- 代码框显示语言/行数，支持自动换行与横向滚动切换；偏好跨搜索/分页保留。条目区分引擎与示例数，详细条目增加章节导航、参数表、层次和更统一的间距；窄屏工具条无横向溢出。
- 原生 `DocumentationActivity` 监听 AppThemeRepository，深浅模式和主题色即时同步到 WebView 与系统栏。语法色分别配套深浅背景，主题色调整到可读对比度。uiMode/旋转配置变更保留 WebView，切换主题不重新加载搜索和滚动；同步 URL 的主题参数，避免重载/历史恢复先用旧色。监听在 pause/destroy 解绑，JS 同步只对可信 API 首页运行。
- `API_DETAILS.md` 新增 7 篇详解：files.read/write、storages.create/get/put、Node select().firstOrNull、accessibility.takeScreenshot、image.readImage/findImage、ui.setMainActivity/Activity、ctx.loadResources。每篇 8 节：用途、引擎与调用、参数、返回值、权限与前置条件、示例、常见错误与清理、源码依据。源码核对不等于全部手机/组合通过行为测试。
- 索引 schemaVersion=3，**764 条/30 来源**；每条新增 sections/examples，HTML 与 Markdown/代码仍由同一来源生成。前两篇跨引擎契约，后五篇仅标 Node，现有传统 Rhino 范围保留。MCP 与 App 均优先呈现匹配的当前详解。
- MCP `read_api_doc` 新增可选 section/includeExamples；搜索返回 sectionTitles/exampleCount，读取返回目录及 examples:[{language,code}]。section 精读参数/返回值等，不存在则明确报错。分页时不额外返回完整代码数组，examplesOmittedReason=paged_content；includeExamples=false 可只读说明。原 Markdown、UTF-16 分页与 indexSha256 防错配契约保留。serverInfo 1.8.0，工具名称仍 59+9=68。
