# 听海原版界面对齐与点击闪屏修复

日期：2026-10-27。交付私有工程 1.2.0，入口 main.js / Node.js；宿主沿用已装 MI8 的 dev-1267 候选，未发布宿主更新源。

## 用户反馈与修复

用户补充“所有操作点击都会闪一下，等一会才显示界面”。代码中确实存在先移除旧层、逐个跨 Java 桥创建控件，随后异步重画的链路。首页还一次创建全部歌单，曲目列表逐行读取原生播放状态；普通设置变更使无关页面失效。

本轮修复：

1. onUi 嵌套调用在同一批内直接执行，不再重复排队露出中间页面。新页面在离屏构建，收到实际布局回调后再移到前面并移除旧层；导航在提交期间排队。
2. 普通开关读取真实存储回填自身，不重建整页；播放/暂停、喜欢和进度更新已有控件。全局主题确需重建时也保留旧画面直至新层就绪。
3. 标签页缓存按各页相关数据判断失效；播放历史、队列位置等不会让全部标签重建。首页歌单初始两行、曲目初始八行，滚动接近底部再追加。
4. 文本的基本属性在 XML 中一次设置；播放器骨架一次 inflate；SVG 优先使用 AndroidX 原生 PathParser 并缓存缩放后的路径。
5. 图片解码延后到布局提交后，复用已解码的大图，主题相同封面回调去重；不为封面到达反复清空根界面。
6. 真机连续点击曾抓到 Android 15 PopupWindow.alignToAnchor 的 LayoutParams 空指针。当前菜单改为无旧锚点监听的 Dialog 窗口，切换主题及页面不会继续依赖被移除的锚点。早期含错误报告页的录屏已明确判为无效，不能用“无纯色帧”掩盖崩溃。

## 原版对照

参考 APK com.tinghai.music 3.0.9 / 27，SHA-256 bb55c434c8c07df2c3fef6e7eed198381d7b7548e27b8d94ff50bb712d7aa67b。

在 MI8 1080×2160、密度 2.75 上直接运行原版取证：五个主标签、首页捷径、设置四组、导入、历史、统计及晴天完整播放器。实际头像/捷径图案取自用户提供的 APK；矢量图标使用 Google Material 图标。

同一首晴天：播放器背景 #1b211f、按钮底色 #344c44 在原版与重建版实测像素一致；标题顶部 1099 px 一致，艺人 1204 vs 1203 px，控件仍有 1～3 px 的舍入差异。动态色来自原版反编译结果的 8 色 AndroidX Palette 过滤/量化，再用 Material Score/TonalSpot；不是固定写死绿色。

## 验证记录

- Node 桌面 52 项：媒体库原子落盘、队列与异步回调、追加队列保持原播放器与播放位置、真实加密向量、接口转换/取消、两歌词源、SVG 边界、专辑取色。
- 首次播放器构建旧测点约 1150 ms；优化后暖开两次为 250 / 166 ms。这是同一台 MI8 的局部 UI 构建/提交计时，不是所有设备、网络或冷启动保证。
- 深色／浅色／跟随系统菜单连续切换三次通过；原版图片与动态色复核；滚动追加、播放菜单、节奏音调、睡眠弹窗均已在 MI8 打开检查。
- 最终连续 12 项：两次纯黑切换、返回、九次标签切换通过；逐项核对真实 selected 状态并排查错误报告页。有效录屏 113 帧，内容区域纯色空白帧 0、白闪帧 0（540×1080 可变帧率录屏，不等于逐个 60Hz VSync 验证）。
- 实际 MediaSession 验证 PLAYING(3)、position=1562 ms → PAUSED(2)、position=1907 ms；最终脚本无 UI ERROR 日志。
- 修正重建容器内的父节点移除、标签就绪前保留旧页、先显示新页再隐藏旧页，以及已测量视图不再次发 onLayoutChange 时的真实尺寸回查，避免返回空白及后续点击一直排队。
- 冷首次构建复杂页仍可有约 0.8～1.6 秒；本轮消除的是中间空白/重复清空，并改善复用后的响应，未把所有首次点击或联网延迟认定为已经消除。

## 实现边界

- 保持原有真实接口、队列、下载、MediaSession 与独立脚本资源回收能力。本轮未重建宿主 APK，也没有把全三引擎 API 兼容性重新认定为全部通过。
- 当前 MediaPlayer 不支持原版的跳过无声片段/响度标准化，两项 UI 禁用；缓存页如实描述封面缓存，未冒充原版音频缓存。
- 在线推荐和封面内容随服务器变化；部分歌词、队列和菜单排版仍有差异，因此不能宣称逐像素/全部功能 100% 一致。QQ/酷狗完整分享链接导入仍需真实样本验收。
- 本轮只使用 MI8，K40 象棋任务未动；Android 16/Mali、独立打包 APK 没有重新完成本轮回归。
