# Node24 控件 API 完善与验证

基线为 DP 后续发布并安装到 K40 的 dev-1093。用户授权暂停象棋识别后，由 Codex 负责方向、集成、复核和设备验证，DP 分别实施 Java 桥和 JS 选择器适配。仅操作 K40 `cccc62c7`，未操作 MI8。

## 本批修改

- `Node24AutomationBridge` 增加 `findNodes/getNodeInfo/getLatestNodeDump/clickNode/longClickNode/setTextNode`；复用每任务连接和结束释放，移除 JS 扩展自己反射绑定客户端的路径。
- Java 和 JS 均拒绝未知字段、错误类型和越界条件；未找到返回空结果，宿主协议错误继续抛出。关闭服务时，即使后端尚未刷新 ready，也不能继续执行动作。
- 保留原方法式 UiObject，增加内置 Node 示例使用的属性式 NodeView 与 `firstOrNull/findFirst/where/atMost/atLeast/from/all/root/tree`；正则、直接子节点数与根路径可用。
- 异步等待使用 Node timer；`waitFor` 只把 NotFound 转为 false，服务错误继续抛出。
- 节点动作携带快照路径和身份条件，空文本也保留，筛选后的序号和选择器变更不会改写节点目标；页面变化造成匹配失败时返回 false，不对点击/输入做坐标兜底。
- 主进程节点元数据新增 `childCount/scrollable/editable/indexInParent`；子树查询不再混入其它分支。
- Java 正则混合本地筛选仍交给 Java 匹配，避免 `(?i)`、`\Q...\E` 被 JS 正则错误解释。
- 修复 Java 代理已经包装后又读取 `$obj/$arr/$class` 而触发重复反射查询的问题。

用法见 [Node24 控件选择器 API](../guides/Node24控件选择器API.md)。未修改 C++、Flutter Dart、AIDL、权限默认值或 inrt 模板。
