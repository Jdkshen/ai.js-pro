# 修「悬浮输出日志窗口一片空白 / 不翻滚」（dev-1409）

## 症状

用户的 Nycspro（诺亚传说辅助）跑起来后左下角输出日志「不翻滚」；追问确认：**窗口里根本没有内容/不更新**。
K40 上按脚本调用顺序复现：窗口有标题栏但内容区**整片空白**。

## 真因①（主因）：`show()` 之前的 `setSize` 被丢弃 → 列表 0 高

脚本惯例：

```js
console.setSize(device.width/5, device.height*0.5);   // ← 此时窗口还不存在
console.setPosition(0, device.height*0.5);            // ← 记住了（mX/mY，onCreate 补应用）
console.show();
```

`ConsoleImpl.setSize()` 旧实现：

```java
public void setSize(int w, int h) {
    if (mShown) { ... ViewUtil.setViewMeasure(mConsoleFloaty.getExpandedView(), w, h); }
}   // mShown == false 时：什么都不做，尺寸被丢掉
```

→ 展开视图保持 `WRAP_CONTENT`，而 `floating_console_expand` 里日志列表是 `layout_weight=1 + height=0dp` → 量成 **0 高**。

**真机诊断铁证**（临时 `ConsoleGeom` 日志，dev-1409 前）：

```text
tick=201 selfH=0 selfVis=0 rvH=0 rvW=0 rvVis=0 rvChildren=0 adapterCount=201 filtered=201 firstText=LINE-1
```

数据一直在、就是没渲染。**修**：记住 `mWidth/mHeight`，在窗口 `onCreate` 与展开视图 inflate 后调用 `applyPendingSize()` 补应用。

## 真因②：跟随判定把「未布局」当成「用户上翻」

`refreshLog()` 里 `follow = findLastVisibleItemPosition() >= size-2`，而 `notifyDataSetChanged()` 之后瞬时返回 `-1` → 恒 false。
**修**：`lastVisible < 0` 也按跟随处理。

## 验证（K40 dev-1409）

```text
修前：窗口内容区空白（selfH/rvH 全 0）
修后：LINE-143 … LINE-150 + MARKER-DONE-150（末行可见 = 自动跟到底）
```

## 走过的弯路（记录）

1. 先怀疑窗口太窄（`width/5`）→ 加宽到 0.7 仍空白 ✗；
2. 试 `notifyItemRangeInserted` 增量插入 → 变成「有数据零子项」更空 ✗（已回退）；
3. 在子视图上加兜底高度 → 被父布局 `weight` 覆盖 ✗（真因在窗口尺寸，已移除该兜底）；
4. 点折叠/展开按钮 → 无变化（窗口并非折叠态）✗。

**教训：先量几何（getHeight/getChildCount）再改代码。**
