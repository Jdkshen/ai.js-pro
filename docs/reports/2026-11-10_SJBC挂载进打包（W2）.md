# SJBC 挂载进「项目配置与打包」（W2 / task-80）

依据：device4 Download/DSH-Go/AIjsPro-挂载SJBC到手机打包.md（4086 B，2026-11-10 01:27）；本文只实现 **§一 接法 A/B 的共同前提**（随包分发 + certSha 对齐）与 **§四 的对应关系**，**不实现** main.js 加载器与 VM（见边界）。

## 1. 改动清单

1) **随包分发（纯逻辑）** apps/app/src/main/java/com/jdkshen/aijspro/autojs/build/SjbcPackaging.kt
   - findSourceDir：工程内 assets/sjbc/ 优先，兼容 sjbc/（md 约定目录）；
   - collect：**只收 .sjbc 与 manifest.json**（保持子目录结构），**不碰**其它 assets、**不进**任何脚本加密/编译流程（md「不要把 .sjbc 当脚本加密产物再套壳」）；
   - patchManifest：把 certSha 写进 manifest，返回 changed/previousCertSha/warning；manifest 缺失或为空 → 合成最小字段（version/certSha/package/files，只写真实已知值）；
   - certSha256(Certificate) / normalizeCertSha(指纹字符串)（AutoSigningIdentity 给的是冒号分隔大写 → 归一成小写 hex）；
   - describe()：打包日志一行。
   > 实现用 **gson** 而不是 org.json：org.json 在 JVM 单测里是 android.jar stub（"Stub!"），换 gson 后这段纯逻辑才可测。
2) **接线** apps/app/src/main/java/com/jdkshen/aijspro/autojs/build/ApkBuilder.java
   - 新增 setSjbcCertSha(String) + stageSjbcAssets()，在 build() 里紧随 copyProjectToWorkspace()/removeDisabledFeatures() 之后执行（在打包之前）；
   - stageSjbcAssets()：收集 → 逐文件拷进 <workspace>/assets/sjbc/ → 用 certSha/packageName/sjbc 文件清单重写 assets/sjbc/manifest.json → 打日志：
     C-PKG: sjbc certSha=<hex|(unavailable)> package=<pkg> files=<n> manifest=<true|false> source=<dir|(none)>
   - manifest 的 warning（首次对齐 / 证书变了必须重编 / 没拿到证书）进 logcat（W）与 getPackagingWarnings()；
   - **没有 .sjbc 时：findSourceDir 返回 null → 直接 return，零行为变化**（有单测钉住）。
3) **certSha 来源（单一事实，按优先级）**
   - ① 调用方显式 setSjbcCertSha(...)；
   - ② mAppConfig.getSigner() 若是 KeyStoreApkSigner → getSigningKey().getCertificate() 现算 SHA-256（**就是真正签名那把**，自定义 keystore 也一致）；
   - ③ 兜底 AutoSigningIdentity.certificateFingerprint()（归一）；
   - 三个都拿不到 → 不伪造：manifest 不写 certSha + 明确 warning。
4) **tools/sjbc/ 入库**（device4 /storage/emulated/0/脚本/sjbc-tools/，**逐字节原样**，字节数与设备一致）
   ajs2sjbc.js 27127 / opcodes.js 1105 / pack_v5.js 3137 / keyderiv.js 671 / vm.js 5450 / sjbc-pack.mjs 3545 / sjbc-pack.js 2885 / build_all.js 2533；README.md 记来源与版本；**不入库** samples/ 与 out/。
   新增 tools/sjbc/build-all.mjs：node tools/sjbc/build-all.mjs --src <dir> --out <dir> --cert <apk|sha256> [--deploy-to <dir>] [--check]
   —— 只解析参数 + 把 build_all.js 顶部 4 行配置（srcDir/outDir/certSha/deployTo）替换后写临时文件执行，**算法一行未改**；--cert 支持 64 位 hex 或 .apk（keytool -printcert -jarfile 取指纹）。
5) **打包语义（§四）**：SJBC 模式下加密等级选「不加密」（.sjbc 自带 AES-256-GCM + HKDF）；其余三项可选再套一层 —— 本任务只做「收集什么 / manifest 写什么」，**UI 文案归 W4**（未动任何 UI 文件）。
