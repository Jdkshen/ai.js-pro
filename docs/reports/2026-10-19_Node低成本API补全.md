## 实现
| API | 实现 |
|---|---|
| accessibility.enableKeyEvents | prelude 新 API → `kind:accessibility action:enableKeyEvents` → Node24HostBridge 广播 → 主进程 AccessibilityEventForwarder 调 `AccessibilityService.serviceInfo.flags |= FLAG_REQUEST_FILTER_KEY_EVENTS` |
| accessibility.lockScreen | prelude → 宿主广播 → AccessibilityEventForwarder `performGlobalAction(GLOBAL_ACTION_LOCK_SCREEN)`（API 28+，低版本中文降级） |
| notification.requestListeningNotifications | 宿主校验通知使用权（无权限打开系统设置并抛中文错误）→ 广播订阅 → NotificationListenerService 转发通知到 :node24 → prelude 返回 listener 对象 `.on('notification')` |
| media.playMusic(URL) | Java `playMusic` 识别 http(s)/file://；MediaPlayer 直接 setDataSource(URL)；JS 包装 Pro 风格 player（duration/currentPosition/pause/start/seekTo/stop/release/awaitForCompletion/setScreenOnWhilePlaying） |
| root_automator | 新增 `node24/modules/root_automator.js` 并加入 Node24Prelude；root:true 通过 `su -c input` 实现 tap/press/swipe，touchDown/Move/Up 最小近似；无 root 中文错误 |
