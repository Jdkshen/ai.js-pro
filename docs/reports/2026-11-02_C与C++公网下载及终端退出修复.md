# C/C++ 公网下载与 HTTPS 终端退出修复

日期：2026-11-02。用户指出上一轮只给LAN下载地址。本轮把同一编译组件放到公网，补默认下载源、切换和MCP文档，并修复HTTPS安装成功后独立CLI进程仍存活的问题。

**组件已公网发布；dev-1307修正版已在MI8安装验收。APK仍提供手动测试包，主LAN更新源保持1305。**

## 下载与命令

dev-1307起，在App终端/MCP的app后端运行：

```sh
aijs-toolchain install cpp
clang --version
```

默认顺序：`gh-proxy.org` → `gh-proxy.com` → GitHub直连。网络/下载校验错误尝试下一路；参数或ABI不兼容直接报告，取消不重试。显式指定`--manifest`保留用户选择，不自动替换自托管源。

公网完整命令：

```sh
aijs-toolchain install cpp --manifest https://gh-proxy.org/https://github.com/Jdkshen/ai.js-pro/releases/download/toolchains-cpp-r29-v1/cpp-arm64-v1.json
```

dev-1306支持完整URL参数；建议升级1307，修复HTTPS完成后终端仍显示运行中的问题。局域网和自托管仍可用`--manifest`指定。

## 实现

- 新增轻量`ToolchainSources`，只在明确安装时联网，主APK不增加编译器载荷。
- `ToolchainMain`支持省略清单的公网安装，help提供三路地址；成功操作刷出stdout/stderr后明确退出这个独立app_process。宿主的状态查询仍直接读取安装快照。
- `get_build_tools.optionalComponents`返回默认installCommand、customInstallCommand、按优先级排列的publicManifests；App终端介绍、MCP指南和783条同源文档同步。
- 编译组件与1306相同：79,139,111字节 / 75.47MiB，展开226.82MiB；SHA-256 `cfecc3be3cdc5a0c0a18297f67b743ae71b6706de89f2435735e3a71fd9a9cff`。更换下载地址不要求重复安装已有相同版本。
