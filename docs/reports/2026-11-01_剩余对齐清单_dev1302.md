## 2. 这轮已修，别再重复列缺失

- 原生 `item_selected`：导航实际回调名应为 `onNavigationItemSelected`；Spinner 使用 AdapterView 的独立接口。修复后导航通知接受切换，Spinner 保留 id/parent/position/child。直接 Android listener 的返回契约不变。
- 旧兼容 Activity：补 `getSelectedItemId`、`setSelectedItemId`、`getMenuSize`、`getMenuItemId`、`menuItems`，底部栏与侧边栏共用实现，Toolbar 可读取菜单。没有把整个旧 UI 协议算作完成。
- **QuickJS 的 `$ui.inflate` 并非缺失**：兼容资产将 `$ui` 与 `ui` 绑定，MI8 dev-1301 实际直接创建文字控件并读到文本。C++ 白名单本身没有该名不能证明最终公开入口不可用。证据：`.artifacts/node-ui-menu-20261101/quickjs-ui-alias-direct-1301.json`。
- `defineClass`、Smali→Dex、super helper、原生回调、内联 binding、once/off、Node 多槽和主要进程隔离均已存在。旧 MD 写“没实现”属于过时结论。
- Node 等级 2 已有自解包源码载荷；它不是 V8 字节码。不能把有条件的编译拒绝分支误写成当前所有 Node 等级 2 均被拒绝。

## 4. 需要原场景的四项验证

1. **V01**：Android36 原机停止 RecyclerView 场景。MI8 的停止回归不能替代原机复测。
2. **V02**：真实走子＋截图＋悬浮窗的 native destroyed-mutex/SIGABRT。看门狗恢复和简单 UI 稳定均不等于根治。
3. **V03**：真正 16KB 页系统下的启动、三引擎、OCR/DNN、插件与独立 APK。当前手机为 4KB，静态 ELF 通过是必要条件。
4. **V04**：混合工程、厂商通知/窗口、冷暖启动/帧耗时/PSS 的同机对照；零散反射微基准不能证明整体更快。
