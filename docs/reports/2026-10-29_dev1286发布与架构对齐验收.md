## 架构落地

| 归属 | 默认执行内容 |
| --- | --- |
| 主进程 | Flutter、MCP/电脑连接控制面、统一日志环、运行任务代理 |
| `:script` | Rhino、QuickJS、传统脚本 Activity、普通浮窗、无障碍及其后端、节点采集、原生日志界面 |
| `:native` | 检测到原生工程的隔离运行，配套同进程 UI/浮窗 |
| `:node24_1..3` | Node 24 三槽独立运行时、对应原生 Activity 与浮窗 |
| `:inspector` | 离线节点快照显示，不加载脚本引擎 |

公共生命周期、停止计数、资源逆序回收及明确创建/注册/挂载的 Java 资源归属接入三引擎。借用框架对象不因 Java 句柄释放而被任意关闭。并发 runtime 的进程级图片状态在最后一个 runtime 退出后回置。

Node 优先请求 `process.exit(-9000)`，750 ms 宽限后升级 native cancel，第 4 次停止请求直接升级；先解绑 RecyclerView 等消费者，再禁用回调。执行返回、资源清理和 native 关闭均完成后才归还服务端及客户端槽位；清理失败/超时淘汰进程。正常退出与外部停止使用同一资源退役边界。

QuickJS JNI 销毁先撤销句柄，最后一个已进入的 JNI 所有者释放 context/runtime，清理 timer 引用；停止标记不在 evaluate 时清零。普通并发进入受到保护，显式 UI 交接保留主线程同步回调，`ui.run` 也走该入口。队列超时撤销尚未开始的 UI 回调；已经开始则先请求中断并等待回调退出，脚本不与它并发使用上下文。

MCP 脚本通过有界请求文件与 Messenger 在执行进程启动，回传真实进程/PID、执行状态、日志、结果和错误堆栈。`stop_script` 可先返回 **STOPPING**，应继续查询，实际释放后才报告 **STOPPED/RELEASED**。`hostProcess/hostPid` 是协调执行记录所在进程；Node 的真实池进程可由运行结果中的 `process/pid` 确认，不能把协调进程误当 V8 进程。

MCP 的布局、截图和 9 个 UI 动作工具通过非导出、同 UID Provider 在无障碍进程执行，大结果使用有界私有文件回传；终端 `aijs-ui` receiver 同步迁移。节点分析抓取经过预算/取消及快照令牌 IPC；音量下键转发回主进程处理分析退出，音量上键走既有全局停止链路。

日志界面从主进程订阅快照和实时批次，包含清空、会话校验、Binder death 清理及 UI 帧批量渲染。截图授权改为 ResultReceiver，requester 按 runtime 和请求代次隔离，支持本地 MediaProjection。传统 UI、浮窗按资源创建进程选择对应组件。

内置独立 APK 模板由当前 `:inrt` 重新生成，20,315,607 字节，模板 SHA-256 `2108bdb9f181f5455adeac2101b5ab07eb678372d36ab76e180daf86b7f1174d`。最终宿主内嵌模板、arm64 QuickJS JNI 均逐字节核对源码树产物。独立旧插件模板未发布更新；用户主动放置的手动模板仍优先，可能带旧代码。

## 仍有边界

这是已定义架构和生命周期的交付，不是“高级版全部 API 完美等价”。节点大树分页、BFS 组合条件、跨布局身份、高级原生控件事件、编译加密 Node 等继续按单独 API 清单推进。保留 Node 三进程池和独立节点显示进程，没有机械复制高级版单一 `:script` 布局。

用户 Android 36 原机的列表崩溃仍需原机复测；本次真机是 Android 35。真实 16 KB 内核、其他厂商系统、更多混合引擎工程及所有手势/截图模式，没有借静态对齐或本次代表用例声称全量验证。DP 本轮只读审查 QUOTA 失败，无委派产出，代码整合和验证由主助手完成。
