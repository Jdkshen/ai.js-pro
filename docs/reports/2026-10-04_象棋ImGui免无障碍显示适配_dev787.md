## 本轮修改

1. ImGui 六按钮操作窗独立于截图通道。自动、录屏、Shell、窗口截图模式均可使用，切换通道时保留小窗及收起状态。
2. 关闭无障碍时，原生操作窗通过普通悬浮窗权限显示。桥接 API 不完整或创建失败时沿用兼容面板。
3. 小窗优先使用完整面板宽度，K40 上六项操作排列为一行；避让和拖动使用原生窗口实际尺寸。
4. 保留普通截图模式的悬浮窗重叠检测、临时隐藏和恢复，以及点击时的避让处理。
5. 修复恢复上次会话时忽略显式 `start:false` 的问题。明确配置不启动时保持停止，未配置该字段时继续支持原有崩溃恢复行为。
6. 同步内置 API 文档、截图隔离指南和象棋项目结构说明。

操作窗提供：模式、开始/暂停、停止、定位、识别、更多。更多返回原有完整参数及日志面板。

## 权限与使用范围

- 小窗显示：有无障碍时可使用无障碍覆盖窗；未开无障碍时需要“显示在其他应用上层”权限。
- 录屏截图：需要录屏授权；Shell 截图需要对应权限。
- Android 14+ 的窗口截图仍需要无障碍服务，本轮没有改变该限制。
- 免无障碍自动走棋仍需可用的 Shizuku 点击通道。普通悬浮窗权限只解决显示权限。
- 窗口截图下的实时透明绘制，以及普通截图下暂停查看的 Canvas 标记策略维持原设计。
- 已导入到用户目录的旧象棋项目不会被 APK 自动覆盖，需重新导入示例 `0.6.57`。

### 更新源

发布脚本生成 dev-787 后，手机访问原配置的局域网地址返回 HTTP 000（K40 当前离线），脚本因此报告发布后网络检查失败。未重复发布或修改手机更新源设置。

随后验证 PC HTTP 200，通过 ADB reverse 让手机从 USB 读取同一更新清单，版本与 APK 哈希一致。再安装已发布的正式 APK，确认 `versionCode=787`、`versionName=dev-787`。
