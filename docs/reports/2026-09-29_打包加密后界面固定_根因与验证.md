# 打包加密后「界面固定、返回不了桌面」：根因与修复验证

2026-09-29，K40（cccc62c7，Android 16）。对象：象棋工程打包产物 `com.jdkshen.xiangqi.quickjs`。

## 症状（用户口径）

打包（**加密/快照**档）之后打开 App：工作台界面**固定**在屏幕上；**返回键无效**（返回不了桌面）；按 Home 回桌面后，这块界面**仍盖在最上面**，整台手机像被"钉"住。

## 根因：执行模式 `"ui";` 没有随加密载荷进入产物

打包产物的入口脚本是**加密载荷**（本包选了「快照 so」= 先编译 QuickJS 字节码再加密、密文嵌进 `libaijscrypto.so` 尾部）。
载荷的**加密头 flags** 里有一个低字节专门放执行模式（`FLAG_EXECUTION_MODE_UI = 0x0001`），实测：

| 包 | 内嵌载荷 flags | payloadType | UI 位 |
| --- | --- | --- | --- |
| 0.6.44（19:07 构建，出问题的那版） | `0x0200` | QuickJS 字节码 ✓ | **0（丢）** |
| 0.6.45（20:57 重建，本次验证） | `0x0201` | QuickJS 字节码 ✓ | **1（有）** |

UI 位丢失后，运行时按「普通脚本」执行：

- `ScriptEngineService` 只会把「带 `"ui";` 声明的脚本」路由到 `ScriptExecuteActivity`（界面是 Activity 的内容视图：Home 退后台、**返回键才结束**）；
- 旧实现里 **QuickJS 分支被排除在这条路之外**（源码注释原文：「ui.layout 只能挂系统悬浮窗——退到桌面后还盖在上面」）——
  于是 `main.js` 的 `ui.layout` 落成了**全屏 `APPLICATION_OVERLAY` 悬浮窗**：可聚焦（吞返回键）、覆盖桌面、脚本不退出就永远在。

即：**界面不是"卡死"，是"以悬浮窗形态运行的主界面"**。`dumpsys` 实证：`mCurrentFocus` 长期是那颗悬浮窗；`input keyevent 4` 发下去焦点纹丝不动。

## 修复（app 侧；已在 dev-726，20:01 装机）

1. `apps/app/.../autojs/build/ApkBuilder.java`：`writeEntryScript()` 把入口脚本的执行模式
   （`new StringScriptSource(name, text).getExecutionMode() & 0xFF`）并进 flags 低字节——
   加密 / 快照 / 加密 so / 快照 so 四个档位都会带上。
2. `modules/engine/.../ScriptEngineService.java`：`JavaScriptSource` 的 `EXECUTION_MODE_UI` 一律走
   `ScriptExecuteActivity.execute(...)`（QuickJS 与 Rhino 同待遇）。
3. 运行时读取侧原有能力即可：`EncryptedScripts.sourceOf()` 从 flags 低字节恢复 `executionMode`。
