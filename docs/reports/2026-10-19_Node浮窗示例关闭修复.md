# Node 浮窗示例关闭/停止修复（task-164，2026-10-19）

## 结论
dev-1112 新手机（520dpi/1280x2772）实测 Node 示例「悬浮日志.node.js」：
① ✕/确定 点击绑定与 hit-test 已在 overlay 内正确命中 → 点 ✕ 后浮窗关闭、script `process.exit()` 退出（exitCode=0）；
② 脚本结束/停止时清理本次创建的全部 overlay（不再常驻/叠加）；
③ 每次 show 前清理上次残留 overlay；
④ 停止链路：stopAll/取消会立即 closeAll overlay，脚本 cancelled=true、浮窗消失；任务页显示「运行中任务 空无一物」；
⑤ 覆盖 520dpi/2772 屏（真实屏幕坐标 rawX/rawY 命中，无坐标换算偏移）。

## 根因与修复
| 问题 | 根因 | 修复 |
|---|---|---|
| ✕/确定点击无反应 | `findClickableViewId` 只返回 `isClickable()` 的 view；示例 `<img id="close">`（ImageView）默认不可点击 → hit 永远 0 | 命中改为「优先 clickable，否则回退命中最深带 id 的 view」；JS `binding.on('click')` 同时向宿主机发 `setClickable=true` |
| 脚本结束/取消浮窗残留 | floating overlay 由主进程 `NodeUiBridgeService` 管理，不在 `NodeUiHost.sOverlayView` 状态里；`Node24Service.closeUiAfterExecution` 因 `hasOverlay=false` 跳过清理 | `Node24HostBridge.closeUiOverlay` 显式下发 `kind:ui op:floatingWindow action:closeAll`；`closeUiAfterExecution` 改为无条件清理；`Job.cancel` 立即清理；`NodeUiBridgeService.onDestroy` 兜底清全部 overlay |
| 多次运行叠加 | 上一次脚本结束未清主进程 overlay | job 启动时先调用 `bridge.closeUiOverlay()` 清残留，再 show |
| 停止 keepRunning 脚本 | 取消只 cancel native，UI 清理依赖 execute 返回 | cancel 路径同步 closeAll；execute 返回后 finally 再兜底 |
| addFlags/removesFlags | JS 只记录 `_flags`，宿主忽略 | 新增宿主 `addFlags/removeFlags/setFlags`（更新 WindowManager.LayoutParams 并 updateViewLayout）；show 时把 flags 带上 |
| 520dpi 命中区 | 无坐标缩放；实际问题是 clickable 回退 | 用 rawX/rawY + 完整 view bounds 命中（已验证 520dpi 屏 ✕ 命中 id=20161211） |

## task-166 停止链路残留修复（2026-10-19，K40）

| 项 | 修复/结果 |
|---|---|
| ① 停止路径主线程等待超时 | `NodeUiHost.closeOverlay` 改为非阻塞（主线程直接执行；其它线程只 post 不等待），`closeCurrent` 不再走 `runOnMain` 的 10s 等待；停止时不再抛 `等待主线程超时（Node UI 显示/关闭）` |

## task-168 Node 浮窗辅助窗遮挡 AI 球（2026-10-19 K40）

### 定位
K40 dev-1115/本机 465 构建下 `dumpsys window windows` 里 App 的 APPLICATION_OVERLAY：
- Window #6：Node 浮窗（`mAttrs=(0,200)(wrapxwrap)`，frame=[0,305][880,1677]，不覆盖左下 AI 球）；
- Window #7：AI 球本体（132x132，frame=[0,1965][132,2097]，`NOT_FOCUSABLE|LAYOUT_NO_LIMITS`）；
- Window #8：AI 球菜单辅助窗（`mAttrs=(0,0)(wrapxwrap) alpha=0.8`，当前 `mViewVisibility=GONE`、无 surface，未显示时不拦截触摸）。
→ 实际遮挡不是第三个 overlay 的静态区域，而是 Node 浮窗在示例的 `focusableOnTouch` 里 `removeFlags(FLAG_NOT_FOCUSABLE)`
后变成**模态**窗口，导致窗口外（左下 AI 球）的触摸被吞。

### 修复
`NodeUiBridgeService` 创建浮窗时基础 flags 增加 `FLAG_NOT_TOUCH_MODAL`（与 NOT_FOCUSABLE/LAYOUT_NO_LIMITS 并存）。
这样即使 JS 在 touch 回调里移除了 NOT_FOCUSABLE，浮窗仍是**非模态**：窗口内按钮/console 正常点击，窗口外触摸继续下发到 AI 球/系统。
未设置 NOT_TOUCHABLE（会破坏浮窗自身 ✕/确定/输入）。

### 验证（K40，本机 465 构建）
- 运行「悬浮日志.node.js」→ 点浮窗内 console 区域触发 `focusableOnTouch`（移除 NOT_FOCUSABLE）→ 点左下 AI 球：菜单正常展开（截图 ball-menu-after-overlay-touch.png）；
- 点菜单红色 ⏹（stop_all_scripts）→ `Node24Service execute returned cancelled=true`，5s 内 :node24 为空、浮窗消失（menu-stop-while-overlay.png）；
- 同浮窗内确定/✕：点 ✕ 后 `execute returned exitCode=0`、overlay 消失（浮窗内控件点击未被 NOT_TOUCH_MODAL 影响）。

### 限制
- AI 球菜单辅助窗（alpha=0.8）隐藏时不拦截；若后续需要在菜单展开时也避免其遮挡，可再在菜单窗口上加 NOT_TOUCH_MODAL（当前实测菜单可点，无需改）。

## task-169 AI 球菜单 ⏹ 点击被吞（2026-10-19 K40）

### 定位（z 序 dump）
`dumpsys window windows`（菜单展开、Node 浮窗同时存在）：
```
Window #6 com.jdkshen.aijspro  mAttrs=(0,1900)(wrapxwrap)  Node 浮窗
Window #7 com.jdkshen.aijspro  mAttrs=(0,1860)(wrapxwrap)  AI 球（132x132）
Window #8 com.jdkshen.aijspro  mAttrs=(-220,1576)(wrapxwrap) AI 球菜单（含 ⏹ 按钮，frame [-220,1681][484,2381]）
```
同类型 APPLICATION_OVERLAY 中 Node 浮窗创建更晚、z 序在 AI 球/菜单之上；高 DPI/大窗时 Node 浮窗底部会与菜单区域重叠，触摸落到 Node 浮窗（其内容区未消费也不下传），看起来就是「点 ⏹ 无反应」。

### 修复
1. AI 球菜单展开状态暴露：`CircularMenuWindow` 记录 `sNodeOverlayMenuExpanded`（onExpanding/onExpanded=true，onCollapsed=false），并提供静态查询。
2. `NodeUiBridgeService.setOverlaysTouchable(boolean)`：把所有 Node 浮窗 `LayoutParams.flags` 加/去 `FLAG_NOT_TOUCHABLE` 并 `updateViewLayout`。
3. `CircularMenuWindow` 回调里：菜单展开 → Node 浮窗 NOT_TOUCHABLE（触摸让给菜单/⏹）；菜单收起 → 恢复，浮窗内 ✕/确定/console 照常可点。
4. 新浮窗 show 时若菜单已展开，初始即带 NOT_TOUCHABLE，避免显示瞬间抢触摸。

### 验证（K40，本机 465 构建）
- 重叠复现：先展开 AI 菜单，再启动 `t169overlap.node.js`（浮窗 y=1900，frame [0,2005][273,2114] 与菜单重叠）；dump 到 Node 浮窗 `fl=NOT_FOCUSABLE NOT_TOUCHABLE NOT_TOUCH_MODAL ...`；点红色 ⏹ → `Node24Service execute returned cancelled=true`、`:node24` 空、脚本停止；
- 菜单展开期间点浮窗 ✕：不触发关闭（NOT_TOUCHABLE 生效，触摸让给菜单）；点 AI 球收起菜单后，再点 ✕ → `execute returned exitCode=0`、overlay 关闭（触摸恢复）；
- 无重叠场景（默认 y=200）：菜单展开 → ⏹ 停止、node24 5s 内空、浮窗消失，同名入口正常。
