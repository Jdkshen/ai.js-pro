# 无障碍指纹手势 — dev-753

## 实现

- 无障碍服务声明 `canRequestFingerprintGestures` 和 `USE_FINGERPRINT` 普通权限。
- 新增 `FingerprintGestureDispatcher` 共享订阅；第一个脚本请求捕获，最后一个脚本退出后释放。服务断开报告不可用，重连恢复订阅，旧服务回调被丢弃。
- API 26 后端在主线程注册 `FingerprintGestureController` 回调，按需设置指纹捕获标志，并保留其他无障碍标志。
- Rhino / QuickJS 均提供 `observeFingerprintGesture()`、`isFingerprintGestureAvailable()`、`stopObservingFingerprintGesture()`。
- 两个事件：`fingerprint_gesture(direction)`、`fingerprint_gesture_available(boolean)`；方向为 up / down / left / right。
- 显式停止和引擎回收均注销订阅；Rhino 使用独立保活 token，QuickJS 对系统事件轮询消费者计数，避免停止指纹监听时影响其他事件源。
- 双引擎内置 30 秒监听示例；使用说明见 [无障碍指纹手势](../guides/无障碍指纹手势.md)。
