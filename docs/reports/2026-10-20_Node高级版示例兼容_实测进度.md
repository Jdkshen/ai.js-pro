## 已实现

- 真实 Java 类生成：ClassFileWriter 生成字节码，AndroidClassLoader/D8 装载；支持构造器、覆盖方法、Java 发起的构造回调、super 方法、基本类型/引用返回和异常传播。移除了 UI 的假 defineClass。
- 双向 JNI 桥源码现已入库：V8 始终在 Node 线程执行；Java 外部回调排队，等待期间可在原 Java/UI 线程处理嵌套 host 调用，避免 Canvas/View 跨线程和同步回调死锁。普通脚本不启用回调时保留原快路径。
- Class 作为 Java 参数、primitive TYPE、嵌套类、Class 方法、Class[]/String[]/基本类型数组和多维数组转换、可变字段重新读取、boxInt 等装箱。Java 对象/数组/类代理复用引用身份。
- setThreadMode / setDefaultThreadMode：current、io、compute、ui、ui-sync；异步结果独立排队，避免被 256 条普通事件缓冲淘汰；Java 异步线程数限制为 4。
- 取消会中断回调 worker 的 Java 等待；先停止 Node 再关闭回调队列，修复脚本结束后的最后一次轮询报错；退出后的 Java 回调安全返回默认值或真实 super。
- 函数转 Java 接口监听器及 `new View.OnClickListener({onClick})`；真实 UI 回调线程与对象身份已断言。
- 高级版找色所用 `@autojs/opencv.Rect` 构造；运算仍走现有 Java/OpenCV 图像实现。该模块目前只补了 Rect 构造，不是完整 addon。
- `plugins.load('org.autojs.autojspro.plugin.mlkit.ocr')` 返回真实兼容构造器，延迟创建内置 MLKit 会话；detect/release 及创建期间释放有测试。它不伪报插件 APK 已安装。
- UI 类 facade 保留 Java 父类身份，使原生界面的 RecyclerView 子类能真实生成；生成自定义 View 保持同一 Node 进程/Isolate。
- 测试工具增加 SamplesRoot、源码 SHA；识别 nodejs ui、ui nodejs、ui、.node.js，项目/常驻示例可显式纳入；console.error、ok:false、supported:false 均按失败处理。完成标记按入口 job ID 匹配并等待 cleanup，不拿子引擎的成功冒充入口完成。
