## 路径为何不生效，以及修复

1. Flutter 设置页发送 `scriptsRoot {path}`，原生分支却只调用 getter 返回旧路径，从未写入。本轮增加校验、自动建目录、提交偏好和明确的 `saved` 回执；失败保留原配置并显示原因。文件系统操作移到目录线程。
2. 历史默认值是 `/脚本/`，原代码把它作为内部存储下的相对后缀。新增 `ScriptDirectory.resolvePreference` 保留该语义，兼容旧相对路径；新保存的绝对路径有独立标记，不重复拼接内部存储。不能把旧 `/脚本/` 直接当系统根目录。
3. 根路径读取会检查偏好文件的更新，避免已经启动的脚本/编辑器进程继续使用缓存值。MI8 实测同一 Rhino 宿主进程在设置修改前后读到不同正确路径，最终 Rhino、QuickJS、Node 三引擎读数均为恢复后的原目录。
4. 文件列表根目录变化后丢弃旧异步读取结果，清理旧选择和滚动位置；目录标题和面包屑使用实际根目录。打开工作区时过滤旧目录的历史标签，避免又跳回旧目录。
5. 不自动移动原目录中的文件；只切换工作目录。新路径必须可读写，内置示例目录不能设置成“我的脚本”目录；空值、文件链接、文件占用路径和权限错误有明确反馈。

主要代码：`Pref`、`ScriptDirectory`、`PocBridge.scriptsRoot/readableFile/list`、Flutter 的 `settings_page/browser/main/workspace_models`。

## 当前统一规则

| 类型 | 行点击 | 编辑/源码 | 运行/预览 | 单文件打包 |
| --- | --- | --- | --- | --- |
| 普通目录 | 进入目录 | — | 隐藏 | 隐藏 |
| project.json 项目目录 | 进入目录 | 项目配置/工作区 | 项目运行按钮 | 项目打包入口 |
| JS、MJS | 文件页编辑；示例页运行 | 显示 | 显示 | 显示 |
| AUTO 录制脚本 | 运行 | 隐藏，避免把二进制当文本 | 显示，要求 Root | 隐藏 |
| XML 布局 | 文件页编辑；示例页预览 | 显示 | 显示布局预览 | 隐藏 |
| Markdown、JSON、TXT、C/C++、Java、TS 等支持的文本 | 编辑 | 显示 | 隐藏 | 隐藏 |
| 图片、音视频、APK、DEX、SO、未知资源 | 交给其他应用 | 隐藏 | 隐藏 | 隐藏 |

文件与示例使用同一类型判断和图标：目录蓝色、项目星标，JS 绿色 J、AUTO 红色 R、其它文件灰色扩展名首字母。保留本项目已有的更多文本类型。完整文件名仍保留在路径、菜单与详情中；JS/AUTO 行显示简化名称。

示例资源仍可导入；资源不再一概显示“打包”。悬浮运行不用于 XML 预览，定时/快捷方式/JS 单文件打包不对普通资源展示。外部打开依赖手机上有对应接收应用，失败会显示错误。

## 筛选与执行底层

- 目录默认显示普通文件、代码、文件夹和项目；点文件能力不决定它是否可见。用户分类选择可独立组合，也可只看项目。
- 默认不显示点开头的隐藏项；打开隐藏开关后可见 `.gitignore` 等。内部回收站 `.autojs-glass-*` 和 `.flutter-*` 临时数据持续隐藏。
- 原生列表原先忽略 recursive/regex，并把所有搜索都当字面包含。本轮增加 `WorkspaceListing`：真正遍历子目录、正则匹配、隐藏目录处理、规范路径边界及取消检查。最多扫描 20000 项、返回 5000 项，超限明确报告，不伪装完整结果。
- `WorkspaceScriptSource` 把 XML 作为字符串数据交给 UI 布局预览，支持 UTF-8 BOM，限制 1MiB，沿用 `:script` UI 生命周期。并非把 XML 当 JavaScript 执行；非布局 XML 仍可能不支持渲染。
- AUTO 接已有 RootAutomator 引擎。已有 Node 项目的自定义入口后缀仍保留原路由，避免文件浏览类型限制误伤项目启动。
