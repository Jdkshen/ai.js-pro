# Node UI：JS 回调默认值与工程资源路径（dev-1299）

日期：2026-10-31。承接 [Node UI 事件与视图树修复（dev-1297）](2026-10-31_NodeUI事件与视图树修复dev-1297.md)，处理 chess-auto 在 192.168.10.4 上复测出的剩余问题。

## 1. 为什么他们那边"很多 bug 没修到"

根因不是 dev-1297 的补丁失效，而是**他们的工程没有可用的编译资源包**：

- `chess-auto/node-port/res` 共 40 处**裸数字尺寸**（`android:layout_marginTop="12"`、`padding="18"`），aapt2 直接报 `'4' is incompatible with attribute layout_marginTop (attr) dimension`；
- `?attr/materialButtonTonalStyle` 在宿主 release 资源表里不存在（R8 资源收缩删掉了）；
- 因此 `build/project-res.apk` 从未生成 → 引擎 `realUiMode=false`，退回**兼容路径（合成 id）**，而 dev-1297 的修复全部在真实 Native UI 路径上。

对比探针（同一台设备、同一工程、dev-1297）：

| 检查 | 兼容路径（无资源包） | 真实路径（补上资源包后） |
| --- | --- | --- |
| `binding[id]` 类型 | marker 函数 | 真实 Java View（object） |
| `JsViewPager.getChildCount()` | 0 | **3** |
| `initAdapterFromChildren()` / `adapterCount` | 0 | **3** |
| `setCurrentItem(1)` | 无效 | 生效 |
| `BottomNavigationView.getMenu().size()` | 0 | **3** |
| `setOnItemSelectedListener` | 抛「无效的 View handle」 | 挂载成功并回调 |
| `ui.inflate(ui.R.layout.page_engine)` | 可用 | 可用（真实 View） |

## 2. 本轮修复

### 2.1 JS 回调返回 undefined → 基本类型拆箱 NPE（真机修复）

`nav.setOnItemSelectedListener(function(item){ ... })` 后调用 `navigation.setSelectedItemId(id)` 会抛：

```text
NullPointerException: Expected to unbox a 'boolean' primitive type but was returned null
```

根因：JS 回调没有 `return` 时 `Node24Engine.invokeCallback` 返回 null，`NodeJsCallback` 直接把 `coerce(...)` 的结果（null）交给动态代理，接口方法声明为 `boolean` → 拆箱 NPE。
`View.performLongClick()` 等同类接口一样会炸。

修复：`Node24HostBridge.NodeJsCallback` 在返回值为 null 且接口方法返回基本类型时补 Java 默认值（false / 0）；`Node24JavaArguments.interfaceProxy` 与 `Node24DirectDexGenerator` 的同类路径一并兜底。

真机结果（MI8 dev-1299）：

```text
U_LONG_CB  U_LONG_CLICK=false        ← performLongClick 不再抛错，返回 false
S_BIND=ok  S_SET=ok  S_DONE cb=1      ← setSelectedItemId 正常，listener 回调
```

### 2.2 缺少编译资源时显式告警

声明了 `androidResources` 却没有 `build/project-res.apk` 时，宿主 `C-RES-WARN` 与脚本 `console.warn` 都会提示：

```text
[ui] 工程声明了 androidResources，但没有可用的 build/project-res.apk：当前走兼容路径（合成 id），
     listener/ViewPager/BottomNavigationView 等行为受限。请在 PC 上运行 tools/build-project-res.ps1 ...
```

避免再把"兼容路径受限"误判成"宿主没修"。

### 2.3 `tools/build-project-res.ps1` 预处理

- 裸数字尺寸自动补 `dp`（Auto.js 语义）；
- `?attr/xxx` 与宿主资源表对账：能映射就替换（如 `materialButtonTonalStyle` → `materialButtonOutlinedStyle`），否则删掉该属性并逐条打印；
- 脚本补了 UTF-8 BOM（PowerShell 5.1 读无 BOM 的中文脚本会解析失败）。
