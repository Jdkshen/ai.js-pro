## 实现范围

新增 18 个规范工具，公开目录为 160 个规范名 + 9 个兼容别名 = 169；文件/APK 工具类共 99 项，其中逆向分类 18 项。原接口和兼容别名保留。

| 能力 | MCP 入口 | 后端与条件 |
|---|---|---|
| 自发现 | reverse_guide / reverse_capabilities / reverse_plan | 内置分页教程、能力快照、8 种机读工作流；不会自动执行计划 |
| APK 工程 | apk_decode_project / apk_build_project / apk_install_framework | 可选 Apktool 3.0.3 + AAPT2；独立 ART 子进程；可签名并真实验签 |
| SO 静态分析 | native_analyze / native_functions / native_function_detail / native_xrefs / native_compare | 可选 radare2 6.2.4；输入快照、有界输出、函数及引用分页 |
| 伪代码 | native_decompile | 可选 r2ghidra 6.2.4 / ABI152，完整上游补丁及 SLEIGH 数据；不需要桌面 Ghidra |
| 指纹/规则 | artifact_fingerprint / yara_scan | 透明启发式证据、可选 YARA 4.6.0；不宣称完整 APKiD |
| 模拟 | native_emulate | 可选 Unicorn 2.1.4；arm64、ARM、Thumb、x86、x86_64，原始代码/数据/寄存器与时间、指令预算 |
| 动态分析 | frida_status / frida_processes / frida_eval | 可选 Frida 17.25.2 客户端；需 Server/Gadget，采集有界消息后卸载、分离 |

新增标准 MCP `resources/list`、`resources/read`、`resources/templates/list`、`prompts/list`、`prompts/get`；支持公共 `_meta` 参数。资源、提示模板和工具指南读取同源资产，工具专用客户端也可读取。`initialize.instructions`、工具描述和 `_meta.aijs` 提供入口、依赖、后台任务下一步。

交给其他 AI 的入口见 [MCP逆向调用说明](../MCP逆向调用说明.md)。完整教程：[内置指南](../../apps/app/src/main/assets/mcp/AIjs-Reverse-Guide.md)；机读计划：[reverse-workflows.json](../../apps/app/src/main/assets/mcp/reverse-workflows.json)。

## 隔离、失败和输出

- 既有 `:tools` 工具进程继续负责会话与任务；可选解析器、编译器、Frida、Unicorn 再进入各自子进程。每次使用独立 setsid 进程组，取消和超时清理编译器子孙进程。
- 默认返回后台 jobId；轮询终态，再按 nextOffset 读取结果，直到 hasMore=false。错误保留 COMPONENT_NOT_INSTALLED 等代码及 nextActions；重启标记 INTERRUPTED，不自动重放。
- 日志最多 4MiB，原生分页中间结果最多 64MiB，输入及工程有文件数、字节、路径约束。输出为新文件/目录，源 APK 不覆盖；发布失败清理自己的暂存目录。
- 修复了 Frida 私有 GLib 必须先初始化、取消回调签名错误，以及 Unicorn Thumb 入口最低位被清除的问题；均有实际失败证据后修复。
- Apktool 在 Android 缺少 ImageIO/AWT。独立预 DEX 组件替换九宫格解码为 BitmapFactory，恢复标准黑色伸缩/内容边框；AAPT2 独立包装 LD_LIBRARY_PATH，避免其 libz 覆盖 ART 系统库。

## 兼容边界

Frida 不自动提权或启动 Server，无法凭普通应用 UID 附加任意其他应用。Unicorn 不提供完整 Android/ELF/JNI 环境。伪代码与启发式指纹仅用于分析，不证明可重编译或业务等价。没有内置完整 APKiD Python 环境、桌面 Ghidra GUI 或未验证的空工具入口。

九宫格当前不恢复 npLb/npOl 红色光学边框，PNG 辅助色彩信息及压缩也可能变化。普通九宫格、Manifest/XML/Smali 的样本通过不能扩大为所有 APK 通过；特殊加固、资源格式、厂商框架仍需目标样本验收。

可选原生组件当前为 Android arm64 / API26+；系统是否允许执行下载代码仍需实际检查。小米 8 Android15 已验，不代表 Android17 原机或其他 ABI 已验。
