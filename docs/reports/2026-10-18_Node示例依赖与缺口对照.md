# Node 引擎示例 require/全局依赖与缺口对照（2026-10-18）

> 目的：Node 引擎示例「跑不了」自查。扫描 `apps/app/src/main/assets/sample/Node 引擎` 下全部示例（排除 React/Vue/webpack 构建脚本），提取 `require(...)` 与使用的全局对象，对照当前 Node24 prelude/host 能力。
> 当前 Node24 已提供：Node 24 全部内置模块（fs/path/http/https/stream/util/...）；自定义模块 `rhino/app/device/files/storages/events/engines(stub)/threads(stub)/ui`；全局 `$autojs`（java/device/files/storages/events/engines/threads）、`require('rhino').install()` 后的 Packages/java 包代理。
> 未提供：多数 Auto.js Pro 自定义模块、npm 第三方包、全局 exit/sleep/toast/http 等。

## 一、可运行（当前能力已覆盖）

| 示例 | 依赖 | 结论 |
|---|---|---|
| 使用Node.js模块/http.js | require('https') | ✅ Node 内置 |
| 使用Node.js模块/http-server-helloworld.js | require('http') | ✅ Node 内置（示例里还用了全局 http 变量则需补全局） |
| Node.js与Android和Java交互/使用内置对象java.js | $autojs.java | ✅ 可用（Java 反射代理） |
| 使用Android原生界面（NodeAndroidUI） | ui/rhino/app | ✅ 已验证（dev-1067 uiprobe/Node UI） |
| 继承Java类-* | rhino + defineClass | ❌ defineClass 明确不支持（需 Java→Node 反向回调） |

## 二、缺第三方 npm 包（最高频阻塞点）

| 示例 | 缺依赖 | 说明 |
|---|---|---|
| 使用Node.js模块/axios网络请求.js | `axios` | APK 无 node_modules；Auto.js Pro 内置 axios，我们未内置 → 需内置 vendor 包或示例改内置 http |
| 对话框.js / 播放音乐.js | `axios` + stream/util/fs | 同上 |

**方案**：在主 APK assets 内置常用 npm 包（axios 体积小），或给 prelude 加 `require('axios')` 映射到内置实现；probe 验证 npm 解析。

## 四、缺全局对象

| 全局 | 示例 | 当前 | 建议 |
|---|---|---|---|
| `exit` / `exit()` | 悬浮日志、root、shell、发送通知、对话框、引擎 | ❌ | 映射到 `$autojs.stopRunning()` + 抛退出信号 |
| `sleep(ms)` | 多例 | ❌ | 同步 sleep（Atomics.wait）或异步 |
| `toast(...)`（全局） | 多例 | ❌ | 映射 app.toast |
| `http`（Auto.js HTTP 对象） | axios/http-server 示例 | ❌ | 可选：提供简单 get/post 包装 |
| `java`（未 install 时的全局） | 使用内置对象java.js 用 $autojs ✅；其它需 install | ⚠️ | rhino.install 后可；可在 prelude 自动 install |
| `class`（Rhino 继承 Java） | 继承Java类 2 例 | ❌ defineClass 不支持 | 需反向回调或放弃 |

## 五、优先级建议（按「示例恢复数量/成本」）

P0（低本高收益，先让多数示例过 require）：
1. 注册 `toast`（映射 app.toast）、`lang`（delay）、`device`（映射 $autojs.device + getInfo）、`clip_manager`（app clipboard）、`datastore`（$autojs.storages）、`settings`、`power_manager`；
2. 全局 `exit/sleep/toast`；
3. 内置 axios（或示例改写为 http 内置模块）。

P1：`color`（颜色解析）、`zip`（fs+zlib）、`dialogs`（复用 ui/宿主对话框）、`notification`、`sensors`、`work_manager`、`shell`。

P2：`image/media_projection/@autojs/opencv/ocr/accessibility/plugins/engines/root_automator/media`（需要原生/权限/跨进程，单独立项）。

## 六、与 t2 报错对齐方式
拿到报错原文后按 `Cannot find module 'xxx'` 对应本表模块；`xxx is not defined` 对应全局表；`Your script error: ...` 与栈定位到具体 prelude 行。建议先修 P0，然后重跑示例清单回归。
