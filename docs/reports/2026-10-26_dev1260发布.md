# dev-1260 发布：APK 卡顿优化

来源：GPT/子任务在 `696ffd0b` 完成的卡顿优化，详见 [定位与验证报告](2026-10-26_APK卡顿定位与优化.md)。本轮将其从本地候选 `dev-1259-perf-candidate` 正式构建为 **dev-1260** 并发布。

## GPT 更新内容

1. 目录扫描、文件 stat/排序、历史日志读取移到独立工作线程，主线程不再被目录轮询阻塞。
2. 文件页首次/切页只读一次；PageView 停稳后才扫描和轮询；自动刷新 2s，滚动/后台/抽屉期间暂停。
3. 导航固定交互子树不再逐帧重建；图标层按整页变化重绘；去掉无效模糊；离屏动画 TickerMode 暂停。
4. Splash 立即挂载工作区并在遮罩下初始化；品牌遮罩最低 300ms、淡出 160ms。
5. 编辑器隐藏日志懒加载；实时日志 50→150ms 合并，`textOnly` 减少结构化载荷；历史日志移出主线程。
6. API 文档正文 DOM 缓存（32 项），搜索/筛选/分页复用；主题仍由 CSS/原生通知控制。

测量：指定切页/滚动场景桥主线程 34 次调用、累计 17.36ms、P95 2.24ms、最大 2.73ms，超过 16.67ms 为 0；三引擎并发与编辑器日志专项通过。不是整包帧率或所有脚本的性能保证。
