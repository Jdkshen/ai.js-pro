## 本次修改

| 模块 | 改动 |
| --- | --- |
| `src/automation/endgame-policy.js` | 新增无进攻子确认器；原始观测、当前盘面、可信账本中我方棋子位置必须一致，两张不同新帧才确认。未知格、将帅缺失、账本仍有攻子、重复缓存帧均不能确认停止。 |
| `src/automation/driver/loop.js` | 自动求胜且轮到我方时，在启动搜索前检查；首帧请求重新抓取，复核期间不启动搜索、不点击，第二帧确认后暂停并通知面板停止。 |
| `src/automation/driver-defaults.js` | 默认启用 `stopWithoutAttackers`；只在自动求胜模式生效。关闭求胜可继续保和；驱动配置 `stopWithoutAttackers:false` 也可禁用。 |
| `src/automation/win-seek.js` | 最后一枚车马炮的静态兑子风险按大子数量判断；即使还有兵也启用软保护。 |
| `src/automation/driver/search.js` | 存在求胜软偏好时请求五路候选，记录实际返回候选数和合法着法数；评分、深度、杀分保护及唯一应对继续生效。 |
| `src/app/panel/driver-loop.js` | 停止文案采用实际原因，避免把所有停止都称为将帅安全检查。 |

这是自动运行策略，不对游戏作和棋裁决，也没有把评分较差的着法强行当成求胜招。本次修复可阻止该无攻子残局继续空走；尚未验收新版本完整对局的胜率。
