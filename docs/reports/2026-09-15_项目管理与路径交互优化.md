# 项目管理与路径交互优化

日期：2026-09-15。已发布 dev-598。

## 改动

- 项目保存增加提交中状态与按钮禁用，阻止重复提交；新建检查绝对路径、同名目标、父目录存在及可写性、名称中的路径分隔符。
- 切换项目存在未保存字段/图标改动时，提供保存后切换、放弃修改并切换、取消。保存失败不切换并释放提交状态。
- 文件夹选择器分别显示读取中、读取失败和空目录；读取失败时禁用确定。
- 原生与 Miuix 文件列表共用 ExplorerBreadcrumbs，实际路径与文案分开。修复同前缀兄弟目录和脚本目录外位置的点击目标。
- 图标选择支持名称/包名搜索、空结果提示；应用列表先读元信息，可见项再后台取图；缩略图最长边 144px，缓存按实际字节限制为 4MB，缓存键包含应用更新时间。

## 验证

- app 单元测试 158 项，失败 0；新增三项路径测试覆盖深层项目、同前缀兄弟目录和存储根以外位置。
- Mi8 安装发布的 dev-598，图标页与文件夹选择页实际检查正常；搜索不存在名称显示“没有匹配的应用”。
- Mi8 ProjectUsabilityTest 五项通过：已有/相对路径拒绝；未保存切换三种选择；读取失败提示；保存忙碌期间不启动第二次提交；缓存夹具中的文件与嵌套文件夹实际删除。
- 删除测试仅操作应用 cache 内本次创建的夹具，结束后清理，没有删除用户文件。
- 发布核对版本 598、SHA-256 和 K40 拉取更新清单 HTTP 200。

## 范围与限制

真机交互检查在 Mi8 进行，K40 验证的是更新源可访问；没有宣称完整 K40 新建/编辑/导入/主题矩阵已复跑。可写性预检查不能替代实际保存错误处理。保存后切换的所有文件系统失败分支、主题跟随系统的完整回归，后续有异常时继续专项验证。
