# Ace 编辑器功能对齐检查（dev-888）

检查日期：2026-10-12。检查范围为 AI.js Pro 新编辑器与原 Auto.js Pro 编辑器的功能对齐；不包含整个应用、脚本引擎或授权系统的全面兼容性评估。本轮只新增检查报告和探针证据，没有修改编辑器实现，也没有重新发布 APK。

结论：常用编辑、保存运行、折叠、缩放及标签切换已有接入；确认仍有 **7 类功能未完全对齐**。其中 API 补全／误报、长按编辑菜单最值得优先补齐。以下“缺失”指新编辑器入口或行为尚未接入，不能用已有菜单名称或过去的 20 项测试替代完整验证。

## 已确认的差距

| 优先级 | 功能 | 原版依据 | dev-888 的实际情况与影响 |
|---|---|---|---|
| 高 | Auto.js API 补全与诊断覆盖 | 原版静态补全索引包含 20 组、314 个属性项；`http.get`、`dialogs.confirm`、`getClip`、`setClip` 等都在索引中。该数值只是内置索引规模，不代表原版全部 API。 | 新类型声明仅覆盖部分 API，`http`、`dialogs` 等为 `any`。本轮运行语言 Worker 探针：`http.`、`dialogs.`、`ui.` 均返回 0 项；`getClip()`、`setClip()`、`currentPackage()` 报 TS2304。源码运行环境有剪贴板 API，属于编辑提示覆盖问题，不能据此认定运行 API 缺失。 |
| 高 | 长按选择后的浮动编辑菜单 | 原版 Ace 通过 `autojs.startActionMode(...)` 接 Android ActionMode，另有复制、剪切、粘贴、选词、全选方法。 | 新 `editor.js` 把三个 ActionMode 钩子设为空函数。顶部“编辑→复制”可用，但没有接回原版长按后的浮动菜单，也没有等价的原生剪切／粘贴／全选入口。输入法自带剪贴板或外接键盘的可用性不能代替这条触摸操作链。 |
| 中 | 调试变量查看与调试时源码只读 | 原版 DebugBar 有监视变量列表、变量值查看、表达式求值入口；原版 `editor.setDebugging(true)` 会锁定源码只读。 | 新界面已接断点、步过、步入、步出、继续、停止；没有变量监视／求值面板。启动调试仅禁用原生撤销／重做标志，没有调用 Ace 只读。断点与实际脚本执行行可能因调试中编辑而偏离。完整单步闭环仍待设备实测。 |
| 中 | 按文件类型使用正确的高亮模式 | 原版扩展名映射覆盖 JS、TS、JSON、XML、HTML/Vue、CSS、Markdown、TXT、Java、Kotlin、Python、Lua、Shell、C/C++ 等。 | 新页面只按 `.json`、`.ts` 分支选择模式，其余普通文件统一 JavaScript；极大文件统一纯文本。XML、HTML、CSS、Markdown、TXT 等能打开但高亮模式不对。这是编辑语言模式差距，不表示已经或应当支持运行这些语言。 |
| 中 | 编辑设置与代码配色主题 | 原版初始化会读取自动换行、空白字符、打印边界线、实时补全、检查、行号、放大镜等设置，并有独立编辑器主题列表。 | 新编辑器只接入字体大小和应用的浅色／深色／跟随系统。其他编辑设置没有映射到 Ace；代码主题固定映射为 `tomorrow_night`／`textmate`，不能独立选择原版完整主题。 |
| 中 | 可视化设计编辑 | 原版 VisualEditorActivity 连接 VisualUIEditor，并有源码、编辑、预览页面及保存链。 | 新“设计”菜单提取 `ui.layout(...)` 或 `setViewFromXml(...)` 中的 XML 后直接创建布局预览。没有可视化编辑页，也没有将设计修改同步回源码的流程；目前只能算布局预览。 |
| 低 | 自定义输入增强栏 | 原版从 `user_symbols.json` 加载用户符号配置，并把配置传给输入增强栏。 | 新符号栏为 Java 中固定的两行数组；常用符号、方向键、TAB 已接，但用户自定义符号配置没有接入。 |

## 大文件当前限制

这部分属于已有的性能降级，不能混同为所有文件都缺少智能功能，也不能以通过大文件打开测试代表大文件获得完整语言服务：

- 超过 **262,144 个 UTF-16 字符单位**、超过 **10,000 行**，或任一行超过 **20,000 个字符单位**，停止完整语义分析和实时自动补全。
- 超过 **4,194,304 个字符单位**，或任一行超过 **20,000 个字符单位**，改成纯文本渲染。
- 这些阈值基于 JavaScript 字符串长度，**不是文件字节数**。中文文件不能简单换算为“256 KB”。
- 跨文件语言分析也会跳过超过 262,144 个字符单位的依赖文件。
- 已验证的是约 1 MiB 文件、12 个访问过的标签共用一个页面及缓存切换；未建立所有手机通用的最大文件／总标签容量。
