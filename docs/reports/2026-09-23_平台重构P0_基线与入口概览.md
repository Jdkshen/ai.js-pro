## 7. 第二批：脚本执行入口调用链 + 设备登记（2026-09-23）

> 依据任务书 §7 P0「更新模块/入口/API 调用图、列出改动中的文件、采集设备」；本批用 CodeGraph 核了**脚本执行入口链**，其余入口（MCP 工具面、inrt、定时任务）标注待续。

### 7.1 脚本执行入口链（已核，行号为准）

```
外部 Intent ──► RunIntentActivity（apps/app/.../external/open/RunIntentActivity.java:27；caller: ExternalRunResume）
UI/文件页/示例等入口 ──► ScriptEngineService.execute(ScriptExecutionTask)（modules/engine/.../ScriptEngineService.java:142）
                          ├─ 含 "ui" 声明 / EXECUTION_MODE_UI → ScriptExecuteActivity.execute(...)（:164，专用 Activity）
                          ├─ Rhino（非 QuickJS）→ LoopedBasedJavaScriptExecution（:169，Looper 线程）
                          └─ QuickJS / 其他 → RunnableScriptExecution（:171，ThreadCompat 线程）
                          └─ 引擎回退：switchEngineWhenTheChosenOneCannotParse（:192，EngineFallbacks + TemplateLiteralPreprocessor）
MCP ──► McpHttpServer（:8788 流式 HTTP）→ McpTools.handle → run_script → AutoJs.scriptEngineService.execute（见 §8.1）
inrt ──► SplashActivity → AssetsProjectLauncher.launch → scriptEngineService.execute（见 §8.2）
定时任务 ──► TimedTaskScheduler → ScriptIntents.handleIntent → RunIntentActivity（见 §8.3）
```

> §8 已补齐 MCP / inrt / 定时任务三条链（2026-09-23 第三批）；五条入口最终都汇聚到
> `ScriptEngineService.execute`（或经 `RunIntentActivity` 进同一条）。

**CodeGraph 警报**：`ScriptEngineService` / `ScriptExecuteActivity` / `execute` / `RunnableScriptExecution.execute`
均标注 **no covering tests** —— 平台 P2（执行生命周期）收口时的重点风险区。

## 8. 第三批：MCP / inrt / 定时任务入口链（2026-09-23，CodeGraph 核对）

### 8.1 MCP 工具面（`:app` miuix，Kotlin）

```
MT 客户端 / adb forward ──► McpHttpServer（HTTP :8788，流式 HTTP；鉴权=令牌或 loopback 兼容）
  → McpTools.handle(JSON-RPC：initialize / tools/list / tools/call)
     · tools/list：26 个工具，定义与 McpToolCatalog 强校验一致（有单测 McpToolCatalogTest）
     · run_script：require 运行授权 → resolveScript(path) → 可选 engine=… 生成**临时副本**
       （首行加 `// @engine quickjs|rhino`，原名不改、结束即删）
       → AutoJs.getInstance().scriptEngineService.execute(source, listener, ExecutionConfig(workingDirectory))
       ← **与 UI/外部 Intent 同一个执行入口**；listener 回填 RunRecord（status/result/error/logs）
     · stop_script → record.execution.engine.forceStop()（中断→统一报 STOPPED，不报 error）
生命周期/存储：McpAutoLifecycle（自启动联动）、McpService（开关：allowWrite/allowExecution）、
McpHistoryStore（历史）、McpWorkspaceStore（私有工作区快照+应用/回退）；UI：MiuixMcpActivity / MiuixMcpHistoryActivity
```

⚠️ **无覆盖测试警报**：`McpService` / `McpTools`、`ScriptExecutionListener` 回填路径均无单测；
只有工具目录有测试（改动工具名单时目录一致性检查会失败，属良性护栏）。

### 8.2 inrt 打包产物启动链（独立 APK 模板）

```
:SplashActivity.onCreate
  ├─ readLaunchConfig（assets/project/project.json 的 launchConfig：启动图/权限清单/隐藏日志）
  ├─ 不需要 splash → 直接 main()；否则 显示启动图 → main()
  └─ main()：按配置申请权限（未配置=存储+手机状态）→ runScript()（独立线程，捕 Throwable）
       → GlobalProjectLauncher（单例 = AssetsProjectLauncher("project")）
            ├─ prepare()：filesDir/project/ 解包 assets/project（buildId 相同则跳过重解）
            ├─ initKey()：新方案=盐+**签名指纹**派生（重签产物直接拒绝，提示“签名与打包时不一致”）；
            │              旧产物= legacy 推导（向后兼容）
            └─ launch()：隐藏日志？直接跑：先进 LogActivity 再跑
                 runScript：source = EncryptedScripts.toSourceFromLibrary("main")
                          （native 存储：载荷嵌在原生库尾部）或 toSource(file) / 明文回退
                          → setPreferredEngine(project.json 声明) → scriptEngineService.execute(...)
异常：LAUNCH_FAILED + Toast + LogActivity（错误信息全路径可见）
```

### 8.3 定时任务链

```
App 启动 → TimedTaskScheduler.init（JobManager：每 20min CheckTasksJob 重排 + 每任务 SetExact Job）
  → TimedTaskJob.onRunJob → runTask → TimedTask.createIntent() → ScriptIntents.handleIntent
  → RunIntentActivity（与外部 `am start` 同一条路）
存储：TimedTaskManager + TimedTaskDatabase；外部控制：BaseBroadcastReceiver / Tasker 兼容
```

⚠️ `TimedTaskScheduler` / `TimedTaskManager` / `ScriptIntents` 均无覆盖测试。

### 8.4 五条入口汇聚图

```
① 编辑器/文件页/示例/搜索/打包页… ─┐
② 外部 Intent `am start … RunIntentActivity` ─┼─► ScriptEngineService.execute ─► （ui 声明→ScriptExecuteActivity；
③ MCP run_script ────────────────────┤                                    Rhino→Looper 线程；QuickJS→Thread）
④ 定时任务 ─► ScriptIntents ─► RunIntentActivity ─┘                     + EngineFallbacks 回退
⑤ inrt 打包产物（独立 APK）──────────►（同一 :engine 模块，入口=AssetsProjectLauncher.runScript）
```
