# dev-786：ImGui 操作窗与字体闪退修复

日期：2026-10-04。宿主 dev-786，象棋工程 0.6.56（code 56）。用户要求先在新手机测试，随后指定改用 K40。正式包已安装 K40。

## 1. 已定位的闪退

新手机 Xiaomi 2602BRT18C / Android 16 / SDK 36 在 dev-785 的 ImGui 第一帧发生 SIGSEGV，fault address 0x48。原生堆栈为 `ImGui::NewFrame()+1368`；反汇编对应读取 `ImFont.ContainerAtlas` 后访问空图集。

从该手机提取 `/system/fonts/NotoSansCJK-Regular.ttc`（32,355,424 字节），使用同一份 Dear ImGui 1.91.9b 构建器复现 `Build=false / IsLoaded=false`。此前仅调用 AddFont 并不能保证字体可用。

修复：使用 APK 已有的静态 `fonts/NotoSansCJKsc-Regular.otf`，释放失败图集并重建拉丁字库；检查 Build 和 IsLoaded 后才进入第一帧。ROM 字体失败回退、自带字体及第一帧回归均通过。补充操作按钮及棋子字形范围，包含 K40 检出的“钮”缺字。完整 Unicode 字库未加载。

关键源码：`modules/engine/src/main/cpp/imgui_font.h`、`ImGuiDrawingOverlay.java`、`ImGuiControlPanel.java`、`ImGuiFont.java`。旧日志与提取字体保存在 `.artifacts/`，不提交产物。

## 2. 操作窗与象棋接入

- QuickJS 新增 `drawing.panel.show/update/poll/hide`，原生 ImGui 按钮位于有边界的触摸窗口，全屏标记层继续不接收触摸。
- 每引擎独立操作窗；按钮 1～12 个，ID 唯一；事件为按钮 ID 和墙钟时间。GL 线程不调用 JS。
- DOWN/UP 分帧消费，隐藏、禁止触摸、换绑定和关闭取消旧输入；标题拖动由 UI 线程执行。
- 象棋窗口截图模式的高级面板点击“ImGui”切换小窗。模式、开始/暂停、停止、定位、识别、更多共六项；完整参数与日志由“更多”打开。
- 停止同批优先、过期开始丢弃；运行时禁用手动定位/识别。脚本阻塞期间仍需等脚本恢复后消费事件，不能跨线程强制中断。
- 截图窗口新增 foreground；active/focused 保留原始值。宿主覆盖窗活动时，可选底下仍有输入焦点的应用；点击守卫继续检查 ID、包名、几何和旋转。
- 示例 11 等目标窗口稳定 600ms 后截图，避免切换应用动画改变边界。示例 12 关闭时同时结束脚本。
- 静态 HUD 第一次更新补一帧完成布局测量，不建立常驻帧循环。

foreground 规则来自覆盖窗切换的排障推断。本轮成功 K40 抓帧时原始 active/focused 都为 true，未单独在真机证明 active=false / foreground=true 分支；该分支已由适配器回归覆盖。
