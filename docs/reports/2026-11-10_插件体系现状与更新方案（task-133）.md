### 3.1 `plugins.json`（工具已实现的字段）

~~~json
{
  \"schema\": 1,
  \"generatedAt\": \"<ISO>\",
  \"plugins\": [
    { \"id\": \"xiangqi\", \"displayName\": \"象棋插件\", \"package\": \"com.jdkshen.xiangqi.plugin\",
      \"version\": \"1.1.1\", \"versionCode\": 6, \"minAppVersion\": 1465,
      \"file\": \"xiangqi-plugin.apk\", \"sizeBytes\": 63681693,
      \"sha256\": \"<64 hex 或 pending>\", \"requiresRestart\": true,
      \"abis\": [\"arm64-v8a\"], \"notes\": \"…\" }
  ]
}
~~~

- **单一来源**：`plugins/<id>/plugin.json`（人写）+ `project-versions.json`（版本号的唯一来源）+ 已构建 APK（有则填 `sizeBytes/sha256`，没有则 `\"pending\"` 仍可出清单）（`:4-8`、`:95-123`）。
- **descriptor 必填**：`id/displayName/package/file/minAppVersion/requiresRestart/notes`（`:86`）；`id` 必须 kebab-case、`package` 有正则（`:89-90`）；**`draft: true` 的插件不进发布清单**（`:80-83`）。
- **校验**：`--check` 对 `schema`/必填/`id` 重复/`sha256`/`sizeBytes` 逐条对账（`:126-159`）。
- **文件名约定**：清单里的 `file` 就是更新源目录/Release 资产里的**同名文件**（工具从 `plugins/<id>/build/outputs/apk/release/<file>` 取，`:102`）。

### 3.2 快速更新策略（**工具注释已写口径，客户端未实现**）

- 客户端**只先拉 `plugins.json`**（几 KB；带 **ETag / If-None-Match**，**304 即结束**）⇒ 再按「**本机缺失** 或 **版本低于清单**」才下载对应 APK；**不做全量探测**（`:15-16`）。
- 直接推论：`plugins.json` 必须**与 `update.json` 同目录**（Release 同名资产）——这样自建源/内置源两套 URL 解析规则可复用（`PluginDownloads` 的既有规则，`:32-46`）。

## 4. 哪些能力适合插件化（判据，带实例）

| 判据 | 适合的正面例（本仓已有） | 反例 / 不适合 |
|---|---|---|
| **体积**：主程序为全用户承担、但只有少数人需要 | 打包模板（`apkbuilder-plugin`，模板 ≥20 MiB、留档插件 APK 88.4 MB）；内建 OCR ≈14.33 MiB（`ocr-plugin` 目标）；象棋引擎（63.68 MB APK） | 小到不值得：`libaijscrypto.so` 18 KB、`libquickjs` 1.1 MiB（进插件反而多一次安装） |
| **权限**：需要宿主权限/系统服务 | —— | **无障碍服务、MediaProjection、悬浮窗**这类**必须由装了主程序的身份**持有 ⇒ 插件跨包拿不到宿主权限（**不适合**） |
| **native / ABI** | 两插件都 `abiFilters arm64-v8a`（`xiangqi build.gradle:33`、`apkbuilder build.gradle:33`）⇒ 与主程序同样的 ABI 约束 | 核心运行时 `libopencv_*`/`libtbb`（DT_NEEDED 10/10 必需，见 task-67）⇒ 剥离会把宿主直接弄崩 |
| **可热更** | **脚本层**可热更：`assets/modules/*.js`、插件 `assets/scripts/`（象棋插件构建时把工程脚本拷进去） | **APK 层**受两条硬约束：**同签名** + **versionCode 只能升** ⇒ 「快速更新」只在「同签名+更高 versionCode」下成立；跨 ABI/权限变化必须整包（**回滚=先卸载**） |
| **是否进主流程** | 可选能力（象棋、OCR、模板兜底） | **默认打包路径已不依赖插件**：内置瘦身模板 + 宿主 lib 合成；插件定位=**最后手段**（`plugins/apkbuilder-plugin/plugin.json` notes 原文） |
| **重启语义** | descriptor 有 `requiresRestart`（两插件都 `true`）⇒ 安装后需提示重启 | 需要「装了立刻生效」的能力不适合（同进程内已加载的类不会换） |
