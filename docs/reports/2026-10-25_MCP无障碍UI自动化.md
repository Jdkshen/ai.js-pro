# MCP 无障碍 UI 自动化与应用管理（2026-10-25）

## 范围

用户要求在没有 root 的情况下，用已有无障碍权限给 MCP 增加 UI 自动化和应用管理能力；只保留 MCP 终端，不做 Java/C/C++/APK 编译工具链。本版实现：

### UI 自动化（8 项）
ui_find、ui_click、ui_long_click、ui_input、ui_swipe、ui_global、ui_wait、ui_scroll。

- 基于 AccessibilityService.instance 和当前活动窗口根节点；无 root、不执行 shell。
- 选择器支持 text/resourceId/contentDesc/className/bounds 及 x/y；click/longClick 先尝试 ACTION_CLICK/ACTION_LONG_CLICK，失败尝试可点击祖先，坐标-only 走 GestureDescription。
- input 只对 editable 节点执行 ACTION_SET_TEXT；global 支持 back/home/recents/notifications。
- 动作失败返回 success=false 和明确 error，不误报成功。

### 应用管理（7 项）
app_list、app_info、app_launch、app_open_settings、app_open_url、apk_install、apk_uninstall。

- PackageManager/Intent，无 root；列表支持 query/includeSystem/分页。
- apk_install 只打开系统安装器（经 ApkInstallActivity/未知来源授权），apk_uninstall 只打开系统卸载确认页；返回显式 silentInstall=false/silentUninstall=false、requiresUserConfirmation=true，不宣称静默安装或成功。

### 终端 aijs-ui
新增同 UID 非导出 AijsUiReceiver + AijsUiBridge。手机终端可执行：

```sh
am broadcast --user 0 -n com.jdkshen.aijspro/.mcp.AijsUiReceiver \
  -a com.jdkshen.aijspro.AIJS_UI --es command click --ei x 500 --ei y 900
```

支持 ping/status/click/tap/longClick/swipe/back/home/recents/notifications/input/settext；结果写入 app-private files/aijs-ui/last-result.json，也可看 logcat tag=AijsUi。receiver 不导出，只接受同 UID 显式广播；必须 --user 0。

## 边界

- 无障碍只能操作当前活动窗口；不读其它窗口/输入法节点。
- 系统弹窗/受保护页面可能拒绝点击；手势可能被系统取消；失败会返回原因。
- 安装/卸载最终结果由系统 UI 决定，无法静默、无法确认用户是否点确认。
- aijs-ui 的 am broadcast 不显示结果，需读 files/aijs-ui/last-result.json 或 logcat；多用户需对应 --user。
- 后续若接入 MCP 服务，建议先确保前台服务已启动，再做端到端工具回归。
