# QQ / 外部文件的打开、导入入口

## 原因与修复

在 dev-702 手机上查询 Android 候选应用时，`ACTION_VIEW + application/octet-stream` 和 `ACTION_SEND + text/plain` 均找不到 AI.js Pro 的打开/导入 Activity。之前的清单只匹配少数 MIME 类型，且没有注册分享附件入口；直接启动编辑 Activity 的测试无法发现这类缺失。

本次修改：

- 打开、导入入口支持 `text/*`、JavaScript、JSON/XML、`application/octet-stream` 和 unknown 类型；无 MIME 的本地文件另设过滤器。
- 为 `ACTION_SEND` 单独注册 MIME 过滤器，不要求 `Intent.data`。接收文件优先读 data，再读 `EXTRA_STREAM`，最后兼容单文件 `ClipData`。
- 系统列表中名称为 **AI.js Pro · 打开文件**、**AI.js Pro · 导入文件**。
- 导入入口另支持 ZIP MIME，导入行为是复制文件，并不在这次补丁中自动解压项目。
- 不扩展“直接运行脚本”入口的通用文件匹配。
- 元信息查询不受支持时，文件名回退到 URI 名称；读取仍经过 ContentResolver 的实际授权检查。
- 打开继续使用上一版的新编辑器，导入继续使用统一名称弹窗。
