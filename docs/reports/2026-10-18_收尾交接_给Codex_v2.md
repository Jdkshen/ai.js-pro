## 5. 雷区（都踩过）
1. 不要用 Select-String 过滤 gradle 输出（会杀 gradle、LASTEXITCODE 失真）；`*>` 写日志再读。
2. Dart 改动必须写进**外置重建源**并用 libapp.so sha 变化验证（stage 改了不算）。
3. .ps1 编辑后必须补 UTF-8 BOM（丢 BOM → PS5.1 GBK 解析报离谱语法错误）。
4. 多 agent 并发构建/发布会抢版本号：发布前先读 update.json 与设备版本；APK versionCode 必须等于 expected。
5. 模板体积阈值 4–60MB（rebuild-inrt-template.ps1 与 :app:verifySlimPackagingTemplate 要一致）。
6. provider authority `com.boyai.auma.debug.provider` 与真 Pro 同装有冲突风险，发布构建须带 -PdevPluginUsbDiscovery=false。
7. 不要为「像 Pro」默认免 token；不要 inrt/GlassFlutterActivity.onDestroy 杀脚本/浮窗；孤儿清理跳过 CircularMenu。
8. DEBUG_RUN 广播 path 不解析项目 engines（项目运行要 UI 点或 插件路由）；单文件带首行 "nodejs"; 可正确选引擎。
9. adb 盲点导航在 Flutter 页面不稳定，验证脚本优先用「单工程 + 结果 JSON」模式（如 /sdcard/脚本/pnode、node24p1probe、node24uiprobe）。
