# VS Code 设备选择修复（扩展 0.3.3）

手机仍使用 dev-1190；本次仅更新电脑端 `jdkshen.aijspro-vscode` 到 **0.3.3**，VSIX 已安装到本机。

## 原因和修复

原“选择设备”调用了运行时自动选连接的 `pickConnection()`：一台在线时直接返回，零台时只显示连接提示，未列出 USB 手机。

- 独立的显式选择器始终弹出列表，显示已连接、USB 和已记住设备；取消直接退出，不再追加提示框。
- 支持刷新和手动地址入口；“重新扫描设备”和状态栏设备名称也打开该列表。
- USB 使用 `adb devices -l` 扫描；未授权或离线状态明确显示。adb 路径可通过 `aijspro.adbPath` 设置，缺少 adb 不影响选择已有网络连接。
- 每台 USB 手机使用独立动态转发端口。连接去重按地址和端口处理，避免两台手机共用 `127.0.0.1` 时漏掉第二台。
- 显式选择后运行使用该设备；其它手机握手不覆盖选择，所选设备掉线时不会静默改用另一台。
- 扩展关闭时只清理本实例创建的转发，不执行 `adb forward --remove-all`。

关键文件：`vscode-extension/src/devicePicker.ts`、`adb.ts`、`manager.ts`、`extension.ts`。
