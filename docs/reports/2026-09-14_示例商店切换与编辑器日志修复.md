# 示例、商店切换与编辑器日志修复

## 修改

- 主界面 ViewPager 保留全部五个页面，提前创建内容，避免跨页切换时创建远处页面；同时保留已加载数据和列表位置。
- 示例浏览器按目录保留 LazyListState，返回父目录恢复原位置；只有搜索、筛选、排序条件改变时重置当前位置。搜索弹窗复用页面结果数量，避免重复搜索。
- 商店实际对应 MiuixPluginFragment。保留插件加载结果，显式保留列表状态，使用包名作为稳定键和条目类型帮助复用；从安装器、应用详情、卸载界面返回时刷新。
- CodeEditor 原尺寸判断重复检查宽度，遗漏高度，并在 onDraw 中调用 setMinWidth/setMinHeight。现改为在测量阶段同步宽高，在父视口变化时刷新 CodeEditText，确保日志收起后重新绘制新增可见区域。
- CodeEditText 行号边距先取整数再比较，避免浮点宽度与整数 padding 不相等而反复触发布局。

## 边界

本轮优化页面创建、列表复用和布局刷新；未更换滚动惯性或回弹算法。默认文件管理使用 RecyclerView，示例、商店使用 Compose LazyColumn，两种组件的滚动表现仍有区别。保留全部页面会增加常驻界面的内存使用，未量化帧率或内存增量。
