## 使用方法

打开应用，点击“检查更新”。其他设备若仍配置自定义更新源，请先在“设置 → 更新源”清空地址，使用 GitHub；也可填入 [GitHub 最新版更新清单](https://github.com/Jdkshen/ai.js-pro/releases/latest/download/update.json)。

此 Release 沿用现有开发版签名。应用下载后继续校验包名、版本、SHA-256 和安装签名，并由系统安装器完成安装。K40 的更新识别与下载链接已验证；本次未在 K40 执行覆盖安装。
