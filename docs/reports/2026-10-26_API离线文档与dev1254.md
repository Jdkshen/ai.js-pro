## 文档范围

756 是「参考条目」数量，不是已验证 API 数量，也不是高级版兼容率。传统 HTML 标注为 Rhino 参考；QuickJS、Node.js 查对应指南。三引擎使用手册包含差异对照，不表示每个接口在三套引擎均可运行。未实现或未逐项验收的接口有明确说明。

原听海播放器项目仍未取得，不能据此宣称该工程已验收；Rhino 传统 UI 仍有主进程路径。真正 16KB 内核和全部高级版行为仍需后续专项验证。手机端 JDK/clang/完整 APK 编译工具链按用户既有决定不再引入。
