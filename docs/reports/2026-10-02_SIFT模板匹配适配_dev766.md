## 实现

- 现有 OpenCV 5 构建补入 features，更新同一构建的 arm64 动态库及 Java/JNI 绑定，保留 OpenCL、TBB 及基底 AAR 资源。
- 使用真实 SIFT 的 128 维浮点描述子、FLANN KNN、Lowe 比率过滤和 RANSAC 单应变换；没有以 ORB-lite 替代 SIFT。
- 原包 OpenCV 4 Java 包名改为 OpenCV 5 的 features / geometry。[官方迁移说明](https://github.com/opencv/opencv/wiki/OpenCV-4-to-5-migration)
- 小图显式 scale 生效，宽高取实际缩放尺寸分别还原，region 坐标加回原图偏移。
- 校验匹配内点数、凸性、角度、有限数值和非退化面积；中心通过单应变换求得。
- Rhino 借用 ImageWrapper Mat；QuickJS 单独释放 images.toMat 副本；临时 Mat 和 KNN 矩阵在 finally 回收，算法状态清理。
- 结果图写入失败明确抛错，无可靠匹配返回 null，原图不随特征清理而失效。
- 现有 images.detectAndComputeFeatures / images.matchFeatures 兼容后端仍为 ORB-lite；本例的可复用接口是 require('./sift')。

OpenCV AAR SHA-256：`a2a2f8550e19fa0beffbc5dd37f059f067d25012d0c4555c0965846d65bdfe9a`。

`libopencv_features.so` 与新版 `libopencv_java5.so` 所有 LOAD 段对齐为 0x4000（16 KB）。本轮新增 features 仅覆盖 arm64-v8a，其他 ABI 尚未补齐。
