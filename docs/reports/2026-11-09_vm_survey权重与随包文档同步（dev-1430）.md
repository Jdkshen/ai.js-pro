- 新增可选 `weights{switchCount,switchCases,dispatchLoopBackEdges,arrayIndexOps,invokeCount,instructionCount,classPayloadBytes}`；`score = min(100, Σ normalized×weight)`、**`rawScore = Σ`（不封顶）**，`contributions` 用**实际生效权重**算。

- **默认权重冻结**：默认表 = 改造前系数（18/2/5/2/1/1/1），单测逐字段断言 `score/rawScore/contributions` 与历史一致；并断言**工具层每个候选等于用返回的 features 重算纯函数**（防止偷偷用别的权重）。
- 非法权重 → `INVALID_ARGUMENT` 并**列出 7 个可用键**：负数 / 非整数 / >1e6 / 未知键 / **生效表全 0**；单项 0 = 关闭该项（贡献项仍出现且为 0）。

## 6. 未做 / 边界

1. `weights` 只接受**非负整数**（不允许小数）；上限 1e6；`bigLiterals` 不参与打分、系数固定 2 且不可调（在 `weightsFixed` 里明示）。
2. 显式传过 0 的键会出现在 `contributions` 里（值为 0），因此「显式传全套默认值」与「完全不传」的 contributions **不完全相同**（前者多 0 项），但 `score/rawScore` 完全相同。
3. `minScore` 与 `scoreBuckets` 仍是**封顶口径**；权重拉大时多个候选并列 100，并列按既有 tie-break（`evidenceRef`）排序——要看真实区分度请用 `rawScore`。
4. 未做：权重持久化/profile 名、按候选类别分组权重、`bigLiterals` 统计。
5. 文档里 `weights` 的措辞保留「**默认权重**未用真实 VMP 样本校准（可用 `weights` 自行校准）」——指默认表，不矛盾。
