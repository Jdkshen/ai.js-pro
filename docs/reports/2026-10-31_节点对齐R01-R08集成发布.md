## 4. 已知边界

- $ui.inflate 仍不可用：QuickJS 的 $ui 是 C++ 白名单 Proxy，需要改 quickjs_jni.cpp 并重编 native；ui.inflate 正常。
- 宿主单次节点预算（约 200KiB/500 节点/5s/5000 访问）未变；客户端只能如实报告截断，真正服务端 cursor 分页需要改宿主 AIDL，本轮未做。
- Node 位置序号上限仍为 255（Node 线协议与同级测试冻结）。
- Node 等级 2 是「源码不可读的自解包加载器」，不是 V8 字节码；安全差异是产物可读性，不是密码学强度。
- plugins/apkbuilder-plugin/src/main/assets/template.apk 由 :inrt 现状重生成为 88,335,762 字节（+17.5MB），与 template-manifest.json 一致；宿主内 apps/app/.../template.apk 仍是旧瘦身模板，未同步。
