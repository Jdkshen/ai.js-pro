## 一、v4 §10.3：号表「字符串常量 + transact 常量」兜底模式

`apk_dex_interface_table` 新增 `mode = auto | descriptor | string_const`（默认 `auto`）：

- `auto`：canonical（接口类 + `TRANSACTION_*` 静态字段 → `transactSource=static_field`）**只在方法表非空且 static_field 时**直接用；否则自动退到兜底；
- `string_const`：只用字符串池 + `transact`/`onTransact` 常量，**不要求接口类存在**（就是他们 10.3 要的）；
- 兜底四步照做：字符串池匹配 descriptor → 同方法回溯 `writeInterfaceToken` 的 `const-string` → 同方法回溯 `transact(N)` 的 `const/4|const/16` → 扫 `onTransact` 的 `packed/sparse-switch`；
- 输出带 **`evidence`**（`writeInterfaceToken+transact` / `onTransact-packed-switch`）、**`confidence`**（high/medium/low）、**`callSiteLocator`**（可直接 `apk_decompile_method` 复核）、`side`(client/server)、`transactSource=string_const+transact_const`（不伪装成 static_field）；
- 取不到就给 `STRING_POOL_TOKEN_NOT_FOUND` 等 warnings + `nextActions`，**不编造编号**。

单测 9 项：只有字符串常量 + `transact(0x0f)` → 得到 code=15（high）；`onTransact` packed-switch → code 1/2 → `requestPermission`/`checkSelfPermission`；canonical `mode=descriptor` 仍 `static_field`（requestPermission=15）；不存在的 descriptor + `string_const` → 空表 + warnings + nextActions。
