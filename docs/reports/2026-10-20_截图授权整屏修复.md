# 截图授权修复：强制整屏 + 自动授权跨进程（dev-1164 → dev-1167）

- 时间：2026-10-20
- 现象（用户反馈）：自动化获取截图权限时，系统弹窗总是选「共享一个应用」；切到别的 App 后截图变黑/报错（单应用模式 MediaProjection 只投被选应用，切后台即黑帧）。
- 影响范围：所有走 MediaProjection 截图的脚本（Rhino / QuickJS / Node24 的 `requestScreenCapture` / `captureScreen`）。

## 根因

1. **授权范围用了系统默认**
   `ScreenCaptureRequester` 与 Node 的 `Node24CaptureConsentActivity` 都调用 `manager.createScreenCaptureIntent()`。
   Android 14+ 因此弹出「共享一个应用 / 共享整个屏幕」选择，自动化脚本的坐标兜底又会点到应用列表，最终拿到单应用会话。
   （历史报告 `2026-09-13_单应用截图兼容修复.md` 当时为了恢复选择权改回默认，但对自动化场景是反向的。）
2. **:node24 进程里没有无障碍服务实例**
   Node 授权页声明在 `:node24`（\`:node24_1..3`）进程，而 `ScreenCaptureAutoConsent` 通过
   `AccessibilityService.Companion.getInstance()` 取服务——该实例只在主进程被赋值，所以 :node24 里永远是 null。
   日志表现为不断打印 `waiting accessibility service`，授权框不会自动点，只能等 55s 超时。
3. 旧兜底坐标（0.12,0.589）恰好落在单应用列表上，会主动点成单应用。

## 修复（dev-1164 ~ dev-1167）

| 改动 | 文件 |
|---|---|
| API 34+ 用 `MediaProjectionConfig.createConfigForDefaultDisplay()` 强制整屏授权（系统不再给单应用选项） | `modules/engine/.../capture/ScreenCaptureIntents.java`（新增） |
| 主进程/Node 两条请求链都改用该 Intent 工厂 | `ScreenCaptureRequester.java`、`Node24CaptureConsentActivity.java` |
| 自动授权：30s 等待无障碍重连；精确文案点击（共享屏幕/开始共享/开始录制/允许 ± 整屏选项优先）；去掉点应用列表；确认按钮坐标兜底 4 次 | `ScreenCaptureAutoConsent.java` |
| :node24 跨进程广播让主进程代持 arm/disarm（主进程有 AccessibilityService 实例） | `CaptureConsentBridge.java`、`CaptureAutoConsentReceiver.java`（新增）+ engine AndroidManifest receiver |

## 真机验证（K40 cccc62c7，dev-1167）

1. **授权框已是整屏**：截图 `output/consent2.png` 显示「共享整个屏幕」默认选中，无「共享一个应用」入口；
2. **零手动点击**：logcat

3. **切 App 后截图不黑**：探针脚本先截当前页 → `app.launch('com.android.settings')` 切到设置 → 再截：
   ```
   first: 1080x2400 mean=33.2
   second: 1080x2400 mean=25.0
   pass: true
   ```
   帧图证据：`output/capture-scope-f1.png`（前台）、`output/capture-scope-f2.png`（切到设置后，非黑）。
4. 发布：dev-1164（整屏 Intent）→ dev-1165（补充确认文案）→ dev-1166（30s 等待/精确点击）→ **dev-1167（跨进程代持）**；
   update.json = 1167，K40 / MI8 已安装 dev-1167。

## 注意事项

- 无障碍服务被系统关闭/应用被强行停止后，自动点击会失效（log 打印 `waiting accessibility service`）；重新启用无障碍即可，脚本仍可手动点一次授权。
- 单应用截图能力不再默认提供；确有需要时可后续加显式开关（`MediaProjectionConfig.createConfigForUserChoice()`），当前自动化优先整屏。
