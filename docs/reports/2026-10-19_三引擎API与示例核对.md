## 核心剩余缺口

| 项目 | 核对结果与影响 | 证据 |
|---|---|---|
| QuickJS `:script` 选择器 | **实际失败**。同样的 `text(...).findOnce()` 在 Rhino `:script` 正常，在 QuickJS 报“不支持选择器链”。227 项回归因含截图 API 走主进程，覆盖不到此路径。 | `context-quickjs.json`、`context-rhino.json`；`QuickJsHostBridge.selectorCreate` |
| Node 引擎管理与线程 | `engines` 只有 stopAll；线程转发没有真实任务实现。引擎通信示例使用的 execScriptFile/myEngine/执行事件仍缺失。修正子脚本标记没有解决父脚本缺失 API。 | Node 审计 F1、相应模块与逐示例台账 |
| Node UI 与 Java 继承 | 多个示例使用 `layoutXml`、Widget、自定义 Java View/类。当前布局主要支持 layoutId，defineClass 返回 marker/对象不构成真实 Java 子类；相关工程仍受阻。 | Node 审计 F2/F3；ui.js、NodeUiHost |
| Node 模块与订阅 | plugins/media/ocr/zip/OpenCV addon 等缺失；dialogs builder、浮窗 view/触摸、通知动作与无障碍事件等仍不完整。 | Node 审计及每方法限制 |
| Rhino 跨进程范围 | UI 与投屏默认保留主进程路线；`:script` 无障碍仅为代理子集，服务对象和部分系统事件不可用。 | Rhino migration_matrix；RemoteAutomationBridge/RemoteAccessibilityBridge |
| 定时任务与 inrt | 发现调度初始化、跨进程服务和模板能力的静态缺口。本轮没有把主 App 验证等同于 inrt 已通过，没有重建并运行所有模板工程。 | Rhino 审计 R-TASK-01/R-INRT-01，静态结论待专项端到端验证 |
| 其它示例问题 | 控制台 UI 示例的 bottomnaviagtion 标签缺少映射；录制示例引用不存在的 test.auto；部分工程依赖 CDN、构建链或用户输入。 | 逐文件台账与 Rhino 原始审计 |

## 已实施的修补

1. Node color 扩展恢复 parseColor/argb/rgb/通道读取/isSimilar、Color.toInt 和整数解析；保留新版 HSV/HSL 类。修正 HSL 饱和度分母、负 hue，以及黑色/透明黑的 0÷0 边界。主控新增黑色边界断言，先复现失败再修复。
2. Rhino `isShuttingDown` 从拼错的 isShopped 改为真实 isStopped 别名。
3. Node 调用 Rhino 的悬浮窗子脚本标记改为 rhino，使 XML 布局由正确的解析器处理；父脚本通信 API 的缺口保留。
4. QuickJS 传感器示例改用 register 返回的 Sensor、`sensor.on('change')`、`event.values` 和正确注销，删除虚假的“不支持时返回 noop”演示，并保证媒体音量恢复。
5. Rhino PaddleOCR 示例显式选择 ppocr，移除不生效的 slim 档位；QuickJS OCR 注释明确 detect 属于会话对象。
6. 示例网页 URL 明确使用 HTTPS，任务查询打印显式转换 Java List；两项为表达澄清，见下节，未作为已证实的运行故障计数。
7. 修正旧验证脚本仍指向“QuickJS 新引擎”的路径；缺少图色样例时改为失败，避免伪装成跳过。增加可复用的全量清单、证据采集与汇总工具，以及 Rhino 行为回归脚本。

未修改 C++、Java/Kotlin、Flutter Dart、AIDL、进程路由、权限默认值或 inrt 模板。跨进程缺口按真实限制报告，没有通过改变脚本路由掩盖。
