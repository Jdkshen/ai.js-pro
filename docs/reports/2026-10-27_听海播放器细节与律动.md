## 具体修改

### 播放器外观与动效

封面 20dp 圆角、48dp 收起入口、统一主题的点击涟漪；时间使用固定宽度和 tabular numerals，播放状态不会挤动控件。歌名保持完整无障碍描述，长按复制歌曲信息。封面大小按窗口高度减控制区计算，窄屏减小左右留白，字号放大预留相应行高，极矮窗口由原生 ScrollView 兜底。窄屏/大字体预算有单元测试，本轮未覆盖所有实体设备和横屏组合。

封面内新增五柱形播放动效，16 张透明小帧由程序绘制，使用 Android `AnimationDrawable` 每 70ms 换帧（约 14fps）；只变化小块动效和必要的秒数/进度。无每帧 JS 回调。暂停、加载、出错、后台、离开播放器时停止；系统禁用动画时保持静止。「我的 → 播放器与音质设置 → 播放律动」可关闭。它是播放状态装饰，不分析实际音频频谱/节拍，不采集麦克风。

初始实现使用 60fps ScaleAnimation，虽然流畅但增加 CPU，已替换为上述原生帧动画，交付包不使用旧实现。

### 画面跳动与交互

1. **专辑动态取色**：正在显示完整播放器时原位修改背景、文字、图标、涟漪和 SeekBar drawable；保留同一个 overlay 和 SeekBar，不重新 inflate。取色等待拖动结束；隐藏主页标记待换色，返回时再更新。
2. **迟到封面**：每个 ImageView 绑定本次请求的唯一 token，异步回包在 UI 写入前再次校验。A→B→A 也不会接受旧 A 请求。切到没有封面的新歌曲先清空上一首图片，显示音符占位；mini 与完整播放器共同修复。
3. **进度回弹**：触摸松手后维持 seeking 锁直到 seek 真正提交，再释放并刷新；旧请求完成不能解锁新手势。键盘/无障碍用户调整无需触摸结束事件，也能短防抖提交到真实播放器。
4. **加载/错误**：状态结构新增 `playWhenReady`，加载中切换播放意图立即通知界面；播放键图标和内容描述对应真实动作。歌手不被错误字符串替代；独立错误状态可点开详情和重试。暂停只改变加载后的播放意图，不取消网络请求。
5. **音量写盘**：拖动只实时更新 MediaPlayer 音量；松手保存一次。非触摸调整 250ms 防抖，关闭菜单 flush，销毁/退出清理定时器。未改为不落盘的假开关。
6. **后台生命周期**：静态读取确认本地 `NodeUiLocalActivity` 没有转发 onPause/onResume；仅覆写 JS Activity 方法的初版真机失败。工程改用 Application.ActivityLifecycleCallbacks，按具体 Activity 过滤，后台停动效和 UI 写入、保持音乐播放，返回后恢复。重建/退出显式解绑，避免保留旧 Activity。没有修改宿主生命周期实现。
