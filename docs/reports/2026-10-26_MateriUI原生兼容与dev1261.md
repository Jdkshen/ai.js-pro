## Node/M3 日志页修复（dev-1265）

- 问题：官方 `使用Android原生界面`（M3 UI Demo）日志页 `<FileConsoleView>` 空白；Node/M3 与 APK 日志都看不到。
- 根因：`ProjectViewCompat` 把 Pro 的 `FileConsoleView` 映射成了普通 `ConsoleView`，没有走 `FileConsoleView` 构造器里的 `NodeUiLocalSession.bindConsoleView`，因此没有挂任何 console。
- 修复：改为映射到本仓库的 `FileConsoleView`，保留其 Node UI console 绑定。
- 验证：内置示例 `Node 引擎/Node.js/Node.js中使用UI/使用Android原生界面`，点「日志」→「运行」后显示 `已勾选卡片: []`；警告/错误过滤控件正常。
