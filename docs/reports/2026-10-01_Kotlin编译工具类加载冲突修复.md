# JavaKotlin2Dex Kotlin 编译失败修复

## 最终方案：修复应用源码

用户明确要求修复 AIjsPro 应用的兼容性。下方修改第三方 dex 的方案属于先前走偏的诊断方案，已撤回交付建议；Downloads 中的两个工具补丁包保留为旧实验产物，不用于本次修复。

源码修复位于 `modules/engine/build.gradle`：增加与根项目 Kotlin 版本一致的 `org.jetbrains.kotlin:kotlin-reflect:2.1.0`，并通过 engine 的 `api` 依赖传递给应用及打包运行时。

问题的直接原因是宿主仅有 Kotlin 标准库，缺少完整反射工厂。宿主 `kotlin.jvm.internal.Reflection` 初始化为轻量实现，产生 `ClassReference`；工具子加载器中的完整反射 API 期待 `KClassImpl`，从而发生类型转换异常。补齐宿主完整反射后，标准库和反射 API 在宿主同一加载器中解析，原工具可以正常委托父加载器。

新增 `KotlinCompilerReflectionTest.java` 两项回归：标准库创建的 KClass 能完成属性反射，以及 Kotlin 1.6.21 编译器实际执行命令行参数反射。旧编译器仅作为测试依赖，并限制版本为 1.6.21，避免 Material 的 Kotlin BOM 自动升级测试对象。

## 输入与结论

用户提供 `C:\Users\18101\Downloads\JavaKotlin2Dex.zip`，Java 示例正常，Kotlin 示例返回 `THROW java.lang.reflect.InvocationTargetException`。

在 K40（cccc62c7，Android 16，AIjsPro dev-750）以关闭缓存、全新输出目录复现原始失败。直接调用编译器取得原因：

```text
java.lang.ClassCastException:
kotlin.jvm.internal.ClassReference cannot be cast to
kotlin.reflect.jvm.internal.KClassImpl
    at kotlin.reflect.full.KClasses.getMemberProperties(KClasses.kt:148)
    at org.jetbrains.kotlin.cli.common.arguments.ParseCommandLineArgumentsKt
        .parsePreprocessedCommandLineArguments(parseCommandLineArguments.kt:76)
```

应用自带 Kotlin 2.1.0；工具编译器与反射库为 1.6.21。工具的 `KotlinRealtime` 把 `context.getClassLoader()` 用作资源加载器的父加载器，其下挂载编译器的 `InMemoryDexClassLoader`。父级优先解析导致 Kotlin 标准库来自应用，完整反射实现来自工具，反射解析命令行参数时类型不一致。

用户成功截图的运行时间仅 0.01 秒，包内也有旧 `ktapp.jar` / `ktapp.dex`。该截图不足以证明执行过实际编译；本次验证均单独记录实编结果与缓存结果。

## 修复位置

修改第三方工具 `JavaToDexAll.dex`，版本标记为 `Kotlin-1.18-fix1`。没有修改应用的全局加载器或应用 Kotlin 依赖。

1. `KotlinRealtime.run` 在建立资源与编译器加载器前，以 `android.content.Context.class.getClassLoader()` 获取 Android 框架加载器作为父级。工具自带的 stdlib 与 reflect 在同一编译器加载器中解析；资源目录镜像仍保留。
2. `KotlinRealtime.runCompiler` 捕获反射异常时，把 `Throwable.printStackTrace(PrintStream)` 写入现有编译器输出流，保留完整原因链。
3. 工具 `Compiler.VERSION` 及相关版本字符串更新。
4. `demo-kotlin.js` 增加 Rhino 指令，默认 `krtUseCache=false`，说明验证后可启用缓存。完整修正版移除旧编译产物。

通过已有 baksmali / smali 3.0.9 工具链修改并重组 dex。原压缩包保留。补丁脚本、反汇编、编译日志和测试脚本均在 `.artifacts/kotlin-dex-20261001/`。
