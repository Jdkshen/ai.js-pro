## 实现

- `apps/app/src/main/java/com/jdkshen/aijspro/ui/editor/AceCodeEditor.java`：WebView、文本快照、原生操作适配、工作区文件读取与生命周期。
- `apps/app/src/main/java/com/jdkshen/aijspro/ui/editor/ProCodeEditorActivity.java`：标签页接入，保存／运行／关闭／另存为／重置前先等待最新文本快照。快照有递增序号，旧回调不会覆盖新文本；保存标记对应实际写入的内容。
- `apps/app/src/main/assets/editor/ace/editor.js`：折叠、撤销重做、查找替换、格式化、断点、主题、代码补全、参数提示与诊断。
- `apps/app/src/main/assets/editor/ace/pinch.js`：双指调整字号并刷新字符尺寸，阻止原有手势修改页面 zoom，同时让 Ace 清理首指长按和手势状态。
- `apps/app/src/main/assets/editor/ace/language/service.js`：独立 Web Worker 中的 TypeScript 5.9.3 语言服务，通过 JSON-RPC 处理文档、补全、悬浮类型查询、参数提示与诊断。启动就绪后才发送查询；仅活动标签页保留 worker。相对模块可读取其他标签页的未保存内容，切换工作区仍保留原标签页的模块上下文。
- 旧编辑器保存的滚动位置从物理像素迁移到 CSS 像素。单指点击、选择和滚动继续使用 Ace 的 Android 触摸处理。

依赖 Ace 1.4.12 与 TypeScript 5.9.3，许可证及依赖哈希随资源保留。Ace 来自用户已有的解包资源，TypeScript 来自本仓库 VS Code 扩展的既有安装；`tools/vendor-ace-editor.py` 可重建第三方资源。常用 Android 脚本 API 有类型声明；Java 动态桥接及部分扩展模块按动态类型处理。Rhino E4X 等专有语法的 TypeScript 诊断未作完整兼容处理，执行仍使用原生引擎。
