# 日志对齐 Pro（task-191）

日期：2026-10-20。执行：t1-native-services。验证机：K40（cccc62c7，dev-1135 待填）。

## 1. 目标（imgui-re task-187 对照结论）

Pro 9.3.11-0 行为：
- 正常结束：TRACE 结束行 `\n------------\n[路径]运行结束，用时1.336000秒`（6 位小数），无 Toast/ERROR；
- 异常：先结束行，再 ERROR 堆栈 + 短 Toast「错误: Error: XXX (path#line)」；
- 停止/关 UI：只结束行，无 error/Toast；
- 主日志 log.txt 一处可见全局开始/结束。

我方 dev-1133 差异：3 位小数、:script 开始/结束行不进主日志页、异常错误堆栈在结束行前、host 多弹「脚本运行失败」Toast、`D/Engine destroy` 噪音。

## 2. 实现

### P0
1. `apps/app/src/main/res/values/strings.xml`、`values-en`、`apps/inrt/.../strings.xml`：`%2$.3f`→`%2$.6f`；
2. `ScriptHostService.RunListener`：onStart 时把 `开始运行[source]`、结束时把 `\n------------\n[source]运行结束，用时%.6f秒` 以 what=103（VERBOSE/TRACE）直接转发主进程统一日志页；与脚本 console.log 同流。

### P1
3. `ScriptEngineService.GLOBAL_LISTENER`：开始行/结束行统一在这里打印（结束行在 onException 的 console.error 之前）；移除 `onScriptExecution` 的 ON_START 重复打印；
4. `PocScriptHost`：不再弹「脚本运行失败：…」Toast（引擎侧「错误: <message>」保留，对齐 Pro）；
5. 用户停止/关闭 UI：ScriptInterruptedException 路径只打结束行，无 error/Toast；
6. app `ScriptExecutionGlobalListener` 不再重复打结束行，仅保留前台执行租约。

### P2
7. 移除 `RunnableScriptExecution` 的 `D/RunnableJSExecution: Engine destroy`；ScriptRunLog footer 保留为运行日志诊断。
