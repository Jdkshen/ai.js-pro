## 一并修正的细节

1. `run_script` 接受 `path` / `file` / `source` 三选一；绝对路径仍须落在操作目录内。源码在内存执行，文件指定引擎支持异步，临时副本保留到实际执行结束。
2. `config` 支持 `path`、`workingDirectory`、`engine`、`delay`、`interval`、`loopTimes`、`arguments`；顶层引擎优先，任务结果报告实际执行引擎。
3. QuickJS 原生桥补齐 `engines.myEngine().execArgv`，重复读取保留参数对象的修改。
4. 真机暴露出两项参数类型问题：Rhino 的嵌套 Map/List 无法按 JS 对象访问；Android JSON 包装器把 Gson 数字包装成字符串。现分别在 Rhino 运行作用域转换对象/数组，并统一使用有限 JS 数字。两引擎验证了嵌套对象、数组、数字、布尔、null、Unicode 和对象修改。
5. 任务日志从该引擎自身控制台读取，避免并行任务日志串入；保留最近 300 条，每条最多 16 KiB。日志尾部裁剪不拆开 Unicode 代理对。
6. 延续此前审计修正：参数 Schema 使用真实类型；内存 API 探针使用独立标记；任务数据准备后再公布终态；等待超时不删除仍在使用的临时副本。

主要源码位于 `apps/app/src/miuix/java/com/jdkshen/aijspro/mcp/`；QuickJS 桥接位于 `modules/engine/src/main/java/com/stardust/autojs/engine/QuickJsHostBridge.java` 和 `modules/engine/src/main/cpp/quickjs_jni.cpp`。

## 使用范围

- 直接 MCP 截图需要 **Android 11+ 和已启用无障碍**；旧系统可在脚本中使用录屏截图 API。受系统保护页面仍可能拒绝截图。
- 节点树取决于系统实际提供的数据；空树会给出诊断。本次读取验证为设置页，没有重新验证用户的微信故障页。
- Rhino 当前循环引擎可能不返回脚本末尾表达式；请读取任务状态和日志。两引擎执行配置均已实测。
- 引擎成员探针只枚举自身可枚举成员；数量差异不代表完整函数签名清单。
- 当前协议协商版本维持 `2024-11-05`、`2025-03-26`、`2025-06-18`；服务提供 tools 能力，单消息 JSON Streamable HTTP。

调用参数和示例见 [MCP 使用说明](../MCP_SCRIPT_SERVICE.md)，应用也可通过 `learnAutoJsSkill` 获取随包说明。
