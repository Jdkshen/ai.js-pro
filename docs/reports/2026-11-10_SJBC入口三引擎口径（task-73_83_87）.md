## 证据（file:line）

- Rhino 挂全局：`modules/engine/src/main/assets/modules/__globals__.js:84-95`（用**既有** `runtime.getProperty` 读 `mProperties`）。
- Rhino 返回对象：`SjbcApi.toScriptValue`（`context.newObject(scope)` / `context.newArray(scope, …)`；**有 Rhino 上下文**才转，否则回退 Map）。
- QuickJS 模块清单：`QuickJsHostBridge.java:334-336` 的 `assets[]`（本轮加入 `modules/qjs-sjbc.js`；真实样例见 `assets/modules/ui-accessibility.js:84-89`、`qjs-plugins.js:17-18`）。
- QuickJS 宿主 op：`QuickJsHostBridge.sjbcCall(...)`（public，返回 JSON；白名单 `run`/`runEntry`）。
- QuickJS JS 侧：`assets/modules/qjs-sjbc.js`（`Java.type(...QuickJsHostBridge).forEngine(id)` → `.sjbcCall(...)` → `JSON.parse` → `global.sjbc`）。
- Node24：`run_script{engine:'nodejs'}` 下 `typeof sjbc` 与 `require('sjbc')` 均不可用（task-73 结论）；要补需 Node24 host 新 op + `node24/modules/` 绑定，**本轮不做**。

## 未验证边界

- **QuickJS 侧没有真机**：本轮只有 JVM 的 JSON 形态断言（`SjbcJsonShapeTest`）与**装配级源码钉**（模块清单/op 白名单/JS 调用/JSON.parse/不复制实现）；QuickJS 真机由 Lead 复验。
- Rhino 侧的属性访问已真机验（dev-1456，`r.steps` 等）；**QuickJS 真机待验**（期望同样 `r.steps` / `r.prints[0]` 可直读）。
- `toScriptValue` 在**无 Rhino 上下文**时回退 Map（QuickJS/Node24/纯 JVM 路径），QuickJS 实际不走它（走 JSON 通道）。
- Node24 不可用是**结论**（不是未做）：`sjbc` / `require('sjbc')` / 取属性通道三者皆无。
