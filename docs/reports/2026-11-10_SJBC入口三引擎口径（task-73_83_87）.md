## task-89：QuickJS 一调就抛「脚本引擎已经结束」

- **位置**：`QuickJsHostBridge.forEngine(int)`（`QuickJsHostBridge.java:317-323`）查 `sActiveBridges.get(engineId)`，null 就抛 `IllegalStateException("脚本引擎已经结束")`；注册表由 `setOwnerEngineId`（同文件 `:304-314`，注释说在 `engine.init()` 里注入）填充。
- **修**：新增 `forCurrentEngine()`（`:317+`）——**注册表里恰好一个活动 bridge** 时兜底返回它；多个时**拒绝**并报出数量（绝不猜错引擎）；另有只读 `activeBridgeCount()`。JS 侧 `qjs-sjbc.js` 先 `forEngine(id)`，失败再 `forCurrentEngine()`，并把 id / activeBridgeCount / 两个错误原文写进异常。
- **诊断入口**：`sjbc.debug()` → `{engineId, hasEngines, activeBridgeCount, liveBridgeCount, registeredIds, engineHandleFromHost, bridgeResolved, bridgeResolvedVia, bridgeError, hostOp}`（只读、不跑字节码）。真机若仍失败，先看 `hasEngines`（JS 侧能不能拿到 `engines`）、`activeBridgeCount` / `liveBridgeCount`（宿主侧注册了几个 / 活着几个）、`bridgeResolvedVia`。
- **已真机验证（dev-1460，K40）**：`debug={"engineId":0,"activeBridgeCount":0,"liveBridgeCount":1,"registeredIds":[…],"engineHandleFromHost":1,"bridgeResolved":true,"bridgeResolvedVia":"forCurrentEngine(fallback)","bridgeError":null}` ⇒ **兜底路径生效**，`r.ok=true steps=1990 codeBytes=476 certShaUsed=38166a4b…`、`Array.isArray(prints)=true len=5 p0=fib(10)=55`、**`forEach` 收集到 5 条**（真 JS 数组）；**错证书** → `SjbcException: SJBC 池层解密失败（AEAD 拒绝：证书指纹不对或池被篡改）` ✓。
- **小尾巴（低优先、非阻塞）**：`activeBridgeCount` 仍为 0（`setId` 补登记在这条路径上没触发），**当前靠 live-bridge 兜底**——行为正确且安全（恰好一个才用，多个则拒绝并报数量）；「id 登记为何不触发」仍待查。

## task-92：QuickJS 里「按 id 注册」这条路为何是空的（结论：**live-bridge 兜底是正常路径**）

- 事实：真机 `debug` 一直是 `engineId=0 / activeBridgeCount=0 / liveBridgeCount=1 / bridgeResolvedVia=forCurrentEngine(fallback)`。
- 代码依据：id 只在 `ScriptEngineManager.java:115 engine.setId(id)` 里分配；`QuickJsHostBridge.setOwnerEngineId` 只登记 `engineId>0`（`:308`）；**MCP 侧代码里没有任何 `setId` 调用**（grep `apps/app/.../mcp` 0 命中）⇒ MCP `run_script` 建出来的引擎**很可能从头到尾没有 id** ⇒ 按 id 注册那条路天然为空。
- 因此**兜底就是正常路径**：`sLiveBridges`（构造加入 / `close` 移除，不依赖 id）+ `forCurrentEngine()`「恰好一个在跑 → 用它；多于一个 → 拒绝」。语义已写进 `qjs-sjbc.js` 的 `debug()` 注释。
- `registeredIds` 之前是 Java `List` ⇒ 宿主把它包成 `{__javaHandle:…}`（脚本读不到）⇒ 新增 `registeredIdsJson()`（JSON 字符串），JS 侧 `JSON.parse` 成**普通整数数组**。
