# 三引擎架构对齐实施（dev-1286 已发布）

用户要求先完成代码架构对齐，再集中测试及发布。本轮已按该顺序完成并发布局域网 dev-1286；最终证据、包位置和剩余边界见[发布验收](2026-10-29_dev1286发布与架构对齐验收.md)。旧 dev-1285 的结果没有用来替代本轮验收。

## 代码实现

1. `ScriptExecutionLifecycle` 统一 CREATED、RUNNING、STOP_REQUESTED、CANCELLING、RELEASING、RELEASED；三引擎适配、销毁通知幂等化，stopAll 在注册表锁外逐项停止。
2. Node 外部停止先投递 `process.exit(-9000)`，750ms 后仍未退出才取消 native；第 4 次停止请求直接升级。UI 关闭也走同一停止入口。JS 退出前先解绑原生消费者，再运行退出钩子。
3. Node 执行返回与资源清理完成分开；两者均完成才归还服务端运行槽。清理失败或超时使该进程退出，不复用不确定的状态；旧清理按 owner 校验，UI 队列超时任务撤销。
4. `ScriptResourceScope` / `ScriptJavaResources` 统一资源归属和逆序回收；接入 Node、QuickJS 和 Rhino Java 包装层。只接管明确创建、注册、挂载的对象；借用的框架对象不因丢失 Java 句柄而被任意释放。原始 WindowManager 窗口先在 UI 线程摘除。
5. QuickJS JNI 的上下文改用共享生命周期：destroy 撤销新调用，最后一个已进入的 JNI 调用负责释放 context/runtime，清掉遗留 timer 引用。禁止跨线程同时进入同一 JS 上下文；Java 销毁不再持锁 join 脚本线程。停止标记不在 evaluate 开始时清零。
6. 退出事件和 headless UI 路由增加任务级策略，消除一个 UI 任务修改进程全局开关而影响其他任务的问题。保留旧 headless 默认接口作为兼容入口。
7. 普通 UI 入口改在 `:script` 内创建执行记录和 Activity；Node 继续使用自己的池 Activity，避免再套空窗口。明确本地旧路径与 `:native` 有对应 Activity，避免执行表跨进程失效；UI 暂存失败不再自动回主进程加载。
8. FloatyService 增加组件解析器；普通脚本浮窗在 `:script`，宿主悬浮按钮、native、Node 槽和分析器各自使用同进程服务。启动、停止、console.show 改走统一解析入口；窗口创建投递主线程，服务销毁释放窗口集合。
9. 截图授权回调由进程内 IntentExtras 引用改为 ResultReceiver；每个 runtime 独立 requester，取消/晚到结果按请求代次和完成状态处理。隔离脚本可请求本地 MediaProjection，已有本地帧时不强制降为主进程 PNG；授权结果与停止释放串行。

10. 无障碍及 AutomationHost 后端统一在 `:script`；同进程直连、其他进程使用 AIDL。权限状态通过同 UID Provider 查询，UI 读取短期缓存；事件支持多个订阅者，单个 runtime 退出不解绑其他订阅。
11. 节点分析采集在无障碍进程，使用有预算的抓取和私有快照令牌回传；显示仍在 `:inspector`。主进程通过音量下键接收器退出分析，音量上键仍走全局停止。
12. 日志界面在 `:script`，统一日志环保留主进程；订阅、分包快照、清空、Binder death、晚到批次会话校验及 UI 帧批量渲染已接入。
13. MCP、VS 等主进程引擎入口使用文件请求 + Messenger 执行代理；源码不进入 Binder，保留参数、错误、日志、结果、运行状态和单独停止。停止中保持 STOPPING，实际释放后才终结；去掉 staging 失败回主进程的自动重试。
14. Node 结果回报也等待资源退役完成，避免客户端过早释放池租约。并发 Rhino/QuickJS 共享图片状态只在最后一个 runtime 结束后回置。
15. MCP 的 11 个无障碍工具通过同 UID Provider 在 `:script` 执行，截图和布局大结果使用有界私有文件回传；终端 `aijs-ui` receiver 同步迁移，避免无障碍移走后误报未开启。
16. QuickJS 普通并发进入受到保护；`ui.run` 使用显式 UI 交接标记和栈顶切换。取消尚未开始的 UI 回调会移除排队任务；已开始的回调先中断并等待退出，脚本不与 UI 回调重叠执行。

## 当前边界

这些是架构和生命周期对齐，不代表高级版每个 API 行为都已等价。仍需单列：节点大树分页/BFS 组合/跨布局身份、高级原生控件事件、编译加密 Node、完整高级版 API 行为验收。用户 Android 36 原机未连接，不能用 Android 35 的结果替代现场确认。Node 继续保留三槽独立进程，节点分析显示独立于脚本进程；不机械复制高级版的单一 `:script` 布局。
