# 停止脚本入口修复（task-165）

（K40 cccc62c7 本轮 adb 掉线，改在新手机验证；K40 复测项见 §6。）

## 1. 背景与复现

t2 在新手机 dev-1112 反馈：Node 浮窗脚本「停止不了」。逐项实测现状：

| 入口 | t2 反馈 | dev-1112 实测 |
|---|---|---|
| 通知栏 | 只有「保持运行中/正在上层显示/调试服务器」，无停止 | 前台通知存在且 `actions=1`（有停止 Action），但 HyperOS 3 折叠态**不展示 Action 按钮**（实测通知卡片只有标题/正文，LogFox 等应用的 Action 同样被隐藏）→ 用户看不到 |
| 任务页/列表 | 无「运行中/停止」 | 任务页（管理 tab）已有「运行中任务 1 / 停止 xxx / 停止全部脚本」；点「停止」可停掉 Node 任务、列表刷新为「没有运行中的脚本」→ 功能已存在 |
| 停止全部脚本 | 点了打开日志页 | 实测点击任务页 FAB「停止全部脚本」正常停止脚本、停留任务页、无日志页跳转（未能复现 t2 现象；但原实现依赖已加载的 running 列表，列表过期/为空时按钮禁用，属于可改进点） |
| Node 浮窗关闭/返回 | 关不掉 | close/back 链路归 native-process 的 task-164；本次 UI 侧提供独立停止入口兜底（通知/任务页/停止全部都能停掉浮窗脚本） |

## 2. 修复内容

### 2.1 通知栏停止入口（task-165 ①）

- `ForegroundService` 通知新增自定义 `RemoteViews`（`res/layout/notification_running_script.xml`）：标题 + 「脚本正在运行 · 点此停止并关闭悬浮窗」+ 红底「停止脚本」按钮（PendingIntent → `ACTION_STOP_ALL_SCRIPTS`）。HyperOS 折叠态直接可见，不再依赖被系统隐藏的 Action；AOSP 仍保留原生 Action。
- 通知栏「停止」统一走 `HostScripts.stopAllScripts(context)` → `PocRuntime.stopAllScripts(context)`：
  - `PocScriptHost.stopAll()`（含 Node 浮窗脚本所在的 :script 宿主进程）+ `PocNativeRunner`；
  - 主进程旧引擎 `ScriptEngineService.stopAll()` 兜底；
  - `NodeUiActivity.closeAll()` 关闭主进程侧 Node UI 覆盖 Activity（overlay 兜底清理）；
  - 释放前台通知 lease（`ForegroundService.releaseExecutionLease`）。

### 2.2 任务页/列表运行中与停止（task-165 ②，已存在，本次增强）

- 任务页已有「运行中任务」分组与行内「停止」；保留 `stopTasks` 按 token 停止（:script/:native/主进程任务）。
- 「停止全部脚本」FAB 改为独立桥 `stopAllScripts`，不再依赖任务页缓存的 running 列表：列表过期/为空/还没加载完时也能一次停干净。
- 相关：`PocRuntime` 在 `runFile` 入口为 Flutter/悬浮条/宿主链路触发的运行领取前台 lease（首个运行拉起通知，任务结束后 3s 轮询自动释放），保证脚本运行期间通知与停止按钮始终存在。

### 2.3 「停止全部脚本」统一入口（task-165 ③）

- 新增 `PocBridge` 桥方法 `stopAllScripts` → `PocRuntime.stopAllScripts(Context)`；
- `HostScripts.stopAllScripts(Context)`（主源集，反射）供通知栏/音量键/悬浮条/任务页共用；
- `PocFloatingBar` 悬浮条 ⏹ 改走同一入口；
- 停止后任务页自动刷新，列表变「没有运行中的脚本」，不发日志页跳转。

### 2.4 overlay 返回键/关闭兜底（task-165 ④）

- 关闭按钮/返回键的 Node 浮窗链路由 task-164（native-process）修 `floating_window.js / NodeUiBridgeService / Node24*`；
- 本任务提供 UI 侧独立兜底：通知栏「停止脚本」、任务页行内「停止」/「停止全部脚本」都会停掉 :script 宿主进程任务（实测 Node 浮窗脚本被取消、`Node24Service post-execute hasOverlay=false`），并 `NodeUiActivity.closeAll()` 清理主进程 Node UI 覆盖 Activity。

## 6. 已知限制 / 待复测

1. K40 本轮 adb 掉线（设备列表只剩新手机与 MI8），三入口需在 K40 补测一次；
2. HyperOS 3 对通知 Action 的隐藏是系统行为；自定义 RemoteViews 按钮已绕开，但不同 ROM 对自定义通知样式的允许度不同，AOSP 仍以 Action 为准；
3. Node 浮窗的 close/back 原生链路（点击右上角 ✕ / 返回键）仍以 task-164 修复为准；本任务只保证 UI 侧停止入口可用；
4. 「停止全部脚本」会同时停掉主进程旧引擎脚本（与音量上键停止语义一致）。
