## 集成期修的两个问题（都是我们自己引入的）

1. **`tool_schema` 插入位置错误导致 MCP 停服**（dev-1402 首版）：`canonicalNames = listOf(引擎工具…) + McpToolkitCatalog.names`，我插在 toolkit 名字**之前**，而 `listTools()` 把它加在 toolkit **之后** → 启动自检 `check(order == names)` 失败 → **MCP 不监听**（端口无 listener）。修正为 `+ McpToolkitCatalog.names + listOf("tool_schema")`，并新增 **`McpToolCatalogOrderTest`** 把"引擎工具 → toolkit → 元工具"的布局契约钉住。
2. **测试假死锁**：`GradleWorkerMain` 残留进程（当时已存活 232 分钟）持有旧 monitor，jstack 显示 Test worker BLOCKED 在 `ToolkitJobs.status()`。按"进程年龄 >25 分钟"清理后，同一套 630 项测试 **86 秒**全过。
