当前发布 **dev-1190**；K40 `cccc62c7`、小米 8 `ce4d2bdb` 已覆盖安装。VS Code 扩展为 **AI.js Pro 0.3.2**（`jdkshen.aijspro-vscode`），VSIX 已生成并安装到电脑。

## 电脑连接

按用户要求，电脑连接使用自家 AI.js Pro VS Code 扩展，不再启动 Auto.js Pro 的 ws-rpc / 21029 / mDNS 兼容服务。脚本引擎的既有 API 兼容工作不受此决定影响。

- 手机监听 `9317`；手机主动连接电脑默认 `8327`，支持自定义端口。
- 手机页提供应用内教程、地址复制、真实监听状态、握手连接数、扩展版本、连接失败原因；移除误导用户进入手机插件目录安装电脑扩展的入口。
- 主动连接使用前台服务，恢复应用时可恢复记住的目标；修复最后一次失败后仍不断重试的计数问题，取消的旧拨号不会覆盖新目标状态。
- 远程文件保留 Rhino / QuickJS / Node 的引擎和 UI 声明，`.node.js` 文件默认 Node；Node 相对依赖从手机脚本工作目录解析。
- 引擎进程初始化时不再清除共享远程缓存，避免 Node 启动时把正在使用的脚本目录删除。
- 推送解压、工程启动及未知命令失败会返回错误，扩展收到错误会直接报告；单独停止不会静默转成停止全部。
- 扩展先登记请求再发送，断线清理请求和文件等待器；补充地址、端口、握手耗时、断开原因和连接时长日志，清理 Android 日志分隔控制符。

USB 可手动使用 `adb -s <设备编号> forward tcp:19317 tcp:9317`，再在扩展中连接 `127.0.0.1:19317`。当前包仍使用 `-PdevPluginUsbDiscovery=false` 与参考应用共存，未宣称恢复旧 Pro provider 自动发现。

## MCP 与界面

- 管理页和侧栏显示实际端口、运行状态、心跳过期和错误；默认 `8765`，占用时在 `8765..8795` 顺延。
- 纠正过时的 `8766` / 单独 LAN 开关说明。实际监听 `0.0.0.0`、免令牌，端点为 `POST /mcp`。
- 分别复制局域网、本机地址和客户端配置；新增刷新入口。
- 工具数量由服务实际目录上报，当前 41 个；新增本次进程请求数和最近请求日志，显示工具名、完成或失败、耗时。
- 并发请求计数和事件记录同步处理；状态桥报告实际网络模式。

## 统一日志

- 主进程直接通过控制台的独立订阅接入统一流，避免 log4j 等级过滤漏掉 Verbose/Debug；控制台未就绪时不会提前标记订阅成功。
- 保留转发回流保护，避免子进程日志写回主控制台后重复进入统一流。
- 日志页修正可见状态判定，支持跟随最新、上翻后提示新日志、回到最新、显示过滤条数、复制当前显示内容。
- 实时刷新失败保留已有内容；清空仅清显示或统一缓冲，不删除磁盘文件。历史清空后暂停自动重读，手动刷新或切换模式可恢复。
